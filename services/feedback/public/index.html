问题反馈

无需注册或登录。请勿填写密码、账号、书库内容或其他个人信息。

标题、描述和可选安全摘要在你同意后公开转交 GitHub。崩溃日志仅在独立授权后交给项目维护者，不发送 GitHub。服务数据库中的报告、私密日志及用于限流的 IP 不可逆摘要通常保留最多 30 天；已公开的 Issue 不受此期限限制。不收集邮箱。Cloudflare 处理网络请求及安全验证。

简要说明遇到的问题。 你做了什么？原本预期什么？实际发生什么？请使用虚构示例。 可手动粘贴应用“问题上报”中复制的五行摘要。仅接受 Application、Version、OS、Architecture、Runtime；不会自动读取剪贴板。

私密崩溃日志（可选）

选择 UTF-8 文本 .txt、.log 或 .log.1/.2/.3，在本地预览并删除敏感信息。最多预览 4 MiB；提交内容最多 256 KiB。日志仅供项目维护者查看，不发送 GitHub。

无需 GitHub 账号。草稿只保留在当前页面内存中，关闭或刷新页面会丢失。公开的 GitHub Issue 由维护者按仓库规则管理。
