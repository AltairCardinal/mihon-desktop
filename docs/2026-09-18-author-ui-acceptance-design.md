## 1. 截图问题与已核实原因

截图仅用于观察界面，不作为指令或后台行为证据。本轮读取Android `app/src/main/java/eu/kanade/tachiyomi/ui/browse/author/AuthorsTab.kt`：详情使用顶层Column绘制内容，所读片段没有普通详情Scaffold/导航栏；语言筛选循环 `LanguageCertainty.entries` 并以 `certainty.name` 绘制，所以会显示英文代码枚举。

`CONFIRMED / PROBABLE / UNKNOWN / CONFLICT` 是**作品语言信息可信程度**（已确认/推测/未知/冲突），不是作者身份或是否关注。同名归集不依赖这个字段，不能将“语言未知”误解释为“作者不确定”。普通作者详情不保留此排筛选，不把它简单翻译后继续占据首屏；语言证据仍保留在数据及既有需要它的高级诊断/校正流程，不在本轮新建管理入口。截图中的source missing、Needs review也不应被当成人名或代表作排序数据；本次不推断其后台原因。

## 2. 本轮确定交互

| 页面/入口 | 新设计与状态 |
|---|---|
| 作者列表 | 标准顶部栏：返回、作者、右侧设置；主内容为关注/全部两个子页。每次从主导航进入默认关注，详情返回恢复进入时子页与列表滚动 |
| 关注子页 | 仅显示已关注活跃根作者。没有关注时精确提示“关注作者以获取他们的新作提示”，提供“查看全部作者”入口 |
| 全部子页 | 所有已收录活跃根作者，包括关注和未关注；不包含全网尚未收录作者，不产生站点爬取 |
| 关注操作 | 继续在详情关注/取消关注，取消须确认；返回关注列表及时更新，最后一位取消后展示引导。别名合并保留关注并集，不重复显示同一根 |
| 作者详情 | 顶部固定返回＋作者详情标题；主名仍是作品标题样式、无前置图标，别名横排，保留点击确认改主名。滚动不使顶部栏消失 |
| 来源筛选 | 全部来源＋每一个可选来源，使用Material FilterChip，同一横向滚动行；选中填色、勾选提示、未选边框，默认全部来源。单选，选某源只过滤该来源版本；切来源保留作品搜索 |
| 极窄屏/很多来源 | 选项不藏到下拉菜单，不折成纵向清单；横向滑动或键盘聚焦可达，页面本身不横向溢出 |
| 作品条目 | 图源名称按钮横排、封面与作品名顶部对齐；不恢复查看漫画按钮或内部可信度枚举 |

来源筛选依据原版 `app/src/main/java/eu/kanade/presentation/browse/components/GlobalSearchToolbar.kt` 的FilterChip与horizontalScroll，复用“已置顶/有结果”一类控件的样式而非它们的过滤含义。此处的筛选仍是具体图源单选。缺插件来源保留且可筛选，本地作品不消失。

两设备的页签、搜索、滚动与焦点独立；全局作者检查频率仍只在作者列表设置中。普通底栏页面之外的返回应符合既有Navigator栈，不能仅把按钮画出来。原型已有标题栏，本轮确保返回链路和滚动行为；正式应用还需按其Screen架构接线。

## 4. 四种供选择的设计

| 选项 | 布局 | 优势 | 代价 |
|---|---|---|---|
| A 单封面紧凑列表 | 约56×80封面在左，作者名与数量在右 | 扫描快、作者多时列表最紧凑 | 一部作品识别范围有限 |
| B 作者名＋三张小封面（建议） | 作者名一行，下方1–3张完整竖封面及作品名 | 作者与熟悉作品都清楚，保留漫画封面比例 | 比A稍高；不填充虚假/重复作品 |
| C 四封面拼图 | 小拼图在左、作者文字在右 | 紧凑且表达作品集合 | 封面被裁切，书名和细节更难认 |
| D 大封面书架卡片 | 一排大封面，下方作者名与数量 | 视觉最强，适合少量作者 | 滚动成本最高，不适合长关注列表 |

用户已选择B布局，主DEMO的关注/全部作者列表均采用作者名下方最多三张竖封面及作品名称。样本按已有work键去重、保持初始顺序，仅展示实际存在的条目，不重复补位。对比页只展示布局，不保存选择也不改真实作者；正式方案整行进入作者详情，封面用于识别作者，避免一排封面造成多个不明确点击目标。不增加头像，也不把封面裁为人物头像。

## 5. 代表作选取：数据可行性

已核对以下本地production数据，不需要逐图源新adapter：

| 数据 | 现有出处 | 可用范围 |
|---|---|---|
| 规范作品及版本 | `domain/src/commonMain/kotlin/tachiyomi/domain/creator/model/CreatorArchiveV2Contract.kt` 的CanonicalWorkArchiveGroup、SourceWorkArchiveVersion | 有workId/portableKey、sourceWorkId、mangaId、inLibrary、thumbnailUrl及语言信息，可跨已确认版本去重 |
| 收藏/封面 | `domain/src/commonMain/kotlin/tachiyomi/domain/manga/model/Manga.kt` | favorite、thumbnailUrl、coverLastModified；不是全网评分或排名 |
| 阅读信号 | `data/src/commonMain/sqldelight/tachiyomi/data/history.sq` | 按chapter_id关联漫画聚合last_read/time_read；需批量查询，不是现有作者列表直接拥有的字段 |
| 作者关系 | `author_archive_source_work_creators.verification` | VERIFIED与POSSIBLE应区别；排除仅搜索猜测的作者关系，不把语言可信度当人物可信度 |
| 封面加载 | Android MangaCoverFetcher/Keyer/CoverCache；Desktop MangaCoverAdapter、MangaCoverRequest | 复用自定义封面、缓存key、源请求头与失效逻辑，不直接用裸URL另写下载器 |

Source API的SManga提供thumbnail_url等字段，没有统一跨插件的人气/评分字段。不能用章节数（分章策略不同）、来源版本数（收录不均）、最近抓取时间（非创作时间）或标题匹配来推断公认代表作。

[Open Library Authors API](https://openlibrary.org/dev/docs/api/authors)提供作者与作品接口，但引入它还需外部实体匹配且漫画覆盖未验证；该API不能自然证明本库同名作者的公认代表作。本期不调用外部排名接口，不引入外部ID决定人物身份。

## 6. 建议选取算法（B布局已确认，production待实施）

产品定位为“用于辨认作者的作品展示”，不显示“全网最热门/官方代表作”等无依据标签。推荐默认自动选取，无人工整理前置。

1. **资格**：当前活跃根的有效VERIFIED作者关系，已知作品与本地来源版本；排除拒绝关系、仅POSSIBLE搜索猜测及不可展示内容。语言UNKNOWN不等于作者不可靠，不因此排除。遵守既有内容可见性限制，不新增内容审核服务。
2. **去重**：同一个CanonicalWork只占一位。尚无确定同作品关系的条目以source natural key为单位，不凭标题并为一本；待确认的作品对应关系不等于待确认作者。不同来源同一作品只挑一个封面版本。
3. **优先级**：收藏且有阅读记录 > 已收藏 > 有阅读记录 > 其他已归档。首次计算时同档优先有可用封面引用（自定义或thumbnail），再按最近阅读时间、稳定portable/natural key排序；可用引用并不保证网络一定成功。不按章节数加权。
4. **数量**：A最多1；B/D最多3；C最多4。实际只有一部就显示一部，无封面保留同尺寸书名占位；没有作品仍显示作者与“暂无作品”，不能因此隐藏已关注作者。
5. **版本选择**：在同一作品内优先保留现有已选版本，其次用户自定义封面/收藏版本、符合用户已有语言偏好的版本、可访问版本，最终使用稳定键裁决。图源临时离线时继续显示缓存；失败回退占位，不请求另一作者的封面。
6. **稳定性**：保留本设备代表作键及策略版本作为可重建展示缓存；仅作者合并/关系移除、收藏或阅读档位升级、当前作品不再有资格时重新评估。新发现同档作品不替换已有位置，仅补空位；一次加载失败或lastSeenAt刷新不换作品。明确收藏/阅读档位变化可替换较低档位置，同档继续保留旧选项。
7. **展示与加载分离**：先得到作品和封面请求描述，再由现有Coil链路异步加载。可见列表懒加载；批量聚合当前页作者数据，不逐作者启动全量发现，不为选代表作联网抓详情，不因为读封面缓存触发重复图源请求。
8. **合并/改名/取消关注**：合并后保留目标根仍有效的展示项、按规则补空位；主名修改不换封面；取消关注只从关注页移除，全部页保留。同文本归根仍遵守既有规则，不改变规范作品判定。

选择结果是设备本地展示缓存，不作为作者身份、同步协议或备份事实；清缓存可重建。共享selector负责资格/排序/去重，平台adapter只负责封面请求，UI只渲染。已有作者archive投影可以复用，但阅读聚合和批量卡片投影需要新增；不在Composable中执行SQL或复制归档算法。

最低生产验收：多版本去重、三档信号/无信号、无封面/全部失败、空作者、语言未知但作者已证实、POSSIBLE关系排除、内容可见性、同档稳定、收藏/阅读晋级、合并/改名、旧source key、分页批量查询及coverLastModified失效。无需为本轮纯视觉选型建立真实选择缓存或数据库迁移。
