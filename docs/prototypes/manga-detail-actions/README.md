## 本轮审阅范围

- 封面下方操作区、按钮定制弹窗、作品级“读完即删”弹窗。
- Desktop 使用鼠标滚轮或列表外侧箭头翻页；Android 保留连续左右滑动。
- 沿用 Mihon 的语义颜色、图标家族、详情双栏和弹窗草稿规则，排序面板与读完即删沿用历史原型内容。
- 背景章节、标题栏和阅读按钮只展示上下文，不模拟阅读器或真实下载。

## 交互契约（实现前固定）

1. 业务按钮依次呈现已选常用操作和其余操作。「排序」始终在最后，占一个按钮宽，用竖线与其他操作隔开，随列表直接滚入视野。点击它打开排序弹窗。长按业务按钮会在栏内进入拖排，拖动时预览位置、靠近边缘可自动滚动，松手应用顺序，取消则恢复。按住「排序」本身不会打开弹窗，松手也不会触发。刷新、切换作品或保存排序时回到列表开头。
2. Desktop 每段滚轮操作按一个视口宽度翻页，停顿 300ms 后接收下一段；末页按边界截断。列表外两侧各显示一个常驻窄箭头，到头的一侧置灰；可用时点击一次翻一页。居中的圆点表示当前页和页数；Android 使用居中的连续进度条，按拖动距离直接滚动，反向拖动可立即返回。
3. 定制弹窗中，勾选控制首屏成员，长按条目或拖动柄后拖动控制顺序。收藏必选但不锁位置；实时预览包含收藏的新位置。拖动时浮起并标识占位，列表边缘停留会滚动；取消拖动恢复本次拖动前的草稿顺序。快速纵向触摸可滚动选项列表。
4. 面板内保存才应用成员和顺序；取消、遮罩、Escape 不写入。布局在本端全部示例作品间通用；删除规则按作品隔离，两端状态独立。刷新恢复样本。
5. “读完即删”以跟随全局、开启、关闭三项呈现；保存只修改原型状态，不删除内容。业务规则沿用上一轮，不在本轮引入全局对齐或延迟删除。
6. 原生 dialog 管理入焦和背景隔离；补充 iframe 内的 Tab 循环，关闭返回触发按钮。主题切换保留局部状态，不抢另一个预览的焦点。

桌面也可聚焦任一操作按钮后按 `Shift+F10` 打开定制；聚焦拖动柄后按 `Alt+↑/↓` 调整顺序。Android 画框内的鼠标拖动仅作为桌面审阅时的触摸替代，鼠标与触摸复用同一水平手势处理。HTML adapter 接管水平位移，使用 pan-y 保留页面纵向滚动；不模拟浏览器水平惯性。示例作品切换用于检查布局与作品级设置的作用域，封面共用虚构插画。

## 来源与边界

- `SOURCE`：基线 `b32d39a5c0` 的 `MangaDetailActionRow`、`MangaActionRow`、`DetailActionStrip` 和共享按钮模型；保留收藏必选、四项上限及删除三态。Desktop 封面 7:10，Android Book 2:3；本轮连续滚动和重排不是该基线已具备的行为。
- `PROJECT_POLICY`：用户要求先审核 HTML；按本轮反馈在末尾加入可滚动到的「排序」，保留含收藏的长按排序，并增加桌面箭头分页。
- `HTML_ADAPTER`：圆角、间距、按钮密度、滚轮归一化和动画为本轮视觉提案；不是 Compose 像素级验收。提示、收藏、复制和分享均为本地模拟反馈，无实际账号、剪贴板或文件操作。

原型优先复用 `multi-device-sync` 中的 Mihon 语义颜色、线性图标和双端独立视图方式；为避免把整套同步模型带入本功能，使用独立的小型本地页面。
