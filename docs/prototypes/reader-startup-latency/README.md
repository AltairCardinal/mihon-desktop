# 漫画打开时间实验室

直接双击 `index.html` 即可离线使用（`file://`），不需要服务器、账号、CDN 或远端请求。这是独立的体验 DEMO，不修改 Mihon 产品，也不代表生产性能优化或体验验收通过。

## 操作

- A / B 独立选择六个实测预设，默认对比真机官方首次与真机探针对齐首次。
- 点击画面或“播放此卡”单独回放；“同时播放 A / B”共用一个起点。“重置画面”只恢复画面，“恢复预设”同时撤回本卡参数更改。
- 2× / 5× 是慢放：原始 300ms 分别用 600ms / 1500ms 播放；画面外计时仍显示样本时间。改速度会停止并重置两卡。
- 探针对齐样本可独立手调六段，数值框保留小数；滑块默认范围 0–2000ms，数值框支持 0–10000ms。官方内部未知，只开放“点击→首漫画”观测总时长，不用探针数字替官方填空。
- 视觉区可以手调旧页保持、旧页淡出、近黑后的最短等待和首图渐显时长。修改参数停止并重置本卡，重新播放生效，另一卡继续独立运行。
- 图片预加载并 `decode()` 完成后才允许播放；解码失败会保留禁用状态并提示检查本地资源。计时、进度条和控制都在设备画面外。

## 真实数据与模拟边界

数值依据：[源视频时钟与 GPU 对照](../../evidence/reader-startup-clock-gpu-2026-11-02.md)及其[JSON](../../evidence/reader-startup-clock-gpu-2026-11-02.json)。同一实测样本的内部探针与捕获端点配对，不跨样本拼接。

| 预设 | 首漫画捕获 ms | 内部阶段 |
| --- | ---: | --- |
| 真机官方首次 | 284.275959 | 未测得 |
| 真机官方暖态 | 289.346552 | 未测得 |
| 真机探针对齐首次 | 366.246971 | 同样本探针 |
| 真机探针对齐暖态 | 308.575662 | 同样本探针 |
| 模拟器联合探针首次 | 1020.322710 | 同样本探针 |
| 模拟器联合探针暖态 | 623.954116 | 同样本探针 |

六段依次为主线程 DOWN→OPEN_READER_INTENT、初始化→PAGE_LIST_READY、列表→OPEN_PAGE、调用点→DECODE_SUBMIT、submit→FIRST_DRAW、draw→视频首漫画。OPEN_PAGE 位于调用当前页 streamFn 之前，不意味着文件打开/读取完成；submit 不等于底层解码开始。末段是同样本观测差值，不是一个已证实的独立流水线工作阶段。FRAME_COMMIT 不作首图呈现端点。

内部准备与视觉转场并行：`ready = 六段总和（官方为观测总时长）`，`visualGate = 旧页保持 + 淡出 + 近黑后最短等待`，`firstPixel = max(ready, visualGate)`。渐显时长影响整页进入完成时刻，不再加到首漫画端点。视觉比内部准备更晚时，卡片明确显示额外等待；修改后的值是自定义假设，原始采样区间只供参考。默认视觉门槛均早于样本捕获端点，因此不会延迟默认实测首图。

真机视觉参数来自源视频帧人工核对；在两锚点之间以线性淡出简化，不是原生 Activity 动画逐帧复刻：

| 样本 | 最后采用的完整旧页锚点 ms | 采用的近黑锚点 ms |
| --- | ---: | ---: |
| 官方首次 | 135.753 | 250.899 |
| 官方暖态 | 124.009 | 253.481 |
| 探针对齐首次 | 164.022 | 313.123 |
| 探针对齐暖态 | 140.381 | 272.055 |

原始帧位于 `.test-tmp/slime-clock-gpu-20261102/contact-aligned-<sample>/`，探针 shared 样本沿用样本原目录；源 PTS、DOWN 及亮度统计分别见 `raw-clock-summary.json` / `native-frame-statistics.json`。中心 ROI 的早期 YAVG<17 候选区间不代表全屏严格黑，不能用来取代近首图的视觉人工核对。模拟器两卡的旧页/淡出值明确为示意，不冒充逐帧测量。

真机探针对齐暖态 308.576ms 首漫画仅部分入场，323.549ms 才整页进入；此 DEMO 简化为在首漫画端点显示整页，可用渐显探索不同体验，但不声称复刻其位移动画。浏览器刷新率会量化动画显示时间，计时不是新的设备测量。视频捕获不证明物理屏幕扫描，联合采集可能带来扰动；首次是新应用进程首次阅读器，不是磁盘冷态。官方与探针对齐版封面、元数据等仍不同，不能由差值直接归因探针。

## 本地资源与文件职责

- `assets/first-page.webp`：直接取自同一原始 CBZ 的 `001.webp`，未重编码；原 CBZ SHA256 为 `b3d7c4e56e58dfee6d9da7d5afafe12b267ccc6d50dd48cd3660456b8d2b4677`。187 页 fixture 的第1页，非封面占位图。
- `assets/details.png`：`tablet-shared-on-first/video.h264` 第12帧，1920×2880，合成测试详情页，不含个人漫画库信息。所有卡片共用此截图作为转场底图；官方实际封面等不同，不宣称还原其详情页内容。
- 设备画面采用 1920:2880（2:3）平板比例；首页 `object-fit: contain`、黑底，不拉伸原图。窄屏依次排列两张独立卡。
- `timing-model.js`：浏览器和 Node 共用的实际时序模型；`app.js`：图片解码、输入、独立动画与交互接线；`styles.css`：演示工具外观。无持久化、网络或生产接线。
