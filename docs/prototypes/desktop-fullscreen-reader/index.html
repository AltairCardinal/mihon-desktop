阅读器设置

提示：全屏快捷键统一为 F11，无论设置面板打开与否均可全局响应。

交互实现说明与验收契约：
  • 全屏按钮位置与激活态：放置在 TopAppBar 右侧，位于 Settings（齿轮图标）按钮的左侧；非全屏时显示 fullscreen 图标（普通悬浮态），全屏时呈现为 Material 3 按下的激活态（is-active，带背景半透明高亮填充与 fullscreen_exit 收缩图标）。
  • 进入全屏气泡提示：每次调用 toggleFullscreen(true)（通过点击全屏按钮、按键盘 F11 或快捷操作触发）时，屏幕右上角均触发 .fullscreen-bubble.is-visible 提示【按F11以进入/退出全屏】，并在 3.2 秒后平滑淡出，支持点击右侧 ✕ 即时关闭。
  • 全屏下边缘自动感知显隐：全屏沉浸状态下顶底栏默认收起。鼠标移到屏幕最顶端（y <= 8px）时触发顶部菜单滑出；当鼠标向下滑动超过菜单高度与安全缓冲区（y > 110px）时顶栏平滑收起；鼠标移到屏幕最底端（distFromBottom <= 8px）时底部控制栏滑出，向上移开后消失。
