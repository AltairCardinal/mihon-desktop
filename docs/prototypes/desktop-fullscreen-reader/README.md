# Mihon Desktop · 全屏阅读模式交互原型

本项目为针对桌面版 Mihon 新增全屏阅读模式的交互审阅原型，位于 `docs/prototypes/desktop-fullscreen-reader/`。

可以直接在任意现代浏览器中打开 [index.html](index.html) 进行本地交互审阅，无需启动后端服务或网络请求。

---

## 审阅要点对照清单

| 序号 | 需求项 | 原型实现与交互表现 | 验收路径 |
|:---:|:---|:---|:---|
| **1** | **全屏按钮位置与激活态**<br>在阅读器菜单右上角设置按钮左边添加全屏按钮，进入全屏后全屏图标显示为一个按钮按下的激活态。 | • 按钮置于 `reader-topbar` 右侧区域，排在设置按钮（齿轮）正左侧。<br>• 窗口模式：图标为展开全屏 `fullscreen`，默认透明悬浮态。<br>• 全屏模式：呈现 Material 3 按下激活态（`is-active`，半透明主色容器高亮填充 + 内阴影），图标切换为收缩全屏 `fullscreen_exit`，`aria-pressed="true"`。 | 打开页面 → 观察顶栏右上角设置左侧按钮 → 点击全屏按钮 → 观察按钮背景变为高亮激活态且图标变为退出全屏。再次点击恢复窗口模式。 |
| **2** | **进入全屏气泡提示**<br>每次进入全屏时都在屏幕右上方用气泡提示【按F11以进入/退出全屏】。 | • 只要进入全屏（点击全屏按钮、按物理键 `F11`、或快捷操作），屏幕右上角立即弹出气泡提示。<br>• 气泡文案为【按 F11 以进入/退出全屏】，采用 Material 3 `surfaceContainerHigh` 材质、圆角高亮与快捷键 `<kbd>F11</kbd>` 徽标。<br>• 持续 3.2 秒后平滑淡出，支持点击 ✕ 提前关闭。<br>• **每次**重新进入全屏均会再次弹出。 | 点击全屏按钮进入全屏 → 观察屏幕右上方弹出气泡提示 → 等待淡出或点击 ✕ → 退出全屏后再次进入 → 确认再次弹出。 |
| **3** | **全屏下鼠标边缘感应显隐**<br>鼠标移到最上方显示顶部菜单，下移一段距离（大于菜单高度）后消失；鼠标移到最下方显示底部菜单。 | • 全屏模式下，顶底栏默认收起，提供沉浸式阅读空间。<br>• **顶部感应**：鼠标移到屏幕最顶端（`y <= 24px` 舒适感应区或悬浮顶部感应条）时，顶部菜单顺滑滑出；鼠标向下移动超过菜单高度（高度 56px，设定阈值 `y > 110px`）时，顶部菜单自动收起隐藏。<br>• **底部感应**：鼠标移到屏幕最底端（距底部 `<= 24px`）时，底部控制栏顺滑滑出；向上移开一定距离（`distFromBottom > 110px`）后自动收起隐藏。<br>• 提供**实时感应诊断条**，实时显示鼠标坐标及顶底栏显隐状态。 | 1. 点击全屏按钮或按 F11 进入全屏模式。<br>2. 观察顶底栏已自动收起隐藏。<br>3. 将鼠标移动至屏幕最顶端边缘（或顶部感应条）→ 顶部菜单滑出，实时诊断条显示「滑出显示」。<br>4. 鼠标向下移动超过 110px → 顶部菜单自动收起隐藏。<br>5. 鼠标移动至屏幕最底端边缘 → 底部控制栏滑出；向上移开后自动收起。 |

## 附加功能与辅助审阅工具

1. **真实物理显示器全屏**：
   - 顶部工具栏提供「真实显示器全屏」按钮（调用浏览器 `requestFullscreen` API），可直接进入操作系统真全屏，在物理显示器屏幕的最上/最下边缘体验原生鼠标贴边感应。
2. **快捷键全面支持**：
   - `F11`：进入/退出全屏（每次进入触发气泡提示）。
   - `Escape`：退出全屏（若处于全屏模式）或关闭设置面板。
   - `←` / `→` / `A` / `D` / `空格`：翻页。
3. **沉浸式漫画跨页模拟**：
   - 包含双页跨页模式、翻页滑动条、页码实时联动、上一话/下一话按钮。
4. **多主题支持**：
   - 支持深色、浅色、AMOLED 纯黑三种 Mihon 标准主题切换。

## 自动化测试验证

本原型包含完整的状态机与交互行为测试用例，采用 Node.js 原生测试运行器驱动：

```powershell
node --test docs/prototypes/desktop-fullscreen-reader/fullscreen-reader.test.cjs
```

测试覆盖：
- 按钮位置、状态切换、激活态 class、`aria-pressed`、图标切换。
- 气泡每次进入全屏时弹出、文案精准匹配、可多次重复触发。
- 鼠标最顶端感应触发、菜单高度以上区域保持、超过下移阈值后自动隐藏。
- 鼠标最底端感应触发与上移隐藏。
- `F11` 与 `Escape` 快捷键状态联动。
