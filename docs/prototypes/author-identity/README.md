# 相同名字共用作者 · 双端交互原型

直接打开 [index.html](index.html)，无需服务或账号。双端使用独立页面内存，刷新恢复样本，没有真实网络、插件、备份或跨设备同步。产品尚未修复；设计见[功能设计](../../2026-09-17-global-author-functional-design.md)与[技术方案](../../2026-09-17-creator-identity-reconciliation-proposal.md)。

## 名称规则

相同非空名称文本无条件视为同一人，跨插件自动复用。来源及来源作者编号不同、缺失均不参与人物判定。首版严格文本相等，不自动转换繁简、大小写、音译、标点；输入是已经分离的单个姓名。空白名称不创建作者；新的未知非空名称自动建作者，不弹身份选择。

历史主名或已接受别名有相同文本的档案在初始化时传递收敛，保留作品、关注和旧入口重定向。手动操作只用于合并不同名字：确认后保留全部名字为全局别名，未来任何插件使用其中任一名字都会自动复用。没有同名不同人隔离、文字署名待确认、逐来源关联或取证流程。

## 固定样本与审阅顺序

1. 初始两端打开漫画柜《平行天堂》。历史三个“冈本伦”已自动归为一位作者；点击署名直接进入作者页，不弹框。其作品为《平行天堂》（漫画柜）、《极黑的布伦希尔德》（文字图源演示）、《变异体少女》（漫画柜），共3部作品、3个来源版本，已关注，每12小时检查。
2. 作者列表另有两个严格不同文本：`Okamoto Lynn`，拥有 MangaDex《Parallel Paradise》；`岡本倫`，拥有演示来源《極黑的布倫希爾德》。因此初始列表共3位作者。两个作品版本分别已确认对应《平行天堂》《极黑的布伦希尔德》，不靠标题猜测同一本书。
3. 作者页 →「合并不同名字」→ 勾选 `Okamoto Lynn` → 预览范围、主显示名、关注开关与检查频率 → 确认。结果3部作品、4个来源版本。未勾选的 `岡本倫` 仍独立；继续合并后为3部作品、5个来源版本。可把英语或繁体选作主名，其他全部名字仍保留为别名。分次合并也会展示所有既有别名，允许将此前别名改为主名。默认频率仅从已启用关注的计划取最短值，未关注档案不缩短周期。
候选列表可搜索名字和别名。搜索不清除已勾选项，零选择和无匹配有明确反馈。

4. 在不同来源的版本点「查看漫画」再点击署名，都进入合并后的同一作者，使用统一关注。来源筛选只影响列表。取消关注有确认，作品和别名不删除。
5. 应用外「加入同名作品」真实调用名称观察模型：通过新插件、无作者编号加入《同名新作（虚构样本）》，名称“冈本伦”自动复用；在初始场景点击一次后为4部作品、4个版本，再点不增加条目。
6. 合并英语名字后，应用外「加入已合并别名作品」通过新插件加入《别名新作（虚构样本）》，署名 `Okamoto Lynn` 自动复用。只合并英语后加入为4部作品、5个版本。重复点击幂等；还没合并英语时只提示先合并，不越界绑定。该演示动作专门验证已有别名，模型对真正未知名称仍自动建作者。
7. Windows作者入口在独立底栏；Android在「浏览 → 作者」。其他页签只展示本次原型边界与返回入口。

所有样本用于设计，不代表用户真实数据库中的作者或作品关系。

## 场景与失败处理

应用外选择目标设备，再「显示场景」或「重置目标端」。动作只影响所选端；另一端的数据、导航、焦点、选择和滚动不变。深浅主题同时改外观；320px开关只改变Android预览宽度。

- 相同名字自动归集：恢复初始化后的3个不同名字。
- 提交失败：不同名字合并无部分结果，取消保持全部原档案；刷新预览后可重试。关注失败同样保留原状态。
- 预览过期：获取预览后实际改变当前作者关注样本，提交被拒；刷新重新读取作者范围、作品计数和关注设置。
- 无可合并的其他名字：已合并全部样本名字，保留作品/别名，选择面板显示空状态。
- 来源不可用／插件卸载：漫画柜标记不可用，本地作者、作品、关注仍保留；不提供真实来源访问。

目标端正打开合并会话时，应用外加入作品只更新模型并保留当前作者、选择、对话框和焦点；旧预览提交会被拒绝，刷新重新计算数量。

取消、关闭、点击蒙层或Escape退出对话框会话并恢复触发按钮焦点；「返回选择」保留选择。Tab/Shift+Tab在对话框内循环。长对话框内容滚动，底部操作保持可达。合并失败保持预览和选择，不部分写入。历史自动收敛与不同名字合并均保留重定向链。

备份说明仅为模拟，不下载文件、不改用户数据，不承诺一键原样撤销。原型没有在线同步或基于来源身份的同步禁用门槛，跨设备合并传播仍未实施。
