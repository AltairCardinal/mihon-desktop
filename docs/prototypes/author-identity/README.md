# 跨插件唯一作者 · 双端交互原型

直接打开 [index.html](index.html)。不需要启动服务、安装依赖或登录账号；`device.html?platform=windows` / `device.html?platform=android` 可隔离调试。

这是本地 HTML 交互设计，不是生产修复。数据仅存当前页面内存，刷新恢复样本；没有真实插件、网络取证、数据库、备份下载或跨设备同步。设计契约见[功能与交互设计](../../2026-09-17-global-author-functional-design.md)及[技术方案](../../2026-09-17-creator-identity-reconciliation-proposal.md)。

## 审阅顺序与固定样本

1. 两端初始打开漫画柜《平行天堂》详情。点「冈本伦」，看到三个历史档案，分别拥有《平行天堂》《极黑的布伦希尔德》《变异体少女》。第二个档案已关注、每12小时检查；另两个未关注。这里是设计用样本，不能当成用户手机数据库中的实际内容。
2. 「整理作者」可取消勾选，至少两份才可预览。「归集预览」列出范围、保留的作者档案、关注开关和12/24小时频率。确认后保留作品并集，旧入口重定向；取消/关闭不改变数据。全部归集后是一位作者、3部作品、3个来源版本。分两次归集也能解析旧入口。
3. 作者详情 →「关联其他来源」→ 勾选 MangaDex 的 Okamoto Lynn →「查看依据」→ 返回候选 → 预览并确认。《Parallel Paradise》是已确认与《平行天堂》相同的作品版本，因此结果是3部作品、4个来源版本。两种版本点「查看漫画」再点击署名，进入同一作者，关注状态共用。证据面板完全本地，不打开来源网站。
4. 「待确认署名」包含文字图源的两部文字版作品。支持全选、取消全选和单项选择；预览列出具体范围，确认只关联勾选作品，未选作品仍待确认。这些文字版本没有同一作品证据，所以保留独立作品条目，不按标题自动折叠。
5. 同面板的「冈本伦（同名演示人物）」以《海边手记（虚构样本）》区分。选择「不是这位作者／保持独立」，确认后不进入当前作者作品集。再次打开待确认面板，可「为同名人物创建另一位作者」，后果确认后在作者列表出现独立人物，默认不关注。
6. 作者页提供别名、作品搜索、来源筛选和关注。取消关注必须确认，影响此人的全部已关联来源；不会删除作品。Windows 从独立作者底栏返回列表；Android 从「浏览 → 作者」进入。其他底栏/页签仅显示可返回的原型边界。

## 场景、键盘和失败边界

应用外控件先选择目标设备，再选择场景并「显示场景」；只重置目标端的内存状态与页面，另一端导航、焦点、选择及滚动不变。「重置目标端」恢复三档案初始场景。深浅主题同时改变双端外观，不改变数据；320px开关只调整Android预览宽度。

| 场景 | 审阅入口与结果 |
|---|---|
| 已确认作者 | 直接作者页，一位作者与3部作品 |
| 正在获取依据 | 关联其他来源显示加载，可取消；约1.2秒后本地模拟完成，不访问网络 |
| 取证失败 | 关联其他来源显示失败，重试恢复候选；不把失败当空数据 |
| 暂无其他来源候选 | 显示空状态，已有作者与作品不变 |
| 提交失败 | 初始归集提交失败，无部分结果；取消后仍为三档案，刷新预览可重试 |
| 预览过期 | 初始归集预览后实际改变本地关注样本，首次确认受阻；刷新会重新读取范围、数量及关注设置，复核后才能应用 |
| 关注同步已开启 | 可以选择和预览，归集、跨来源关联及文字署名关联确认均禁用；不关闭同步，也不宣称归集决定可跨设备传播 |
| 来源不可用／插件卸载 | 作者页保留作品与关注，漫画柜显示不可用；本地详情仍可查看，不提供真实来源访问 |

对话框支持点击蒙层或 Escape 关闭、Tab / Shift+Tab 焦点循环，取消后恢复触发按钮焦点。确认后的新页面将焦点放到关注按钮。预览中的返回选择不会提交，关闭/取消整个面板返回原页面。长内容在对话框内滚动，底部确认按钮保持可见。

历史归集不是可一键撤销的操作。备份说明明确为模拟，不真的生成恢复资料、不改变用户文件。正式功能仍需真实事务、恢复往返、插件及发布运行时验收。

## 复用与文件边界

- 只读复用 `../multi-device-sync/styles.css` 和 `ui-view.js` 的主题、Material图标、平台规格与底栏。没有加载同步业务模型，没有复制整个同步原型，也没有修改原同步原型或共享文件。
- 导航和页面入口参照 Desktop `AuthorsTab.kt`、Android `ui/browse/author/AuthorsTab.kt`；平台差异限制在外壳与导航。
- `model.js` 为纯内存原型模型，维护档案、作品来源版本、重定向、待确认选择与原子预览确认；`app.js` 执行真实页面交互。`preview.js` 仅发送目标端场景及外观消息。
- 不同iframe各自创建模型，无共享存储；模型不实现跨设备通信。场景切换是应用外演示控制，不是生产功能。
- 本目录超过8个文件，属于一个完整跨插件作者交互批次：双端容器、应用、模型、视图、行为验证和说明缺一不可。主要风险是选择范围、焦点与设备隔离；不改变产品 Kotlin、持久化或同步协议。
