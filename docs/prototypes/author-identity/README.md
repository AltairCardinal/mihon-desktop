## 名称规则与样本

相同非空名称文本跨插件无条件复用同一作者，来源及来源作者编号不参与判定。输入是已分离的单个名字，严格比较文本，不自动转换繁简、大小写、音译或标点。空白不创建作者，新的未知非空名称自动建作者。历史主名/已接受别名有交集的档案自动传递收敛，保留作品、关注及旧入口；没有同名不同人隔离或文字署名待确认流程。

初始漫画柜《平行天堂》署名“冈本伦”直接进入作者页。历史三个同名档案已自动归为一位，作品为《平行天堂》（漫画柜）、《极黑的布伦希尔德》（文字图源演示）、《变异体少女》（漫画柜）：3部作品、3个来源版本，已关注。

另两位名称不同的作者：`Okamoto Lynn`拥有MangaDex《Parallel Paradise》，`岡本倫`拥有演示来源《極黑的布倫希爾德》。这两份版本分别已有同一作品关系，所以初始列表3位作者；添加英语别名后当前作者3部作品4个版本，再添加繁体后3部作品5个版本。样本不代表用户真实数据库。

## 审阅路径

1. 作者页 →「添加别名」→ 勾选其他名字 →「添加」立即应用。没有第二步预览、主名选择或备份说明弹窗。搜索覆盖候选名字/已有别名，搜索不清除选择；零勾选禁用添加并说明原因。未选作者保持独立，成功回当前作者页并反馈；关注保留并集，全局频率不变。
2. 作者详情不再提供「修改名称」。每个已有别名都是与漫画详情署名同样式的可点击链接；点击后弹窗「要把XXX设为该作者的显示名称吗」。取消/关闭不变更并恢复别名焦点；确定后该别名成为主名称，旧主名成为可点击别名，其他别名和作品/关注/全局频率不变，焦点移到主名称标题。不提供自由输入或下拉编辑。
3. 全局频率在作者列表右上角齿轮「作者设置」中。Windows底栏作者；Android「浏览 → 作者」。作者详情没有频率齿轮。设置只有每天/每周/每月三项，默认每天，简短说明“应用于全部作者”。每月是日历月语义，原型不运行调度。
4. 全局设置覆盖当前设备全部现有及未来作者，保存不改任何关注，添加别名/改主名也不改变频率。取消草稿不生效；保存显示“检查频率已保存”，焦点回齿轮，重新打开读回。失败保持原值。另一iframe独立，并非在线同步。
5. 来源筛选与作品搜索仅改变列表。作品下方直接点击图源名称按钮打开对应版本，再点署名进入当前主名作者。图源横向排列、空间不足换行；封面缩略图与作品名称顶部对齐，不再提供额外「查看漫画」按钮。关注留在详情，取消关注有确认。无别名时整行隐藏；不显示自动归集提示、周期摘要或作品版本说明。
6. 应用外「加入同名作品」通过新插件、无作者编号加入《同名新作（虚构样本）》，同名自动复用，初始加入后4部作品4版本。合并英语后「加入已合并别名作品」加入《别名新作（虚构样本）》，成为4部作品5版本；重复操作不增加条目。英语未关联时只提示先添加，不越界。模型对真正未知名字仍自动建作者。

## 署名视觉基线

作者详情逐项别名与漫画详情原始署名统一参考原版 `MangaInfoHeader.kt` 的 `MangaContentInfo`（仓库提交 `97a9dc17ff` 的父版本，加入身份 Chip 之前）。采用 Material 3 `titleSmall`：14px、500字重、20px行高、0.1px字距；16px PersonOutline 图标、4px图文间距，整行透明度0.78，颜色随主题正文色。漫画标题与署名间隔2px。作者列表去掉作者头像。作者详情主名不带图标，直接复用漫画详情作品标题的字号、字重及正文颜色（当前原型桌面24px、窄屏21px），不施加次级透明度。别名在主名下方横向排列，间距12px，空间不足自动换行；保留每项人物图标，名称本身允许换行。别名及漫画署名保持可点击纯文字，无胶囊边框、蓝色强调或按钮内边距，键盘焦点仍有可见轮廓。Windows和Android使用同一规格；CSS像素模拟默认缩放下的dp/sp，不代表系统字体缩放或字体渲染的像素级复刻。漫画页保留该来源原始署名，别名集合仍在作者详情展示。

## 失败、焦点与场景

目标设备决定场景/重置/加入作品的影响范围，不改变另一端的数据、导航、焦点、选择或滚动。主题同时改外观，320px开关只改Android宽度。

- 相同名字自动归集：初始化3个不同名字。
- 提交失败：直接添加、名称修改、全局设置均失败且无部分写入；添加窗保持选择，刷新候选可重试。
- 候选资料变化：打开添加窗口后实际改变本地状态，提交版本校验失败；在同一窗口刷新候选后重试，不进入预览步骤。
- 无可合并的其他名字：全部样本名字已关联，添加窗口显示空状态。
- 来源不可用：保留作者、关注与本地作品，只标记来源不可用，不提供真实远程访问。

应用外加入作品时若当前端有窗口，保持作者、窗口、选择与焦点；添加窗口的旧版本提交被拒，刷新当前候选。取消/关闭/蒙层/Escape不提交并恢复触发按钮焦点；Tab/Shift+Tab在窗口内循环。成功保存名称回名称按钮，保存设置回齿轮，添加成功回添加别名按钮。
