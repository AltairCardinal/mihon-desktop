# 阅读模式设置 v3：双端统一审批稿

入口：[交互 Demo](index.html)。本轮采用用户提供的 v3，替换上一版审批稿；未修改 Android/Desktop 应用、原生偏好、阅读器或体验包。

## 当前设计契约

- 第一层「跟随默认／单独设置」互斥且始终可切换。默认状态显示完整的继承摘要，不显示可编辑的具体选项。
- 阅读模式只分「翻页／条漫」；「自动」属于翻页下的「单双页」策略，与「单页／双页」互斥，不再作为独立阅读模式。
- 翻页包含单双页、双页自动匹配及翻页方向。**明确选择双页时只提供「从左到右／从右到左」**，纵向选项不可见但保留第三列占位，前两项位置不变，且不参与键盘选择；从纵向切入双页时改为从右到左，原有合法横向方向不变。默认注入、旧演示配置及恢复的值遵守同一约束；单页仍提供纵向。自动策略在本原型中不推算真实单双页，因此沿用原有方向选择。
- 单页隐藏双页匹配；自动或双页时显示，隐藏不清除已选匹配开关值。
- 条漫只显示「页间有空隙」开关，隐藏翻页相关项；切回翻页恢复先前配置。
- 跟随默认显示实际采用的阅读模式、适用布局/方向/匹配或条漫间隙。布局「自动」表示所选策略，本原型不推算真实漫画视口下当前的单/双页结果。
- **与上一版不同**：切回默认保留单独设置值，再次选单独设置时恢复；更改演示默认不覆盖自定义值。此规则以用户 v3 为准，替代上一版“切回默认丢弃覆盖”的设计。
- 移动与桌面使用同一个 Shadow DOM 组件、相同字段与操作逻辑；差异仅是预览容器宽度，两端选择与焦点相互独立。
- 保留用户 v3 的深色、分段控件、图标卡片、开关与展开动画。组件按自身宽度响应；窄浏览器改为上下排列，不在窄列内沿用宽屏样式。
