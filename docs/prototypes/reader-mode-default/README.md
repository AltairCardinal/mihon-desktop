# 阅读模式：默认与单独设置（待审批）

入口：[交互 Demo](index.html)。本次只提供设计候选，不修改 Kotlin 或已构建体验包。

## 固定设计与边界

- 第一层仅有「跟随默认」「单独设置」两个互斥选项；始终可见，支持随时切回默认。
- 默认状态隐藏具体模式选择器，明确显示「当前生效」的实际模式和「来自全局默认」。默认是自动时，显示「自动 → 翻页式」和当前单页/双页结果，避免仅显示“自动”而不知道正在如何阅读。
- 单独设置才显示「自动／翻页式／条漫」。初次进入时从当前默认初始化；切回默认取消本漫画覆盖，再次单独设置以当前默认为起点，不悄悄复活旧覆盖。
- 默认状态下，方向与单双页作为结果说明，不放可编辑控件，避免修改下级选项时暗中脱离默认。单独设置的翻页式可改方向及单双页，条漫隐藏这些控件，自动模式由当前窗口推导结果。
- 切换即时生效；关闭重开保留当前演示会话选择。页面刷新重置，未接入真实偏好、漫画、数据库或应用窗口。
- Desktop 与 Android 并列呈现同一交互提案，选择、关闭及焦点独立；顶端「全局默认（演示）」共用场景输入，不代表跨设备同步。窗口宽窄仅影响 Desktop 自动结果。
- 原型只覆盖阅读模式区域，其余常规/滤镜标签禁用并说明未纳入本次演示。并列组件是非模态预览，不伪造真实全局模态焦点圈定。

## 验收路径

1. 默认打开 → 只有来源二选一，看到当前生效为翻页式及默认来源；没有具体模式选择器。
2. 单独设置 → 出现三个具体模式 → 选条漫 → 生效摘要变为条漫，翻页选项隐藏；另一端不变。
3. 跟随默认 → 立刻恢复当前全局默认，具体模式选择器收起；改变演示全局默认为条漫，默认端更新，独立设置端不变。
4. 全局默认选自动 → Desktop 宽/窄切换 → 双页/单页说明更新，Android 保持单页。
5. 关闭重开、键盘 radio 切换、320px / 200% 字号、浅深色 → 内容可读、无横向裁切、选中状态与焦点有效。
