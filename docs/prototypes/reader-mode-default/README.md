# 阅读模式设置 v3：双端统一审批稿

入口：[交互 Demo](index.html)。本轮采用用户提供的 v3，替换上一版审批稿；未修改 Android/Desktop 应用、原生偏好、阅读器或体验包。

## 当前设计契约

- 「跟随默认／单独设置」互斥；切回默认保留自定义值，返回后恢复。
- 阅读模式为「横向阅读」（适合传统漫画）与「纵向阅读」（适合条漫）。内部 `paged/webtoon` 标识保留兼容，不直接代表真实阅读器。
- 横向阅读提供自动／单页／双页，所有布局都只有左右两个方向，等宽铺满一行，不留纵向按钮占位。自动说明为「根据阅读区域宽高比自动切换单/双页」。单页隐藏双页自动匹配，其余布局在方向下方显示。
- 纵向阅读提供「滚动方式」：连续滚动／逐页翻动，后者承接原单页从上到下的语义。只有连续滚动显示「页面有空隙」；切换方式或阅读模式时保留隐藏值。
- 滚动方式使用现有细线图标语言：连续滚动采用用户确认的「长方形内上下双向箭头」`scroll-continuous`，外框复用单页图标的 12×18.5、圆角 1.8，箭头略缩以增加留白；逐页翻动继续使用用户选定的 Lucide `gallery-vertical`（来源：https://lucide.dev/icons/gallery-vertical，ISC）。均为24×24网格、19px显示、1.65描边、圆角端点/转角、currentColor；选中时随文字变为强调色，图标为装饰，不重复朗读按钮文案。双端共用；纵向阅读模式卡片的原有图标不变。
- 默认摘要显示适用阅读模式、单双页及左右方向，或纵向滚动方式；仅连续滚动展示间隙摘要。
- 旧演示状态 `paged + single + vertical` 且没有新 `scroll` 字段时转换为纵向逐页；其余旧纵向非法组合改为横向从右到左。旧条漫转为纵向连续滚动。恢复、默认注入、浏览器保存与聊天状态均通过同一规范化入口。
- 双端共用组件，状态与焦点独立，仅容器宽度不同。原生应用未修改；逐页翻动在本 Demo 中只验证设置选择及语义映射，不绘制或运行真实翻页动画。

## 验收与验证

1. 横向所有布局下两个方向占满横向空间，无第三个按钮。
