# Mihon 多设备同步离线演示

这是需求草案阶段的本地交互演示，不代表同步方案已经获用户确认，也不连接 GitHub、GitLab 或其他真实服务。

## 打开

直接双击 `index.html`，或在浏览器地址栏打开该文件的 `file:///` 地址。HTML、CSS 和 JavaScript 均为本目录文件，没有 CDN、安装依赖或网络请求。

Node 行为测试使用内置测试运行器：

```text
node --test docs/prototypes/multi-device-sync/sync-model.test.cjs
```

## 建议演示路径

1. 页面初始选中电脑 B，同步页会显示手机 A 发来的取消收藏待确认项；点击「确认取消」或「忽略本次」，观察当前设备状态和计数变化。
2. 切换「更新」页，在一台设备（来源端）操作《星海骑士》收藏或记录阅读位置并点击「立即同步」；再切换到另一台设备（接收端）点击「立即同步」。设备缺失不会生成取消操作。
3. 点击右上角网络图标进入离线，继续在实验台收藏或阅读，再恢复在线并重试；待发送计数会保留到成功交换。
4. 在两台设备分别制造相反收藏决定；每次都先在产生决定的来源端点击「立即同步」，再在另一台接收端点击「立即同步」，进入「冲突」条目选择保留本地或采用远端；选择会形成新的待发送决定。
5. 在实验台打开「模拟正在阅读」，在来源端记录新的阅读位置并点击「立即同步」，再切到另一台接收端点击「立即同步」。当前画面不会自动跳转，提示中的「采用此位置」是显式入口；阅读模式下拉框始终按设备独立保存。
6. 使用「模拟启动同步」和「模拟定期到期」验证开关，关闭对应开关后触发会显示跳过；「重置演示」恢复有内容的初始状态。

## 演示边界

操作、确认、去重、离线待发送、冲突和阅读位置均由 `sync-model.js` 的内存模型驱动。刷新页面会重新建立演示状态；页面没有持久化、真实远端、系统后台调度、真实凭据、跨源识别、完整历史迁移或文件传输。模拟定期按钮代表一次到期机会，不等待真实时间。
