# 外观页：原版源码对齐与审核清单

本轮目标是【更多 → 设置 → 外观】的页面结构、选项、预览与状态转换。**SOURCE** 固定为官方 `mihonapp/mihon` 主分支 `866d045c7aba343fd739c57d15c81ff6df59e796`，不是本 fork 较旧的设置实现。HTML 验收不代表生产 Desktop 设置或 Android 系统能力已移植；没有原生截图基准，因此不把 CSS px、浏览器字体和渲染结果宣称为跨平台像素完全相同。

## 实现前固定契约

| 项目 | 原版依据与必须保持的行为 |
| --- | --- |
| 入口与宽窄布局 | `SettingsScreen`：窄屏先设置目录，再进入外观；平板布局左侧设置目录、右侧默认外观，左栏半宽且上限 450dp，双栏没有分割线，独立滚动。本页 HTML 以 1dp 对应 1 CSS px 表达，左栏上限 450px；字体与实际设备密度仍属于适配边界。 |
| 主题组 | `SettingsAppearanceScreen`：主题组只有应用主题自定义控件与纯黑开关；“跟随系统／浅色／深色”分段控件、横向主题卡片，不是下拉选择框。 |
| 卡片 | `AppThemePreferenceWidget`：宽 114dp，预览 9:16，4dp 边框、17dp 圆角，内含顶栏、封面、双色角标和底栏；选中显示 RoundedFilled.CheckCircle，主题名称在卡片下方。 |
| 纯黑 | `PreferenceItem.StatusWrapper` 将 enabled 映射为 AnimatedVisibility；`ThemeMode.LIGHT` 时整行隐藏，SYSTEM 即使当前系统浅色也显示并允许操作，实际纯黑覆盖只在深色生效，原值保留。 |
| 显示组 | 原顺序：应用语言、平板界面、日期格式、相对时间戳、在漫画注释中显示图片。应用语言是子页；其他两个枚举是单选弹窗；两项布尔值是即时开关。 |
| 平板界面 | `TabletUiMode`：自动／始终开启／横屏／关闭四项；改变后提示需要重启。原版自动按最短边与方向判断，HTML 使用 iframe 尺寸模拟，偏好在模拟重新打开后应用。 |
| 日期格式 | 空值默认、MM/dd/yy、dd/MM/yy、yyyy-MM-dd、dd MMM yyyy、MMM dd, yyyy，展示按当前语言格式化的日期示例。 |
| 单选弹窗 | `ListPreferenceWidget`：新值即时提交并收起；点击已选值不提交或收起；只有“取消”，没有“确定”。Escape／遮罩／取消保留原值并恢复焦点。 |
| 语言 | `AppLanguageScreen`：首项默认，其余由非空翻译资源生成，按各语言自称名称排序；显示自称名和当前语言下名称，选中尾随 Check；点击即时设置，留在语言子页。 |
| 默认与反馈 | `UiPreferences`：模式SYSTEM、纯黑false、平板AUTOMATIC、日期空值、相对时间true、简介图片true；主题默认取决于 Android 动态配色可用性。外层演示主题指令是显式覆盖，不能使页面选中与实际配色矛盾。 |
| 隔离与复用 | 应用内设置只改变当前设备；复用 `themes.js`、现有详情时间与简介渲染链路。外层演示主题可同时覆盖双端；浏览器重载重置的既有边界保留，不另建生产偏好存储。 |

## 用户验收

- [ ] **AP01 / 入口**：窄屏【更多 → 设置 → 外观】→ 显示外观顶栏与两组设置；返回设置、再返回更多，焦点回到原入口，根导航不挤占子页。
- [ ] **AP02 / 宽屏**：Windows 宽窗口【更多 → 设置】→ 左侧设置目录、右侧外观；两栏无分割线，滚动互不牵连；右侧主内容保持可达。
- [ ] **AP03 / 三段模式**：依次点击跟随系统、浅色、深色 → 唯一选中，颜色即时更新；系统模式响应浏览器深浅偏好变化，仅影响当前端。
- [ ] **AP04 / 主题卡**：横向滚动浏览主题列表 → 完整主题均有原版结构预览与名称；点击卡片 → 选中边框与勾选图标移动，当前端页面和弹窗立即采用配色，另一端不变。
- [ ] **AP05 / 纯黑条件**：深色开启纯黑 → 背景变黑；切浅色 → 整行开关隐藏但原值保留；切跟随系统 → 整行开关恢复可操作，实际覆盖随系统深浅；没有额外确认框。
- [ ] **AP06 / 外层一致性**：外层工具切主题／深浅／纯黑 → 两端外观页的选中项和开关同步；随后应用内选主题 → 只改变当前端。
- [ ] **AP07 / 平板弹窗**：打开平板界面 → 自动、始终开启、横屏、关闭四项，当前项单选；点击已选项弹窗保留；点击其他项立即关闭并提示重启，取消不会改值。
- [ ] **AP08 / 平板生效**：选择关闭 → 当前布局暂不变 → 外层选择该端【模拟重新打开】→ 再进入设置，为单栏；选择始终开启后模拟重新打开 → 双栏；自动和横屏按模拟设备尺寸／方向判断。
- [ ] **AP09 / 日期弹窗**：打开日期格式 → 六项按源码顺序显示日期示例 → 选择新项即时关闭，设置摘要更新 → 返回详情，章节日期使用选中格式。
- [ ] **AP10 / 相对时间**：日期格式改变后，相对时间戳说明使用当前日期格式 → 开关关闭显示绝对日期，开启显示适用的相对时间；旧日期仍用绝对格式。
- [ ] **AP11 / 简介图片**：关闭在漫画注释中显示图片 → 打开含本地图片的简介审阅样本，不显示图片 → 开启后显示；不影响简介文本或链接，不请求远程图片。
- [ ] **AP12 / 语言子页**：应用语言 → 默认加全部68种非空资源语言；当前项右侧勾选 → 选择English、简体中文等 → 留在子页，外观文字与日期语言即时更新，返回仍保留选中。其他既有 DEMO 样本文案的翻译范围见 README。
- [ ] **AP13 / 弹窗与键盘**：日期／平板弹窗 Tab 与 Shift+Tab → 焦点限于弹窗；Escape／遮罩／取消 → 只收起一层，焦点回触发项，不退出外观。
- [ ] **AP14 / 可达性**：Android 320px 与 Windows 宽窗口，浅色／深色／纯黑及200%字号 → 主题横向滚动、完整显示组、弹窗各选项与取消按钮均可到达，没有被底栏或固定容器遮挡。
