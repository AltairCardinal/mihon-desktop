# 分类与作品详情 UI 收敛验收（本轮目标）

本页验收 HTML 交互 DEMO，不代表 Desktop Compose 产品已变更。以下规则在实现前固定；已有 [完整详情差异清单](DETAIL-PARITY-ACCEPTANCE.md)继续用于检查功能是否可达。

来源：**SOURCE** 为原版 Mihon 的 `MoreTab/MoreScreen`、`CategoryScreen/CategoryListItem/CategoryFloatingActionButton/CategoryDialogs`、`ChangeCategoryDialog`、`MangaToolbar`、`MangaInfoBox/MangaActionRow/ExpandableMangaDescription` 与 `MangaCoverDialog`；当前 Desktop 的 `MangaDetailScreen` 用于确认应保留的单本阅读模式等桌面能力。**PROJECT_POLICY** 是保留已有 DEMO 功能及结果，同时按用户纠正将分类管理入口设在底部导航【更多】页面，不放入书架设置。**HTML_ADAPTER** 包括本地模拟结果、鼠标右键代替部分长按、HTML 拖动手柄及其 Alt+方向键键盘适配；原生像素与系统能力另行验收。

## 分类

- [ ] **CUI1** 底部导航【更多】→ 在“下载队列”和“统计”之间点击“分类”→ 独立“编辑分类”页面，顶栏有返回；书架顶栏及书架设置均无分类管理入口，返回后仍在【更多】。更多页其它条目只是本轮原型的范围提示，不代表其生产功能已接入。
- [ ] **CUI2** 分类页右下“添加”悬浮按钮 → 新建弹窗，名称输入自动聚焦；空名称或重名时确认不可用并显示对应提示；输入唯一名称后确认，新分类进入列表和书架分类标签。
- [ ] **CUI3** 点击分类卡片主体或编辑图标 → 重命名弹窗预填现名并聚焦；名称未变、为空或重名时确认不可用；改成唯一名称并确认后列表和书架标签同步改名，作品原所属分类不变。
- [ ] **CUI4** 按住卡片左侧拖动手柄重排自定义分类 → 列表和书架标签立即同序，模拟重新打开后仍在。Windows 可聚焦手柄后按 Alt+↑／↓ 排序作为 HTML 键盘适配；页面不显示原版没有的常驻上移／下移按钮。
- [ ] **CUI5** 分类页只列自定义分类；无自定义分类时显示空态，添加按钮仍可用。点击卡片删除图标 → 带分类名称的确认弹窗；取消不变，确认后作品不被删除，无其他所属分类的作品归入系统默认分类。
- [ ] **CUI6** 已收藏作品详情 → 顶栏“更多 → 编辑分类” → 对话框只列自定义分类；勾选并确定后重开，对应勾选状态保留，全部取消则归入默认。
- [ ] **CUI7** 详情分类对话框 → 改动勾选但不保存，点“编辑” → 先丢弃草稿、进入与【更多】相同的分类页面；返回后回到详情，重新打开时仍为原保存状态。无自定义分类时也有“编辑分类”入口。
- [ ] **CUI8** 分类页及新建／重命名／删除弹窗 → Escape、顶栏返回、取消各退一层且不产生未确认改动；弹窗关闭后焦点回触发按钮或分类卡片，双端预览互不抢焦点。

## 详情界面

- [ ] **DUI1** 打开作品 → 详情顶栏常驻返回、标题、下载、章节筛选和“更多”；刷新、编辑分类、迁移、分享、笔记不再各占一个常驻按钮。
- [ ] **DUI2** 顶栏“更多” → 逐一打开检查更新、编辑分类、迁移图源、分享链接和笔记 → 原有结果或本地模拟反馈仍可达；未收藏、本地、缺源作品不显示不适用的迁移或分享菜单项。
- [ ] **DUI3** “更多 → 全部标为已读” → 显示确认后更新章节状态；进入选章模式 → 顶栏改为已选数量、全选、反选、退出，章节筛选仍可操作。
- [ ] **DUI4** 左栏从上到下是封面／标题／作者／状态／来源、收藏／更新间隔／追踪／网页动作、笔记／简介／标签；分类状态和上次检查不再单列占位，分别从分类对话框和间隔对话框查看。
- [ ] **DUI5** 点击封面 → 大图查看器中有编辑封面菜单；替换、删除自定义封面后详情和书架封面同步变化，关闭查看器回到封面入口。
- [ ] **DUI6** 标题右键 → 复制反馈；作者／画师右键、标签单击 → 搜索或复制菜单；简介可展开并选中文本，右键复制。常驻复制小图标已移除。
- [ ] **DUI7** “更多 → 笔记” → 编辑、格式化、保存或取消；有笔记时摘要出现在简介上方，点摘要可再编辑；空笔记不占独立信息卡。
- [ ] **DUI8** 收藏、更新间隔、追踪、网页动作仍可直接使用；Desktop 单本阅读模式保留在信息区末尾。点击阅读模式 → 五个选项在宽窗口及 320px 窄窗口内完整显示且可点击，不被左侧滚动区域或底部导航遮挡；切换后在阅读预览回显。
- [ ] **DUI9** 宽窗口只滚动右侧章节 → 左侧封面不跟着滚动；左侧内容超长时可独立滚动但不显示滚动条。窄窗口变为单列，顶栏“更多”菜单完整位于视口内。
- [ ] **DUI10** 打开封面编辑菜单后按 Escape → 先收起菜单、再关闭查看器并恢复封面焦点；点关闭按钮或遮罩退出并重进查看器 → 编辑菜单不自动重开。关闭其它弹层后回到相应入口；并列预览中操作一端不重置另一端的分类、滚动或选择。

操作建议：在 [并列 DEMO](index.html) 选择 Windows，载入“基础书架 A–E”后打开 A；再分别载入“详情长简介与作品资料”“详情二百章长列表”“零章节与本地作品”等场景核对边界。勾选由人工审核完成，自动测试仅证明浏览器样本的行为。
