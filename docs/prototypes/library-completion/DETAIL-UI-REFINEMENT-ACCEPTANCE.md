# 分类与作品详情 UI 收敛验收（本轮目标）

本页验收 HTML 交互 DEMO，不代表 Desktop Compose 产品已变更。以下规则在实现前固定；已有 [完整详情差异清单](DETAIL-PARITY-ACCEPTANCE.md)继续用于检查功能是否可达。

来源：**SOURCE** 为原版 Mihon 的 `MoreTab/MoreScreen`、`CategoryScreen/CategoryListItem/CategoryFloatingActionButton/CategoryDialogs`、`ChangeCategoryDialog`、`MangaToolbar`、`MangaInfoBox/MangaActionRow/ExpandableMangaDescription`、`MangaCoverDialog`、`MangaScreenLargeImpl`、`TwoPanelBox`、`MangaBottomActionMenu/SharedMangaBottomActionMenu`、`ChapterHeader` 与 `MangaChapterListItem/ChapterDownloadIndicator`；当前 Desktop 的 `MangaDetailScreen` 仅用于确认保留不冲突的桌面能力。**PROJECT_POLICY** 是保留已有 DEMO 业务结果，但按用户要求移除详情页阅读模式控件与顶栏“全部标记为已读”入口，并将分类管理放在【更多】。**HTML_ADAPTER** 包括本地模拟结果、鼠标右键代替部分长按、HTML 拖动手柄及其 Alt+方向键键盘适配；原生像素与系统能力另行验收。

## 分类

- [ ] **CUI1** 底部导航【更多】→ 在“下载队列”和“统计”之间点击“分类”→ 独立“编辑分类”页面，顶栏有返回；书架顶栏及书架设置均无分类管理入口，返回后仍在【更多】。更多页其它条目只是本轮原型的范围提示，不代表其生产功能已接入。
- [ ] **CUI2** 分类页右下“添加”悬浮按钮 → 新建弹窗，名称输入自动聚焦；空名称或重名时确认不可用并显示对应提示；输入唯一名称后确认，新分类进入列表和书架分类标签。
- [ ] **CUI3** 点击分类卡片主体或编辑图标 → 重命名弹窗预填现名并聚焦；名称未变、为空或重名时确认不可用；改成唯一名称并确认后列表和书架标签同步改名，作品原所属分类不变。
- [ ] **CUI4** 按住卡片左侧拖动手柄重排自定义分类 → 列表和书架标签立即同序，模拟重新打开后仍在。Windows 可聚焦手柄后按 Alt+↑／↓ 排序作为 HTML 键盘适配；页面不显示原版没有的常驻上移／下移按钮。
- [ ] **CUI5** 分类页只列自定义分类；无自定义分类时显示空态，添加按钮仍可用。点击卡片删除图标 → 带分类名称的确认弹窗；取消不变，确认后作品不被删除，无其他所属分类的作品归入系统默认分类。
- [ ] **CUI6** 已收藏作品详情 → 顶栏“更多 → 编辑分类” → 对话框只列自定义分类；勾选并确定后重开，对应勾选状态保留，全部取消则归入默认。
- [ ] **CUI7** 详情分类对话框 → 改动勾选但不保存，点“编辑” → 先丢弃草稿、进入与【更多】相同的分类页面；返回后回到详情，重新打开时仍为原保存状态。无自定义分类时也有“编辑分类”入口。
- [ ] **CUI8** 分类页及新建／重命名／删除弹窗 → Escape、顶栏返回、取消各退一层且不产生未确认改动；弹窗关闭后焦点回触发按钮或分类卡片，双端预览互不抢焦点。

## 详情界面

- [ ] **DUI1** 打开作品 → 详情顶栏常驻返回、标题、下载、章节筛选和“更多”；刷新、编辑分类、迁移、分享、笔记不再各占一个常驻按钮。
- [ ] **DUI2** 顶栏“更多” → 逐一打开检查更新、编辑分类、迁移图源、分享链接和笔记 → 原有结果或本地模拟反馈仍可达；未收藏、本地、缺源作品不显示不适用的迁移或分享菜单项。
- [ ] **DUI3** 顶栏“更多”不再出现“全部标记为已读”；进入选章模式 → 原版动作栏取代常规顶栏：左侧单个关闭图标、纯数字选中数，右侧仅全选与反选图标；作品标题、下载、筛选、更多和重复的退出按钮不显示。点击左侧关闭或按 Escape 只退出选择、不返回书架；执行“全选当前可见章节 → 批量标为已读”后适用章节状态更新，未选章节不受影响。退出选择后常规顶栏恢复。
- [ ] **DUI4** `TwoPanelBox` 的原版公式是左栏 `min(可用宽度/2, 450dp)`，封面是左栏扣除 16dp 两侧内边距后宽度的 65%；本 HTML Windows 审阅窗以 `min(可用宽度/2, 360 CSS px)` 表达视觉比例，360 是 450dp × 0.8 的 **HTML_ADAPTER**，不是原版常量。右栏用剩余宽度，封面居中且标题／作者／状态／来源在下方居中；窄窗口封面与资料按原版小屏并排。Windows 封面比例保留 7:10、Android 为 2:3，这属于本项目平台事实。
- [ ] **DUI5** 点击封面 → 大图查看器中有编辑封面菜单；替换、删除自定义封面后详情和书架封面同步变化，关闭查看器回到封面入口。
- [ ] **DUI6** 标题右键 → 复制反馈；作者／画师右键、标签单击 → 搜索或复制菜单；简介可展开并选中文本，右键复制。常驻复制小图标已移除。
- [ ] **DUI7** “更多 → 笔记” → 编辑、格式化、保存或取消；有笔记时摘要出现在简介上方，点摘要可再编辑；空笔记不占独立信息卡。
- [ ] **DUI8** 详情信息区不再出现“阅读模式”控件；收藏、更新间隔、追踪、网页动作仍可直接使用。进入阅读预览仍有明确模式状态与切换路径；展开模式菜单后返回详情、再次进入阅读预览，菜单应保持收起，不回放上次会话的弹层。
- [ ] **DUI9** 宽窗口只滚动右侧章节 → 左侧封面不跟着滚动；左侧内容超长时可独立滚动但不显示滚动条，两栏之间及详情顶栏下方均没有额外可见分割线，分栏宽度遵守 DUI4。窄窗口变为单列，顶栏“更多”菜单完整位于视口内。
- [ ] **DUI10** 打开封面编辑菜单后按 Escape → 先收起菜单、再关闭查看器并恢复封面焦点；点关闭按钮或遮罩退出并重进查看器 → 编辑菜单不自动重开。关闭其它弹层后回到相应入口；并列预览中操作一端不重置另一端的分类、滚动或选择。
- [ ] **DUI11** 章节标题按原版简中资源显示当前处理后章节数（例如“共 3 章”），不显示“3/3”式分数；有缺章时在标题下单列“缺少 N 章”提示。改变章节筛选后计数随当前可见章节变化，零章节时显示“共 0 章”。
- [ ] **DUI12** 未读章节在标题前显示主色小圆点；已读章节通过标题／副标题弱化表示，不在行尾常驻勾号；只有已书签章节在标题前显示实心书签，未书签章节不常驻空心书签。下载状态使用行尾单一指示：未下载为圆圈内向下箭头、排队／下载中为单一进度环、已下载为实心勾选圆、失败为错误标记；点击相关状态后原有下载、取消、重试和删除结果仍可达。本地作品或选章时，行尾标记保持可见但不可触发。
- [ ] **DUI13** 无实际汉化／译制组字段的章节 → 副标题只显示可得日期与阅读进度，没有“示例汉化组”“未知译制组”或多余分隔点；章节筛选及排除组对话框不凭空造组名。有实际组名的更新场景 → 组名显示在副标题并可用于筛选。
- [ ] **DUI14** 打开作品详情 → 根 Tab 导航不占页面底部，返回书架后恢复。宽屏选中章节 → 顶栏遵守 DUI3，章节行仅用原版选中背景而不加常驻复选框，章节计数入口不可用、继续阅读 FAB 隐藏、刷新不会在选择中触发；底部贴详情页底边的右半栏浮出圆角操作容器，默认只有图标而无横排文字；长按图标短暂显示操作名，键盘与鼠标仍可获取名称。书签、取消书签、标为已读、标为未读、标记之前、下载、删除按原版所选章节状态分别出现，排队中／下载中的章节仍显示下载图标但执行批量动作时不重复入队；窄屏底栏铺满可用宽度。改变选择数、切换已读／书签／下载状态、退出选择后，顶栏和底栏即时一致地更新，既有批量操作结果不丢失；关闭选择、反选至零或操作完成后的键盘焦点回到可见控件。

操作建议：在 [并列 DEMO](index.html) 选择 Windows，载入“基础书架 A–E”后打开 A；再分别载入“详情长简介与作品资料”“详情二百章长列表”“零章节与本地作品”等场景核对边界。勾选由人工审核完成，自动测试仅证明浏览器样本的行为。
