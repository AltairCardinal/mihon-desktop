# Mihon Desktop 作品详情页：现状基线与本次变化验收

本页先用 D01–D20 审核**当前 Desktop 详情页**的还原，再用 D21 起审核叠加在该基线上的 [书架 roadmap](../../roadmap/2026-09-28-desktop-library-completion-roadmap.md) 变化。勾选只表示认可本地 HTML 交互，不表示 Kotlin 产品功能落地，也不把 HTML 像素尺寸当作 Compose 实测。建议在 [并列 DEMO](index.html) 选择 Windows，载入“基础书架 A–E”，单击作品进入详情；每组变化最好重新载入相应场景。

## 来源与边界

- **SOURCE**：[MangaDetailScreen.kt](../../../app-desktop/src/main/kotlin/mihon/desktop/ui/library/MangaDetailScreen.kt) 定义顶栏、动作、对话框、阅读模式、章节列表、底栏和继续阅读 FAB；[MangaDetailComponents.kt](../../../app-desktop/src/main/kotlin/mihon/desktop/ui/library/MangaDetailComponents.kt) 定义封面信息、动作行与章节行；[MangaDetailChapterListItems.kt](../../../app-desktop/src/main/kotlin/mihon/desktop/ui/library/MangaDetailChapterListItems.kt) 定义章节数标题及列表组装。当前章节选择状态只有切换、全选与清除；章节 Shift 范围和反选不是现有产品功能。
- **PROJECT_POLICY**：D21 起叠加的 L02、L08、S06 是书架 roadmap 的目标行为。书架页的 Ctrl 多选、Shift 范围、Ctrl+滚轮切分类和双段顶部刷新沿用本 DEMO 已审核的目标规则；这些规则不能反推到现有详情页的章节选择。
- **HTML_ADAPTER**：本地样本、生成封面、浏览器 CSS 和弹窗用于审核结构与状态。外链、系统分享、文件选择、追踪、扩展源迁移、真实下载和阅读器由本地模拟或说明代替；最终命中区域、字体、系统窗口与异步结果仍以原生 Desktop 验收为准。没有源码显式尺寸的顶栏及章节行，不以 DEMO 的 px 宣称生产尺寸。

## 现状基线：视觉与层级（D01–D20）

- [ ] **D01**：书架单击作品 → 顶栏显示返回、当前作品标题和详情动作；返回后保持原书架分类、滚动与筛选。
- [ ] **D02**：封面位于信息块左侧，Desktop 容器比例为 7:10；封面右下是编辑入口。标题、作者／画师、状态与来源、简介、标签按现有组件顺序显示；简介最多六行。
- [ ] **D03**：封面信息块下面依次是收藏等作品动作、单本阅读模式、章节数标题和章节列表；继续阅读是右下 FAB，只在有可继续章节且未选章时出现。
- [ ] **D04**：章节行标题与次要信息、书签、下载状态和阅读指示分区清晰；已读章节文字弱化，已选章节有选中底色及复选框；窄窗口可滚达所有操作。
- [ ] **D05**：深色与浅色主题分别检查上述布局；封面比例不随主题或窗口宽度改变。

## 顶栏与作品操作

- [ ] **D06**：顶栏下载菜单 → 可看到“后续 1/5/10/25 章、全部未读、未读且已书签”等当前动作；选择后有可见队列反馈。
- [ ] **D07**：有 HTTP 链接的作品显示打开、复制、分享；无链接时不显示不适用动作。HTML 对系统能力给出明确本地演示反馈。
- [ ] **D08**：“全部标为已读” → 先出现带章节数量的确认，取消不改状态，确认后章节已读状态与继续阅读入口同步变化。
- [ ] **D09**：刷新显示结果或进行中反馈；迁移、笔记入口可打开对应当前页面语义的面板，不会直接改变章节或收藏。
- [ ] **D10**：封面编辑图标 → 下拉菜单含替换、删除；替换后详情和书架封面一致，删除恢复当前源封面。
- [ ] **D11**：标签点击用于搜索，标签尾部复制为独立动作；作者／画师可点时能辨认其入口。演示数据没有身份或源服务时，反馈明确。
- [ ] **D12**：作品动作行可切换“在书架／加入书架”，并有分类、抓取间隔、追踪及适用时的外链动作；取消弹窗不保存，确认后的状态在当前详情可见。
- [ ] **D13**：单本阅读模式提供默认、自动、从左到右、从右到左、条漫，选择后当前值立即更新。

## 章节列表与选择

- [ ] **D14**：章节筛选菜单 → 已读、未读、仅书签、仅下载、扫描组排除能改变当前可见列表；标题显示“可见数/总数”，不删除被隐藏章节。
- [ ] **D15**：同一菜单可选来源顺序、章节号、上传日期、字母排序；再次选择当前排序方向反转，箭头反馈方向；标题／章节号显示模式即时更新。
- [ ] **D16**：未选章时单击章节进入本地阅读预览；长按章节进入选章模式。选章后普通单击其他章节增减选择，不打开阅读器。
- [ ] **D17**：选章时顶栏可全选当前可见章节或关闭选择；底栏显示选中数量及书签、标已读、标未读、标此处及以下已读、下载／删下载和关闭动作。操作结束反馈可见。
- [ ] **D18**：选章时继续阅读 FAB 消失；取消最后一个所选章节退出选择，FAB 按剩余未读状态恢复。章节 Shift 范围或反选不作为当前页面验收项。
- [ ] **D19**：单章书签按钮独立切换；下载按钮按未下载、排队／下载中、错误、已下载展示对应动作，删除已下载文件先确认；阅读指示区分未读、进度和已读。
- [ ] **D20**：空章节、筛选后零可见章节、更新失败样本有清楚的列表状态；不显示可启动的假继续阅读按钮。

## 本次叠加：详情页直接可见的 Roadmap 变化（D21–D34）

这部分只针对真正改变详情体验的 **L02 封面、L08 目录变化、S06 作品信息**。上方的返回、顶栏菜单、章节普通点击、长按选章和 FAB 是现状基线，不要把它们重复算作本次新功能。其余 16 项书架/设置目标和操作编号见[总验收清单的变化对照](ACCEPTANCE.md)。

| Roadmap 项 | 当前 Desktop 基线 | 本次叠加目标 |
| --- | --- | --- |
| L02 | 详情已有封面编辑，但书架封面请求未完整复用自定义封面和版本变化。 | 详情与四种书架布局共用当前生效封面；自定义优先，源封面同地址变化后有新版本。 |
| L08 | 目录更新主要处理新增章节；改名、源顺序、移除和可识别换链的状态承接不完整。 | 详情能看见完整差异；重复刷新不虚报新增，阅读/书签/下载身份不因重排与换链丢失。 |
| S06 | 当前请求固定不抓取作品详情。 | 用户明确开启后才刷新简介与源封面；默认关闭，已保护标题和自定义封面仍不被覆盖。 |

- [ ] **D21 / L02 自定义封面跨页**：载入“自定义封面”场景 → 详情封面右下编辑菜单替换 → 返回书架轮流检查四布局 → 同一本均显示这次替换；重进详情仍是同一封面。当前详情原有编辑入口保持原位。
- [ ] **D22 / L02 优先级**：已有自定义封面 → 外层模拟源封面变化 → 详情及书架仍显示自定义版本；从详情删除自定义封面 → 两处一起切换到最新源封面，不恢复旧缓存。
- [ ] **D23 / L02 同地址版本**：没有自定义封面时连续模拟源封面修订 → 详情和书架都能看出版本变化；封面容器比例保持 Desktop 7:10。
- [ ] **D24 / L08 新增与计数**：载入“目录增删改与换链”场景 → 从详情点检查更新 → 章节 4 新出现、章节 2 消失，章节标题和书架计数按结果重算；本样本一增一减，总章节数仍是 3，不应虚报为 4。更新结果只把真正新章节计为新增。
- [ ] **D25 / L08 更名及源顺序**：同次更新后检查章节 3 的标题变化，再在章节菜单切换“源顺序／章节号” → 源重排与数字排序得到可辨认的两种顺序；切回源顺序不还原旧目录。
- [ ] **D26 / L08 可识别换链及进度**：更新前第 1 话有已读、书签和下载，第 3 话显示阅读进度 → 更新结果说明可识别链接替换；第 1 话仍保留原章节身份与三种状态，第 3 话更名后仍显示第 5 页。现有章节行不直接展示 URL，不为 DEMO 凭空添加这一字段。
- [ ] **D27 / L08 移除不删文件**：同次更新后第 2 话从章节列表消失 → 详情明确列出仍保留的本地下载身份；不自动把用户下载当作无效文件删除。
- [ ] **D28 / L08 重复检查**：目录已经同步后再次点详情“检查更新” → 结果不再虚报“新增 1”，章节 ID/顺序/下载身份稳定，不复制第 4 话。
- [ ] **D29 / L08 异常响应**：重载空目录及畸形目录场景，各从详情刷新 → 有可读失败原因，原章节标题、数量、书签和下载仍在，不能把空响应当成用户清空目录。
- [ ] **D30 / L08 单本提交失败**：目录保存失败场景从详情刷新 → 当前作品旧目录完整保留，其他作品既有状态不受影响；恢复源后按本次真实样本响应重试，成功反馈不伪造新章节。
- [ ] **D31 / L08 中断及文件关联**：目录提交后中断或下载文件关联失败场景 → 结果说明哪个阶段未完；恢复/重试只补剩余阶段，详情不重复新增章节，下载身份最终保留。
- [ ] **D32 / S06 默认关闭**：书架设置“刷新作品信息”保持关闭 → 从详情检查更新 → 简介和源封面版本不因目录检查擅自改变；章节仍可按 L08 更新。
- [ ] **D33 / S06 明确开启**：书架设置打开“刷新作品信息” → 返回详情检查更新 → 简介与源封面版本在详情立即变化；返回书架封面同步变化，关闭设置后后续更新不继续改这些信息。
- [ ] **D34 / S06 用户保护**：载入自定义封面场景（标题按样本设为受保护）→ 开启作品信息刷新并更新 → 章节及允许刷新的简介变化，标题与自定义封面仍保留；删除自定义封面才显示最新源封面。

上述条目供用户手动审核，暂不替用户勾选。自动浏览器测试验证本地 DEMO 的行为接线；SQLDelight、文件重命名、真实图源响应及原生运行仍属于产品 roadmap 的验收。
