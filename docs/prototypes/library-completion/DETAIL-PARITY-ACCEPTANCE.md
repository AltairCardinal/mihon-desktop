# 作品详情页完整差异：交互 DEMO 验收

入口：[Windows / Android 并列 DEMO](index.html)。在应用外选择“基础书架 A–E”，然后在 Windows 书架单击「A · 星海手记」。每组验收建议重新载入场景。下方复用上一轮源码审计的 A1–I4 编号；同一编号的多个操作须全部成立才算通过。

本页审核的是目标交互。**SOURCE** 是原版 Mihon `deb7b33118` 与当前 Desktop `2a8ced5581` 的详情源码；**PROJECT_POLICY** 是审计后的“对齐业务语义、保留 Windows 入口及 Desktop 独有能力”决定；**HTML_ADAPTER** 是本地章节、源、追踪、迁移及文件操作样本。按钮的结果必须在页面中可见；“本地模拟”不得让用户误以为发生真实下载、联网、磁盘删除或账号修改。原有 [详情现状和书架 roadmap 验收](DETAIL-ACCEPTANCE.md) 保留为历史基线。

- [ ] **A3** 长按或 Ctrl 选择章节 → 顶栏显式进入选择状态、显示数量和全选/反选，作品级动作不会被误认为对所选章节执行。

- [ ] **A6** 宽窗口右侧章节列表回到顶部后继续向上滚动 → 先有刷新提示再真正刷新；左侧信息区滚动不误触发；多选时不触发；顶栏刷新仍可用。窄窗口由整页顶部触发。

## 下载与阅读

- [ ] **F1** “接下来 1/5/10/25 章”按当前阅读顺序，从未读且未下载的适用章节中取数；已下载项不会占用数量。
- [ ] **F2** “下载书签章节”包含已读但有书签的章节；只跳过已下载/不可下载项。
- [ ] **F3** 打开“下载是否跳过当前筛选”偏好，切换当前筛选后执行同一下载动作 → 工作集随偏好变化；反馈说明范围。
- [ ] **F4** 对未下载、排队、下载中的章节打开右键菜单 → 可立即/优先下载或取消，队列反馈可见。
- [ ] **F5** 对未收藏作品发起下载 → 非阻塞提示可加入书架；不强制收藏也能继续模拟下载。
- [ ] **F6** 本地作品/失效源样本 → 无意义的下载入口禁用或说明原因；已在本地的章节仍可进入阅读。
- [ ] **F7** 章节右键菜单可切换已读、书签和下载状态；鼠标操作覆盖原版滑动能力，且不改变单击阅读规则。
- [ ] **F8** 未读点、阅读进度环、已读勾容易区分；“继续阅读”入口明确命名，点击后进入对应章节而非误标已读。
- [ ] **F9** 启用仅下载/书签/未读筛选后点“继续阅读” → 目标是当前可见叙事顺序的下一未读章；没有目标时按钮隐藏。
- [ ] **F10** 在详情设置作品阅读方向 → 阅读预览显示当前模式；返回详情仍为该值。
- [ ] **F11** 外层载入“同步阅读进度与页码”→ 打开 A → 第 3 话显示同步至第 13 页，“继续阅读”进入同章节第 13 页；另载入“详情缺失图源与外部章节”→ 第 3 话打开明确的本地浏览器预览，且不能加入普通下载。
