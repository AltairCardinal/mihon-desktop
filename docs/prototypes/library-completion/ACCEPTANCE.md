# 书架完整 Roadmap：交互审核清单

本清单对应 [产品 roadmap](../../roadmap/2026-09-28-desktop-library-completion-roadmap.md) 的全部 19 项需求，并在 I05 中补充本轮书架工具栏、导航和页面结构调整。勾选表示审核者认可本地 HTML 中的交互，不代表 Kotlin 产品实现、数据迁移或原生设备验收完成。每个场景从外层工具栏重新加载，避免前一场景的筛选、选择或设置影响结果。

## 审核方法

打开 [并列 DEMO](index.html)。外层工具用于选择目标端、加载样本、模拟故障/时间/设备条件；iframe 内是拟议产品操作。先按 Windows 流程审核，再对 Android 检查相同业务结果。Windows 的 Ctrl 操作仅在 Windows 端适用；Android 使用长按和选择模式。

以下是固定验收目标。条目保持未勾选，供用户审核；自动测试的实际结果另记在 [README](README.md)，不能据此自动勾选用户意见。

## 本次变化对照：现状基线 → Roadmap 目标

下表的“现状”采用 [roadmap 冻结的 Desktop 缺口](../../roadmap/2026-09-28-desktop-library-completion-roadmap.md)，属于 **SOURCE** 索引，不把 HTML 模拟当作原生产品现状；“叠加后”是 **PROJECT_POLICY** 目标。右列指向下方可操作的 **HTML_ADAPTER** 验收项。尤其要区分：详情页原本已有封面编辑、章节点击/长按/全选和阅读 FAB；本次变化主要在书架显示、更新规则及结果，不会凭空给现有详情章节增加 Shift 范围或反选。

| 需求 | 现状基线 | 本次叠加后要审核的变化 | 操作条目 |
| --- | --- | --- | --- |
| L01 滚动定位 | 书架普通滚动容器缺少可拖动的快滚条。 | 四种布局都有可拖动滚动条；按分类记住位置，详情返回仍能回原处。 | A01–A02 |
| L02 封面 | 详情可编辑封面，但书架的封面请求只用图源 URL/ID，同地址更新及自定义封面不一定同步。 | 详情替换/删除后四布局立即使用同一封面；自定义优先，删除后显示最新源版本。 | A03–A04、[详情叠加](DETAIL-ACCEPTANCE.md) |
| L03 继续阅读 | 书架继续按钮资格与未读角标投影耦合。 | 隐藏角标仍可从真实未读章节继续；已读完和多选状态不产生错误阅读动作。 | A05–A06 |
| L04 评分 | 不同追踪服务的原始分数直接平均，量纲混用。 | 换算为十分制再排序/平均，无评分明确区分。 | A07 |
| L05 追踪筛选 | 服务以数字 ID 呈现，追踪过滤生效时顶栏提示不完整。 | 单服务显示“已追踪”，多服务显示名称；包含/排除及生效状态可见。 | A08–A09、B03 |
| L06 分类标签 | 仅在分类数大于一时显示标签。 | 唯一自定义分类仍显示；唯一系统默认分类不强加标签，显示开关仍生效。 | A10 |
| L07 更新容错 | 一部作品失败会中断后续更新；结果难以定位和重试。 | 其他作品继续，摘要区分成功/失败/跳过；仅重试失败，取消/恢复保留既有进度。 | F01–F06 |
| L08 章节变化 | 更新主要处理新增章节。 | 同一目录的新增、改名、重排、移除和可识别换链正确呈现；阅读/书签/下载身份承接，异常响应不清库。 | F07–F11、[详情叠加](DETAIL-ACCEPTANCE.md) |
| S01 默认分类 | 入库逻辑已有偏好读取，书架设置缺少可操作入口。 | 可选每次询问、系统默认或自定义分类；只影响后续入库，删除分类有回退。 | E01–E02 |
| S02 更新分类 | 更新设置主要只能排除自定义分类。 | 系统默认与自定义分类均可包含/排除；排除优先，草稿确认一次保存，失败回滚。 | E03–E06 |
| S03 更新周期 | 周期选项缺少 48/72 小时。 | 增加 48/72 小时且保留 6 小时；到期、重启及时间回拨不重复调度。 | G01–G02 |
| S04 智能限制 | 已追平、已开始、未完结、预计更新期等偏好未完整影响更新候选。 | 自动和手动更新均按作品条件决定处理/跳过，并展示原因；零章节和本地图源按各自规则处理。 | G03–G05 |
| S05 设备条件 | Windows 自动更新缺少 Wi-Fi、非计量和供电限制的真实等待链。 | 仅自动任务受选中条件约束；条件未知时等待，恢复后继续原任务；手动操作可绕过设备门槛。 | G06–G09 |
| S06 作品信息 | 目录更新固定不抓取作品详情。 | 设置中按需开启作品信息刷新；默认关闭，已保护标题和自定义封面仍保留。 | G10–G11、[详情叠加](DETAIL-ACCEPTANCE.md) |
| S07 分类排序 | 关闭按分类设置后，旧分类排序可能在重开时复活。 | 关闭时清理旧分类排序；失败或中断有恢复反馈，全局显示偏好不受影响。 | E07–E08 |
| I01 分类手势 | 当前 Desktop 未接入本次目标的 Ctrl+滚轮分类操作；先前 DEMO 方案曾使用 Ctrl+方向键。 | 根书架 Ctrl+滚轮切相邻分类，首尾不循环；输入、弹层、详情和 Android 不接管。 | C01–C03 |
| I02 顶部刷新 | 滚到顶部后继续滚动缺少可审的提示与确认步骤。 | 第一次额外向上滚只提示，新的第二段才刷新当前完整分类；取消、超时和冷却不误发任务。 | D01–D08 |
| I03 多选 | 当前 Ctrl 未进入书架选择链；原 Shift 范围采用追加并移动锚点。 | 未选时单击打开，选中后单击增减；Ctrl 增减、Shift 固定锚点替换、Ctrl+Shift/长按追加；跨类及锚点失效有规则。 | C04–C14 |
| I04 统一面板 | 筛选、排序、显示分散在多个入口。 | 一个三标签面板即时生效；再次点击书架可重开，Escape 分层退出并恢复焦点。 | B01–B13 |
| I05 书架顶部操作 | 更新全部、更新分类、随机打开和书架设置散落于顶部。 | 搜索与筛选在前、同步第三、【更多】最后；更新与随机打开进入更紧凑的【更多】菜单；移除独立书架设置按钮。 | N01、N03–N04、N09 |
| I06 宽屏导航 | 窄屏式底部导航在宽窗口仍占底部空间。 | 宽窗口使用与 Mihon `NavigationRail` 几何一致的左侧栏；窄窗口保留底部导航，主入口次序与上游一致。 | N02 |
| I07 更多页结构 | 【更多】页入口层级与原版分组不同。 | 品牌标识、两个开关及下载／分类／统计／数据存储／设置／关于／帮助按 Mihon 分组；依用户要求不显示捐赠。 | N05–N06 |
| I08 作者导航 | 作者是根级导航项。 | 作者作为【浏览】的第二个子页签，不再占用主导航位置。 | N07–N08 |

## D. 顶部继续滚动刷新（I02）

- [ ] **D01**：内容中部向上滚至顶部 → 仅滚动，不立即更新；继续向上才出现“继续向上滚动，准备刷新当前分类”。
