# 作品详情按钮与作品级读完即删

本页记录实现边界，供维护使用。Android 平板候选的验收范围见双语变更历史。

## 共享组件与平台接线

`presentation-manga` 的 `DetailActionStrip` 由 Android `MangaActionRow` 和 Desktop
`MangaDetailActionRow` 消费。平台提供已有业务回调、图标和本地化资源；共享层负责布局偏好、
长按、物理左右手势和两个确认对话框，不执行下载文件删除，也不新增导航 owner。

## 审定原型与原生交互

操作带采用 `docs/prototypes/manga-detail-actions/` 的末尾排序入口。现有平台业务动作和可用性仍由各宿主提供。

首屏显示完整顺序中的前四个可用动作，收藏也可排到后面。最后一个槽位为「排序」，采用 Material Symbols 的方框铅笔图标，用竖线与业务动作分隔，随列表直接滚入视野。该入口可点按打开排序面板，长按和松手不执行打开或拖排，也不参与保存的业务动作顺序。

Desktop 使用鼠标滚轮或两侧常驻箭头分页，末页边界截断。每段滚轮输入只翻一页，300ms 无输入后接受下一段；修饰键滚动不消费。箭头与操作按钮等高，在各自方向到头时置灰。居中圆点表示当前页。普通鼠标拖动不移动列表。
Android 使用连续水平滑动和居中进度条，反向拖动立即回滚。主按钮栏和排序预览在松手后按最后拖动方向减速停靠到完整按钮，甩动速度可以带出更多按钮，列表首尾截断；再次按下会立即中断惯性。只有在真实边缘继续向外拉才出现浅弧，最大伸入 9 dp，弧高为栏高的 65%，主题色叠层不超过 15%。拉动接近上限时增长放缓，松手或取消后收回。滚动、翻页和排序自动滚动共用 `DetailActionMotionState` 里的边界。

双端长按业务按钮后直接在原栏拖排，靠近边缘可自动滚动。拖动底色在按钮的 13 dp 圆角内淡入淡出，图标、文字和尺寸沿用静止状态。松手提交完整顺序，取消不写入，写入失败保持原顺序并显示错误。点按「排序」打开沿用的单列面板，保留草稿预览、无障碍移动和保存／取消。

`MangaDetailPreferences.layout()` 沿用原本机键 `manga_detail_primary_actions`，完整顺序成为当前UI的唯一排序依据。格式仍为 `旧成员枚举逗号列表|顺序枚举逗号列表`；旧成员投影只为兼容保留，UI不据此隐藏动作。无分隔符的旧数据兼容读取，未知项过滤、重复去重、缺失动作追加。布局跨本机作品通用，不进入作品同步协议。

## 删除规则与安全边界

`DownloadPreferences.mangaDeletionSettings(mangaId)` 提供跟随全局、开启、关闭三态，默认跟随全局。开启时显示既有设置的刚读完／倒数第2至第5章选择和允许删除书签开关；弹窗不显示额外说明文字。每次更改原子写入模式、保留位置和书签权限，立即生效；关闭面板保留已写入的设置。格式为 `MODE|slots|bool`，兼容原来的单枚举字符串（默认0章、禁止删除书签）。旧 `mangaDeletion()` 作为模式投影仍可读写，修改模式保留其它选项。
该规则是按数据库作品 ID 隔离的本机状态，键带 `Preference.appStateKey` 前缀，双端标准偏好
备份创建和恢复均排除它。它不添加同步字段或数据库迁移；不能将其当成跨设备可移植的作品身份。

规则在后续阅读完成时被读取。更改偏好不会立即删除已下载文件。
模式以平铺单选呈现。选择「开启」后，保留位置和书签开关显示在模式选项下方。共享面板管理设置更新，平台提供外层面板及复用的设置控件。每次修改即时提交，写入失败时显示错误，保留上次成功设置。
双端开启时解析作品的0至4个保留位置及书签权限，关闭解析为禁用，跟随全局精确保留现有保留章节数及书签开关；仍经过原有
进度成功提交、完成计划、下载管理器分类及书签过滤、待删队列与关闭阅读器清理流程。
Desktop 保留当前主干的完成结算与关闭阅读器清理边界；在完成时按当前章节的作品ID解析覆盖。仅实际到末页并成功提交进度后捕获有限清理对象，释放阅读资源、关闭阅读器后仍沿既有分类／书签／占用／generation保护删除。已经读过但本次未到末页不能提前删。作品书签开关只影响阅读完成的清理；手动标记已读或直接删除继续沿原有全局策略，不被作品设置改变。分类排除条件不被作品设置覆盖。

本次不重写主干已有的全局删除设置或延迟清理，不新增历史已读扫描、后台定时器或重试策略。新候选基于含迁移46的主干，避免旧分支候选降级数据库。
