# 双端阅读模式设置

交互基线为已审批的 [双端原型](../prototypes/reader-mode-default/README.md)。原型只确认设计；原生实现的验证以 Android 与 Desktop 的 production/wiring 测试为准。

## 状态与持久化

`domain` 的 `ReaderSettings` 是双端共同的设置契约。阅读模式分为横向与纵向；横向包含自动/单页/双页及左右方向，纵向包含连续/逐页及连续页面间隙。隐藏的方向、布局、间隙和双页自动匹配值保留，不因切换界面分支而重置。

作品仍通过 `Manga.viewerFlags` 保存，不引入数据库列或另一个作品配置存储。`ReaderSettingsCodec` 负责有效值、单独设置快照和默认继承之间的转换；平台负责将它接入已有偏好、reader viewer 和保存链路。选择默认时 active mode 为零，完整自定义快照保留；恢复单独设置时由同一快照产生 active mode。默认摘要展示有效值，不能展示隐藏自定义值。

全局偏好保留旧模式和匹配键作为有效值权威，另外保存完整快照以保留隐藏选项。Android 的隐藏快照键为 `reader_default_settings_snapshot`，Desktop 为 `reader_settings_snapshot`；读取时将旧模式/匹配键叠加到快照，写入时同步更新。这些平台偏好适配不改变共享作品 flags 的格式；首次启用单独设置可用默认值初始化，之后全局默认的修改不会覆盖已保留的作品自定义快照。

快照占用 flags 的位 6–12，存在标记为位 18。原来的模式位 0–2、方向锁定位 3–5、Desktop 旧布局位 32/33、旧自动位 34 及无关位均按各自契约处理。新增自动从左向右使用位 29 加低位模式 1；双页从左向右继续使用位 30 加低位模式 1。新增配置均能通过 Android 现有 Int 备份格式保存。旧客户端不理解新增模式时仍能回退为单页 LTR。

快照布局编码固定为 AUTO=0、SINGLE=1、DOUBLE=2；不可通过重排枚举改变已有编码。后续新增字段或编码必须先用旧 flags 夹具验证兼容，不能占用已有模式、方向锁定或扩展标记位。

没有快照的旧数据按实际模式懒转换：1/2 为横向单页，3 为纵向逐页，4 为纵向连续无间隙，5 为纵向连续有间隙，6/8 为横向双页，7/9 为横向自动。旧 Desktop 布局覆盖继续保留；旧 mode 0 加布局覆盖沿用原来的默认阅读模式，默认纵向时布局只作为隐藏值保留，不强制转为横向。快照与 active mode 不一致时，以 active mode 的显式字段为准，保留其余隐藏字段，兼容快捷模式入口和旧版本的模式更新。

## 原生边界

Android 复用已有 pager、vertical pager、webtoon viewer 和共享自适应布局。Desktop 的纵向逐页必须使用真实竖向 pager，不能将 flags 3 降级为横向单页。双端的匹配与间隙来自有效设置，不能只改变控件选中态。

Desktop 的 `initialReaderSettings` 是启动投影与完整 `ReaderScreenModel` 的唯一设置解析入口。`ReaderFirstComposition` 接受晚到页表前，按完整有效设置重新校验，不能只比较旧全局单双页/匹配字段。提前请求设置沿主干既有链路解锁完整模型；页表到达后继续保留已选择的设置和作用域。纵向逐页不进入横向单页启动视图，保留原有 early 输入、当前页需求及图片交接机制。

横向没有从上到下选项。自动与双页显示匹配选项，单页隐藏；连续纵向显示页面间隙开关，逐页隐藏。开关不附加是/否文字，辅助技术仍读取 checked 状态。图标沿用原型的 24×24 细线图形与主题颜色。逐页图标改编自 Lucide `gallery-vertical`，双端分别打包 `res/raw/reader_icons_license.txt` 与 `resources/icons/reader/LICENSE` 中的 ISC 声明。

模式切换不另建章节加载、图像解码或进度权威；继续使用现有阅读器的呈现变更、进度和配对失效链路。读取旧数据不批量写回；用户显式修改设置时才保存规范化 flags。偏好保存失败沿用平台原有失败处理，不以临时 UI 选中态证明持久化成功。

## 维护与验证

共享契约测试为 `ReaderModeFlagsContractTest` 与 `ReaderSettingsContractTest`，覆盖旧模式、隐藏值、默认恢复及 Int 格式往返。平台回归必须覆盖真实设置入口点击、保存/重开、默认摘要以及实际 viewer 选择；共享模型测试不能替代平台接线。

日常只运行这些行为及受影响 reader 路径的 focused tests，不因本页或原型审批触发完整模块测试、正式构建或版本发布。原生功能仍需用户体验验收后才能更新公共功能承诺。
