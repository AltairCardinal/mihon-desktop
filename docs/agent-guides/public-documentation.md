# 公共说明与 GitHub Pages

本页是[根规则](../../AGENTS.md)按动作加载的项目约束。仅阅读本次动作适用章节；代码命令与普通路径以仓库根为基准，Markdown 链接按本页位置解析。

## 公共说明与 GitHub Pages

维护流程见 [公共文档与 GitHub Pages 维护](../../docs/architecture/public-documentation.md)。默认英文 `README.md`，中文入口为 `README.zh-CN.md`；公共网站源码在 `website/`。

- 功能实施期间，只在已有内部计划或交接中记录待验收的文档变化。**用户明确验收本次具体功能/候选合格之后**，Agent 必须主动更新公共说明；测试通过、构建成功、审查通过、提交、合并或 roadmap 勾选均不等于用户验收，Agent 不得自行批准。
- 获得验收后，同步原位更新 `website/features.md`、`website/zh/features.md` 中受影响的小节，替换被淘汰的行为和限制；仅在摘要或步骤改变时同步 README 和开始使用页。只宣传验收覆盖的平台与范围，不推及整个版本。
- 双语 `changelog.md` 追加本次差异摘要，写实际验收日期、候选版本/实现提交和最小批准依据；私有聊天只记日期和范围，不公开全文或私有链接。当前功能说明不按版本层层追加，旧内容由 Git history 追踪。没有实际产品发布时不得造版本或发布日期。
- 纯翻译、勘误、链接、视觉修正不增加能力承诺时可直接维护；已知错误的可用性说明及时撤回。首版从既有公开 README 建立文档基线，不伪造历史用户验收。
- 文档范围运行网站构建、链接/必要浏览器检查和 `git diff --check`，不自动跑产品全量、正式构建或分配应用版本。遵守远端分支保护及[已授权的本机账号豁免与主干交付规则](governance-and-reporting.md#git-交付细则)，不把 PR 作为默认交付终点；Pages 部署成功才报告上线，存在真实门禁阻塞时交付可审阅产物并说明阻塞。
