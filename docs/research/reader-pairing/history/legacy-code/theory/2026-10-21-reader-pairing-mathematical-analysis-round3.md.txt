## 3. 统一数学解释：用已知条件消除无关信息依赖

固定版本v与已观察知识K，令完整输入集合为Ω(K)，完整计划为Γ(X)。
目标完整unit投影集合为 `S_t(K)={π_t Γ(X):X∈Ω(K)}`。
稳定认证要求该集合只有一个元素；临时计划Γ_now(K)不是这个证书，更不自动授权曝光。
本轮分别证明一个数值比较不再需要未知量，以及一个左侧控制入口已不可达。
仍需的几何、side、manual、原始内容与setting依赖继续经过真实扫描/收集器，不丢弃失败或缺失事实。

## 4. A：真实非负 provider 下的零距离支配

[laterWins](../domain/src/commonMain/kotlin/mihon/domain/reader/ReaderCanonicalPairingScan.kt#L88)先比较相邻候选强度，再在等强且自动开启时比较距离。
设已观察 near=d，未知 later=e，现规则仅在 `e!=null && (d==null || e<d)` 时选 later。
[真实 score](../domain/src/commonMain/kotlin/mihon/domain/reader/SharedSpreadMatching.kt)由三通道绝对差求和，成功返回的数值非负；白/黑/低方差或超阈值返回null。
所以在该 provider 域 d=0 时，任何e≥0或null都不能胜出，读取 e 不会改变这次扫描决定。
这发生在既有强度比较之后，不覆盖更高manual/side强度，不省略为取得强度所需的其他事实。

隔离 scan 增加默认关闭的 `distancesNonNegative=false` 参数，仅 certifier 的真实 owner 距离回调显式设true：

```kotlin
val nearDistance = distance(pages[i], pages[i + 1])
if (distancesNonNegative && nearDistance == 0.0) return false
val laterDistance = distance(pages[i + 1], pages[i + 2])
```

**公开 canonicalPlan 的任意 distance callback 不能默认视为非负。** 若near=0而later=-1，真实旧规则会选later。
三版都运行此负数小控制，仍选pair(2,3)；公开API未标记时保持原行为。
A只在 isolated certifier 可信回调接线中开启标志；没有给普通 canonicalPlan 或B开启。
若未来 provider/评分语义允许负数，该契约必须撤销或重新给出下界，不可继续引用本证明。

### 默认容量16的真实19页见证

全部0-based，target=p1，RTL/AUTO/automatic=true。p1/p2为同纹理纵图，p3同纹理，其余灰纵图，全部side已分析为UNKNOWN。
原始像素通过真实采样，实际 near score(1,2)=0；不注入scalar、不反射删除score。
owner默认容量16，接受顺序：p1,p2，然后p0,p4…p18这16个互异filler，最后p3。
p2样本在p3首次加入前已逐出；已计算的edge(1,2)=0标量保留，edge(2,3)从未计算；所有分析标量均仍Computed。
真实step(0)实际到达cursor index1，reservedStart不为1：AUTO封面不与UNKNOWN side的p1配对，也没有预留pair(1,2)。
因此后续确实进入i1的等强 near=0比较，不是借早先原子预留绕过了laterWins。

| 对照 | 目标结果 | edge读取 | readset唯一键数 |
|---|---|---|---:|
| baseline | NeedFacts EDGE_SAMPLES(2,3) | (1,2)、(2,3) | 12 |
| A | Certified [1 RIGHT,2 LEFT] | 只(1,2) | 11 |

完整 oracle owner得到同一pair，含certainty与完整unit等值；少一个readset键不是一次IO或毫秒收益的等价单位。

### A的精确域

`容量2/16 × near真实0/15/null × LTR/RTL × 3开篇 × auto开/关 = 72` 项，分别5/19页。
纹理每通道偏移5产生真实三通道距离15；灰/纹理组合产生computed null；接收顺序相同，竞争edge保持缺失。
自动开启且非FIRST_PAIR时，near>0/null控制必须仍NeedFacts，不能沿用零下界捷径。
FIRST_PAIR是实际开篇配走target的控制；auto=false不进入距离比较，不计为新增收益。
8个新增认证为两容量×两方向×AUTO/FIRST_SINGLE，均auto=true/near0；默认容量16占其中4个。

## 5. B：leading页侧形成前缀同步边界

target完整几何先按原流程验证；自动开启且target已有Computed leading side时，incoming edge(t−1,t)会被resolved侧向veto。
但manual优先于side，因此只在 raw incoming manual 不存在、且 t=1 时没有FIRST_PAIR隐式manual0，才采用该充分条件。
保守检查原始starts而不自行重算manual有效性；即便某条raw manual最后无效，也宁可保留原认证路径。

同步lemma：incoming不可能配对，则真实扫描不能跨过target，也不可能在t−1合法创建reservedStart=t。
更早reservation只能到更早index；到达target时没有有效reservedNow，opening只剩true/false两种可能。
所以可直接从target枚举这两个入口，再运行原step；target仍可与下一页配对，绝不是强制单页。
实际step仍可能需要必要右侧/前邻几何，不能把“控制同步”扩张为“所有左侧事实都无关”。

实际条件为：

```text
!isolatedSpread && automatic && targetIndex>0
&& incoming start不在manualPairStarts
&& !(targetIndex==1 && openingMode==FIRST_PAIR)
&& resolvedSide(targetIndex)==direction.leading
```

当前 certifier 本地无Need检查函数实际名为 [resolvedSide](../domain/src/commonMain/kotlin/mihon/domain/reader/ReaderPairingCertification.kt#L246)：
NotAnalyzed返回null，不发新增Need；读取真实analysis并记录readset，Computed也加入analyses依赖。
会发Need的是side()；本候选不调用它做快捷条件检测，也不使用跳过readset的peek。
targetFact缺几何/身份不匹配的早期返回未改；auto=false、UNKNOWN、缺分析或incoming manual存在时不启用快捷入口。
未命中仍可能增加一次analysis查询/record操作；readset去重后的唯一键数不等于执行次数，成功见证12→6不能泛化为所有输入读集总是子集。
当前b1d的dimension/effectiveFact已记录目标Analysis，实跑MISSING+OWN控制的唯一键数未增加；不声称已经测得新增唯一依赖或重认证。
这里确定的是额外metadata查询/记录操作；不新增NeedFacts并不表示零成本，也不等于已测整体延迟。

只有 `leadingTarget && first==targetIndex` 时使用这两个新入口；两opening完整unit不同则继续原来向左扩展。
first减小后恢复原四正规/独立入口枚举，不把更早位置也错误限定成两个入口；既有isolatedSpread路径保持原样。

基本域 `target1/2 × side leading/trailing/UNKNOWN/未分析 × 两方向 × 三开篇 × auto开关 × NONE/INCOMING/OWN manual = 288` 项。

## 7. 推荐及可推翻条件

优先保留两种证明思路：A用可信下界剪掉无胜算比较；B用不可能的incoming边建立同步入口。
它们用已知条件证明部分信息不影响结果，保持原输出并缩小取证需求。
默认非负契约、readset、必要事实与原有回退必须同时保留；不能把Γ_now临时结果当稳定证书。

下一步若实施产品变更，仍需focused红绿TDD、真实DI/provider契约、Memo/readset失效与受影响Session接线验证。
之后才测冷/热、真实淘汰/慢邻页下的IO、decode、总CPU及intent到正确像素分布；本轮没有此类数据。
A减少的竞争edge可能早已便宜可得，B的前缀可能已热，故8/4个新增认证不能外推用户延迟改善比例。

可推翻或收窄候选的条件：provider允许负值却启用A；side/manual/旋转身份失配；有效reservation绕过B同步lemma；两opening分歧仍提前认证；遗漏负向读集/内容失效；真实接线无法维持上述契约。
尚未覆盖任意像素、失败/重试、EXIF/用户旋转变换族、长manual链、A+B组合及原生呈现/导航/进度。
未观察到的这些路径不视为通过；本轮交付是可复跑的数学/算法研究证据。
