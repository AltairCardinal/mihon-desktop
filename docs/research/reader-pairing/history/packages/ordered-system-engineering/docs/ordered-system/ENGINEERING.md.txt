# 工程事实、模型与证据边界

## 目标与信息边界

这是有序对象的局部分组、部分知识认证和增量复用问题。完整输入对应确定计划；部分信息下只能发布
已证明不受允许补全影响的单元。不能通过锁定猜测或虚构版本保持稳定。完整 unit 包括成员、顺序、
槽、原因及确定性，不能只验证成员集合。

所有新知识必须来自某个合法世界，或明确标为接口扩展/故障注入。未知、已知空值、失败、陈旧、
驱逐和真实版本变化分开；不能将失败或缺失统一替换为 null。相邻边共享端点见证，端点分析的
可见性和失败会影响边的可见性。

## 三层实现

1. **冻结核心**：`reference.py` 与原测试、golden 保持字节一致。它们定义既有扫描与保守/扩窗认证，
   不包含完整宿主。只在事实完整时，`complete_plan` 才能作为完整世界语义 oracle。
2. **新增工程模型**：`generator.py`、`runtime.py` 与 `benchmark.py` 提供有界实验。生成器的公式、
   会话事件与实际来源对照单独验证；没有被移植的真实时序、资源和外部故障不能推断为已验收。
3. **既有探索候选**：`prior/` 保留上一轮探索程序，便于复算思路和避免重复研究。其分支、失败和
   入口策略与后来硬化实现并不完全相同，不能拿它的时间或覆盖率冒充宿主候选性能。

原 `protocol.py` 仍是合成切片：`consume` 表示接纳工作完成，不表示用户确认消费；其简单 `publish`
也不是完整发布权限检查。H6/H7 的个别切片通过不表示 H2/H3/H8/H9 全部成立。

## 可执行接口和生成域

- `make_witness(seed, count)` 生成中性潜在栅格；`sample_item(spec)` 同时导出几何、方向标签与
  边特征；`score(earlier, later, direction)` 从相邻特征求匹配值，包含已知空值。
- 生成器是受限 8-bit straight-alpha 栅格域：条纹、平坦、单侧边界和变换；所有派生量来自共同
  见证。它不提供编码文件、解码、网络、自然内容分布，也没有穷尽所有可实现的特征组合。
- `Knowledge(witness, capacity)` 容量范围为 2…16。正常 observe 先计算可见邻边，再淘汰原始
  样本；analysis 与已计算边可持久。显式 `evict` 是合成的容量控制事件，不是所有真实驱逐策略。
- `Session.request(target)` 执行当前知识投影、检查、必要重算、需求映射；`apply(event)` 处理
  `request/prefetch/demand/finish/consume/cancel/observe/fail/evict/flag/navigate/metadata/rebind/publish`。
  返回的 work、proof 和 publishable 分开。它没有完整关闭、重排、事务恢复或外部平台所有权API。
- `flag` 是简化的逻辑进度投影，不是用户观察/确认政策的逐项移植，也不参与证明或物理任务状态。
  模型没有声明完整 H9 已实现。

## 生命周期合同

下表是后续算法必须尊重的行为，不是任意可放宽的性能机制：

| 事件 | 事实/身份 | 缓存 | 验证义务 |
|---|---|---|---|
| 重复请求 | 不变 | 可以复用 | 先检查记录有效性；计入校验成本 |
| 导航 | 目标改变 | 基线清空认证缓存 | 不把此处不存在的跨请求命中计为收益 |
| 内容重绑定 | 真实新身份 | 基线创建新会话/新认证缓存 | 保留策略配置；拒绝旧完成；迁移需另证安全 |
| 元数据确认 | 会话内某位置身份修订 | 认证缓存保留 | 已读位置改变应失效；未读位置可研究安全保留 |
| 分析/边事实到达 | 知识精化 | 缓存保留待验证 | 未知变已知与规则/内容版本变化不同 |
| 驱逐 | 失去见证或已知值 | 需重验 | 不凭空恢复已知值，不默认容忍已知→未知 |
| 可重试失败 | 有类型的失败 | 需重验并报告 | 不用短路吞掉合同要求的错误 |
| 关闭/新代次 | 权限失效 | 丢弃旧权限 | 迟到工作不能对新身份发布 |

证明依赖、物理工作和发布权限应分别记录。依赖缩小不自动取消任务；同身份正在执行的任务应可
复用或提升。不可抢占工作没有实际结束前不能假装释放容量。模拟器未包含的排队态或取消语义
需要写成额外前提，不能由一个 KEEP/CANCEL 有利轨迹推断普遍优势。

## Header 权威性必须分支处理

α：有效 header 的占用分类在同一内容版本内不会被后到分析推翻。β：可能被推翻。
冻结核心有些认证路径依赖 α；它并不证明 α。模型生成器产生同源事实时可构造 α 世界，但这不证明
所有宿主调用路径都满足 α。

在 β 下，先发布基于 header 的结果，随后令旧证书失效，不足以满足同版本已观察单元不变的要求。
必须在发证前排除冲突补全、采用更弱事实，或证明额外接纳合同。不能回退到已知不安全的旧证书。
任何候选都须声明自己的适用模式。

## 性能比较必须比较完成同一请求的成本

“基线快速返回失效”与“候选继续比较并命中”不是完成同一工作的两种耗时。总成本至少包括：

输入准备 + 作用域构建/维护 + 校验 + 必要重算 + 各次被拒尝试 + 物理取证/接纳 + 合法发布。

作用域一次构建、多次复用的摊销成本要单独列；语义结果和有效性相同后再比较时间。
若继续缓存转换或索引结构，要计入建表、维护、失效及内存，不只计入热路径查询。

操作预算不是墙钟、字节或栈上限。整输入准备可能发生在第一次预算检查之前；需要明确终止、
回退和异常边界。预算耗尽返回未证明，不允许签发截断证明。

## 本次交付的实际验证

- 包内35项测试通过，包括原核心17项及新增生成器、会话、候选与成本边界测试。
- 新采样生成器与冻结原实现独立直接对照：896个采样组合、1792个双向评分、896个header几何
  投影一致；覆盖7组尺寸边界、8种方向变换、4种旋转、4类图案及5档alpha，非所有因素的完整
  笛卡尔积。知识事件投影48项一致，容量取2/16。自然频率和所有栅格组合未验证。
- 原实现直接执行了重复请求命中、导航清缓存、旧请求拒绝、元数据确认保留缓存并重算、内容
  重绑定后新缓存等最小生命周期路径。任务提升、补位、容量和进度仍是合同模拟，不能扩大成
  完整异步运行时对齐；旧基线没有后来新增的策略开关，开关保留是本模型的研究扩展。
- 作用域适配只针对冻结核心已认证结果，驱逐容忍关闭；对258份认证结果做了有限定向校验，
  包含856项未知/失败精化保留、774项依赖身份失效及258项顺序修订。它不证明任意候选的
  自定义验证器健全；need_facts/blocked 仍按严格读集比较，避免永远缓存旧的等待状态。
- quick CLI 以候选接口示例执行，30个策略/场景组合通过；完整配置提供但本次未实跑。
  所有新时间来自模型本机运行，模拟服务时间单列，未宣称真实物理取证或用户等待改善。
- 独立检查发现并修复：旧完成接纳的身份漏验、取消已完成任务后未补位，以及知识投影重复
  采潜在像素污染热路径成本。相关回归已加入测试，冻结核心文件保持不变。

会话模型不是宿主逐行移植。metadata 会保守撤销该对象旧分析、原始样本及相邻边，即使重复同值
也可能多重算；rebind 逻辑上更换会话编号，保留未变对象知识但清空memo。native lease、线程、
编码格式、实际取消退出、系统事务恢复、全平台发布和完整用户确认规则未验证。

历史底层成本2880条已按允许字段逐值中性化，并保留进程分组；额外的最新探索摘要属于 provisional，
未复算其全部原始数据，未冻结完整代码/环境，不作为采用证据。匿名化筛查与交付文件摘要用于
防止泄露标识和意外夹带，不能保证从算法形状完全无法猜测应用类别。
