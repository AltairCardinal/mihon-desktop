# 成本证据及采用边界

`data/` 是真实 JVM 记录的必要匿名投影，不是新一轮计时。六组全部保留，没有选择获胜组：

| 数据 | 原始记录数 | 性质 |
|---|---:|---|
| owner | 1800 | 三种真实历史来源 × 三独立进程，同一生命周期与可观察签名 |
| kernels | 405 | 评分同代码消融、完整信息研究算法、规则迁移及分阶段取证；含预热 |
| memo | 792 | 修正后的同代码研究对照，所有配置各自承担本配置设施维护成本 |
| partial | 630 | 部分信息研究 kernel，包括不同合同与秩域，不是默认采用率 |
| direction | 72 | 完整信息方向换槽研究，不能迁移未知证据的认证权 |
| scheduling | 162 | 暖机/轮换后的真实队列与策略执行；服务时间来自注入虚拟时钟 |

运行 `python data/recompute.py --check` 可核对全部计数、40 个跨来源公共签名单元、逐字段 min/median/max、投影 SHA。`aggregates.json` 排除显式 `warmup=true`，原始投影仍保留预热。CSV 来源记录轮均照录；保留负数哨兵，不当成有效操作数。不同配置不一定等容量，`structure_weight` 是结构权重估计，不是实测字节；`thread_allocated_bytes` 是当前测量线程的累计分配，不是进程总内存或驻留内存。`elapsed_ns` 是完整所述生命周期的墙钟计时，不能当单次用户操作耗时；`policy_lifecycle_ns` 同样不能单凭字段名解释成 CPU 或真实关键路径等待。

隐私投影：删除 UTC；原 PID 重映射为 `process_index`，这是匿名进程索引，绝非原 PID。历史来源分别改名 `legacy`、`corrected`、`current`；默认配置改名 `default`。整数、时长、分配、工作量、签名数值均未修改；抽象轨迹签名保持原值，用于一致性核对，不是内容本身。内部逐文件 SHA、行区间及 source-field→neutral-field 映射独立保存，不随公开包分发。保留这些细粒度指标并不构成不可重识别保证。

`owner` 中 `legacy` 是修复前真实历史代码，`corrected` 仅具备完整尝试支撑正确性修复，`current` 另具评分减耗。40 个安全轨迹 cell 可比较公共签名；已知错误轨迹没有混入速度比较。相同来源内关闭索引、紧凑比较或戳的配置是消融，不是另一历史版本。评分优化已是 incumbent：局部时间比约 0.0654–0.6152，分配比约 0.1227–0.1990；它没有减少物理取证或特征访问，研究不得重新包装旧 Python 深拷贝收益。完整 owner 有回退：例如 `current/corrected` 的 lifecycle、n=256 汇集中位比约 1.391，unrelated、n=256 约 1.355。报告所有 cell，而非只报局部最高倍数。

完整信息树的随机点查询约为 canonical 的 0.3946–0.4250，相位翻转约 0.3037–0.3333，逐步输出全计划却为 1.3748–1.6271。尚无盈利的部分信息产品消费者，不可把它替换成完整信息 oracle。部分认证的一次构造驱逐场景多得四个合法证书，但 source-grid 全生命周期约 258.0µs 对照 152.9µs；自然命中频率、真实补取 IO、native transform 和用户关键路径尚未测量，采用门槛仍开放。

修正缓存各策略可能更慢，保留全部原始 cell；位置戳、日志、反向依赖、驻留、尝试缓存与闲时预备不能凭复杂度默认获利。调度方向预测 required 虚拟等待未优于固定窗口；aging 将 optional 最大等待 115→20，同时 required 总等待 1770→1865。debounce 减少过时工作但可令最终版本等待 14→16，慢变更还会合并中间版本。虚拟单位不得换算原生 IO 加速；更少工作不等于更短关键路径。

## 无效及负结果台账

| 排除项 | 真实原因 | 保留范围与重开条件 |
|---|---|---|
| 初轮 memo 全部记录 | 精确重验成功未刷新基线戳，反复多付不应支付的成本；亦发现非本配置设施维护污染并修正 | 不混入有效数据。仅采用 memo 投影中的修正重测；更改机制后可重新比较 |
| 初轮 scheduling 的 CPU/分配 | 首配置冷启动污染；未逐 cell 暖机及轮换 | 不外发失效数字充当有效对照。事件及虚拟等待轨迹有效，修正暖测与之相同 |
| 自然采用率或真实 IO 收益 | 未测，不是零收益 | 新实验需实际 IO/transform/关键路径与频率，不得补造参数当实测 |
| 规则变体质量 | 300 世界、19200 位置中 251 单元归属改变，无质量真值 | 只证明差异，不能推论质量改善 |

负结果不是永久禁止研究；重开须改变可检验机制、合同或负载前提，并与当前正确 incumbent 比较。固定支撑的历史正确性修复不可回滚换命中。
