# 宿主事实与模型边界

本文是内部只读核对后的匿名约束，不是 native 源码移植。包内 Python 是可执行研究合同，不能单靠通过它宣称真实宿主端到端可采用。

1. **完整尝试支撑与公开结果分离。** 一次请求可执行默认、重试及分支。公开 selected trace 的有序需求、失败、依赖及步数保持既定语义；memo 校验与读取上限使用全部实际尝试的读取并集。超限或支撑越界时正常重算且不存 memo，不能截断支撑后继续缓存。基线精确重验成功后刷新戳；戳饱和时关闭快命中，不能回绕。
2. **身份分层。** owner generation、有序身份、每 item 的内容标签、旋转/方向、尝试身份及请求 capability 共同控制接纳。无关 item 的元数据变更不应废除仍有效的物理请求；同 item 内容替换必须拒绝旧完成。普通 rebind 可迁移仍相同内容的确认事实和最终释放所有权，但不能迁移旧发布/绘制许可。请求对象的拥有权不能仅凭结构相等伪造。
3. **α 是 producer contract。** 同内容标签且同方向的有效先验几何与后到物理分类必须一致。真实 producer 从同一内容及方向规则产生两者，并核对捕获状态、版本或缓存几何。但共享接口并未对所有人工注入强制 α。后续 revision 失效只能防复用，不能追溯证明此前证书。不存在已证明的正常同内容合法矛盾；β 研究不得冒称已证实产品故障。未报告的外部原位替换也不因此获得密码学保证。
4. **持久派生与有界 raw witness 分离。** raw feature witness 有有限驻留容量；驱逐不等于清除已确认的 item analysis 或邻接标量 rank。Computed(null) 是已计算且不可连接，Unknown 是未计算，RetryableFailure 是失败且可重试，三者不同。相邻 witness 可联合派生两方向 rank；非相邻、错误身份或非物理原始来源不能冒充当前证据。
5. **认证、许可、准备、发布、确认、释放分层。** 当前 certification 必须为 Certified 才能捕获 presentation permit；两 target 的身份、支撑、布局与位置需一致。一个 target 就绪不得无条件等待整批，但也不能将其许可推广到另一个未证 target。接纳完成不等于发布，发布不等于确认；旧许可不因 release route 存活而恢复绘制权。
6. **取消不等于物理退出。** 发出取消后，在 runner 真正退出前仍占物理 slot。过时完成可能需要释放资源，但不得接纳旧事实或发布旧版本。用于比较策略的输入、服务时间及外部变更必须相同，不能让预测器偷读 future/hidden truth。
7. **成本分层。** 真实 JVM 计算/分配、研究 kernel、注入服务下真实队列执行、纯服务模型分别报告。物理 open、native transform、系统发布与用户等待并未在本数据中完整实测。维护、创建、关闭、失败与重新调度的成本不能丢掉，structural weight 不可当 actual bytes。

## 受限数值域 D_src

已获取 witness 的算子输入各为 50 个 packed 四通道 feature。高通道 c 表覆盖量，低三通道 x 经整数归一化 `floor((x*c + 255*(255-c) + 127)/255)`；累加对应三通道绝对差得到整数 q。只有 q<1500 才有数值秩 q/50，否则 Computed(null)。均高、均低与两侧低方差亦拒绝，精确阈值及 binary64 求值顺序见独立中性数学实现 `OPTIMIZED_OPERATOR.py`。所以数值秩落在 `{q/50 | q=0,…,1499}`；这个网格是保守外包，不能反向断言每个值或多条相邻 rank、analysis、side 的任意组合都能由同一组 witness 实现。量化边界只约束已获取并合法归一化的 witness，不赋予未知 witness 额外事实。此独立 Python 实现没有 native IO 或宿主桥，不拿 Python 运行成本代替 JVM 成本。

## 四条仍失败的历史计数断言

两个宿主族的 focused 验证各有两条失败：A 的已挂接相邻项累计 content-open 次数断言；A 的 required-prefetch 全局循环上界；B 的两个固定 feature-sampling 次数断言。回退到真实历史来源仍复现同类型失败。首次结果与历史对照均保留内部证据，没有放宽 oracle、删除失败或宣称整方法通过。它支持“未发现由当前评分/支撑修复引入的差异”，不证明断言错误，也不证明宿主没有其他问题。研究者必须把这四条计数约束视为未解决历史事实，不能悄悄改为成功；认证/许可的先行断言通过不等于这四条全通过。
