# 主会话族：S（L2 语义替代）、T（研究决策）与 X30

证据层：core（冻结 `_Scan` 谓词）、coupled（Session，虚拟 u）、local_measured。
原始数据：`results/raw/wpS/studies.json`、`results/raw/wpT/t05.json`；代码：`candidates/wpS_rules.py`、
`candidates/wpT_bounds.py`、`candidates/wpT_checker.py`、`candidates/wpM_q02_x12.py`；
测试：`tests/test_wpT.py`（4 项：3 条隐藏前提复现 + 交接校验器）。
所有 S 族规则都是 **L2**：输出与冻结规则不同，只比较结构与成本，不宣称质量更好（没有质量真值）。

## S01 替代规则的支配关系 — D2，limit_proved
路线 1：局部极大（LMP，round-8）；路线 2：全局目标（`maxcard`：允许边上的最大基数匹配，按强度/秩偏好/最左打破平局）。
804 个输入（800 随机 G0 + 4 条递减链）：所有规则都合法（划分 + 1/2 元单元）。对数：reference 4 855、LMP 4 739、maxcard 4 910；
强度和：reference 6 330、LMP/maxcard 6 368。递减链编辑半径：reference 92、LMP 2、maxcard 48；前插一个对象后重标记比例：
reference 0.984、LMP 0.953、maxcard 0.031。**没有一个规则在（对数、强度、局部性、插入稳定性）上同时支配其他**：
maxcard 对数最多且插入最稳，但编辑半径 48；LMP 局部性最好但对数最少、插入仍几乎全重标。
与 WP-B 的 N06 定理一致：精确（=reference）、局部、插入稳定三者不可兼得。

## S02 数据无关的质量保证 — D2，limit_proved
路线 1：最坏质量比：reference、LMP、seg、anchor 都是**极大**匹配（每条未配对的允许边都有一端已配对），因而对数 ≥ 最大基数的 1/2，
随机样本最小比恰为 0.5（下界紧）。路线 2：对"所有偏好"成立的结论只剩支配关系，而 S01 显示不存在支配者 → 任何"更好"的主张都
**需要裁定**；最少裁定量见 S05。

## S03 语义迁移的版本边界 — D2，conditional
路线 1：只在新上下文切换（全部撤销重发：12 502 个单元）；路线 2：逐单元迁移（两个划分的公共单元在新上下文**重签**但外观不变，
只撤销 4 474 个旧单元、发布 4 590 个新单元）。正确性：两者都是划分，先撤销变化单元再发布新单元，任何时刻都不出现重叠；
证书/确认/发布租约按上下文签发，从不迁移（与 WP-H H05、WP-C Q03 一致）。逐单元迁移把可见变动降到 36.7%。

## S04 局部性可调规则族 — D2，refuted（重启式）/ conditional（强制切分）
路线 1：在绝对位置或内容锚点处重启扫描（`seg8/seg16/anchor`）：**并不限制影响半径**——若一对单元跨过重启点，扫描根本不会在该点停下；
递减链上编辑半径 94/31/95，与 reference 92 同级（一个可执行反例）。路线 2：强制切分（`cut8/cut16`：每段独立规划，不允许跨段配对）：
半径 ≤ L（实测 6/14），代价是对数 4 301/4 600（vs 4 855）、13.6%/5.9% 位置单元不同、段首适用首位规则；插入后重标记 0.75/0.94
（绝对段边界随插入移动）。这正是题面警告的"绝对奇偶/位置不能当免费改进"。

## S05 用户约束的最小表达 — D2
把两个规则的差异归约为**局部差异模式**（±3 窗口内的 WIDE/允许/强度/null 结构 + 相邻序位）：300 个输入上 6 条规则间共有 453 类模式；
若用户偏好只依赖这样的局部窗口，**2 个判断**（贪心分离集）就能把所有可区分的规则对分开；reference 与 seg8/seg16 在样本内无差异模式
（不可区分，无需裁定）。路线 2（硬约束 + 例外）等价于给每个模式类一个裁定，上界 453。结论：最小裁定量在 2（局部偏好假设成立）与
453（任意模式偏好）之间，取决于偏好是否局部——这是需要外部确认的前提。

## S06 L2 是否值得继续 — D2，结论：当前不值得
路线 1：L2 的局部性收益：完整知识下参考证书回看距离中位 2、90% 分位 4、99% 分位 14（随机输入），只在相位链上随 n 线性增长
（n=256 时 254）；LMP 只需目标 ±6 位置（另加 pinned 段）。路线 2：现行语义内的剩余收益（T05）：oracle 参照点显示信息选择在模糊族
（W06/W01）上还可省约一半物理获取，远大于 L2 在随机输入上的局部性收益。停止条件：除非（a）获得局部偏好的质量裁定（S05：≥2 个判断），
且（b）负载以长相位链为主，否则不继续 L2。最小可审查试验：收集 S05 的 2 个分离判断 + 一条长链负载的取证计数对照。

## X30 语义迁移 × 剩余收益界 — D2
四组：0 = 现行语义；A = 先在现行语义内优化（T05 参照：W06 82→42、W01 33→15 次获取的上限空间）；B = 引入 L2（S06：随机输入几乎无局部性
收益，迁移需重发 36.7% 单元并重签全部证书）；A+B = 先 A 再评估 B。两种组合方式：先 A 后 B（B 的边际收益在 A 之后更小，因为 A 已经
吃掉了长链以外的大部分物理工作）；先 B 后 A（B 的迁移成本先付，且失去与冻结规则逐字段比较的 L0 判别力）。交互：A 与 B 在"省物理工作"
指标上是替代关系（负交互），在"证书支撑大小"指标上互补（B 把支撑变为常数）。结论：先 A；B 只在 S06 的停止条件被推翻时重开。

## T01 自动发现隐藏前提 — D2，3 个新前提（另 3 个由分支独立发现）
路线 1：规格–实现差异（逐条对照 `NATIVE_OWNER.pseudo` 与 `coupling.py`）；路线 2：因果变异（翻转实现选择，看规格不变量是否破）。
可执行复现（`tests/test_wpT.py`，只用包内 API）：
- **P2 先驱逐后派生**（抽象不保真）：`Session.consume` 先把 raw 驱逐到容量再派生相邻秩；伪代码先派生后驱逐。raw_capacity=1 时永远派生不出秩
  （0 次 vs 容量 2 时 1 次）。WP-G 在耦合负载上量到活锁（W06 11 967 次获取只发布 4/64）。
- **P3 确认不绑定发布**（模型 API 可达缺陷）：`confirm(target)` 无法区分迟到回调属于哪次发布；旧发布过期并重发后，旧回调确认了新发布。
  WP-H 在留出负载上 35 次迟到回调中 16 次误确认；按句柄绑定后为 0。
- **P6 精确支撑在纯精化时过期**（合同含义）：强证书支撑记录了未知事实的类型化值，接纳一个**不改变真值单元**的事实也会使发布过期，
  需要刷新（WP-A 的 shadow 用 L0 刷新解决）。
分支另外独立发现：容量 1 下包内 Controller 活锁（WP-A NH-A1，与 P2 同根因）、取消会毁掉后续目标可复用的证据（NH-A2）、
投影支撑被误用为发布支撑（WP-G NH-G2）。分类：P2 = 抽象不保真；P3 = 可达模型缺陷；P6 = 合同（精确支撑 vs 精化容忍）的必然后果。

## T05 剩余收益上界 — D2
路线 1：关键路径份额（耦合运行中延迟全部来自服务等待，证明在独立 lane 时延迟上界由服务次数决定）；路线 2：不可省物理工作的参照点
（`OracleRunner`：评估器知道隐藏世界，每次只获取使精确 DP 认证所需的最小物品集合；**不是候选**）。4 个族 × 4 个种子（n=10–12）：
| 族 | incumbent 获取/延迟 | 精确证明零成本 | oracle 参照 |
|---|---|---|---|
| W06（全分析、秩全缺） | 82 / 48u | 76 / 45u | 42 / 25u |
| W01（相位链，3 个洞） | 33 / 33u | 25 / 24u | 15 / 18u |
| RP（随机部分） | 26 / 48u | 26 / 48u | 23 / 51u |
| W05（驱逐缺边） | 3 / 3u | 3 / 3u | 2 / 3u |
结论：剩余收益集中在"共享变量使结构模糊"的族（约一半获取），随机部分知识几乎没有空间；更强证明本身只拿到其中一小部分，
其余必须来自取证选择（F 族）——而 WP-A 显示在不读隐藏世界的前提下，便宜的选择器只拿到 5–9%。
