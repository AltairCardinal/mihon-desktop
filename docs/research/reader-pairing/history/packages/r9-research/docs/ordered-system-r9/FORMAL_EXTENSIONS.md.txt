# 形式化分域与新增合同

## 1. 状态与规则

有序身份向量 I=(i_0,…,i_{n−1})，上下文 C 包含 owner incarnation、内容标签、顺序、
方向、变换、规则设置与修订。K 为当前可观察事实，W 为隐藏完整世界。
F(W,C) 是冻结扫描规则给出的完整划分，F_t 为包含目标 t 的完整单元。
单元的有序槽、原因及确定性均属结果；不能只比较成员集合。

四种状态不得合并：未分析、分析失败、已计算空秩、已计算数值秩。
有效头部和已完成分析也不是同一个事实来源。一个证书必须声明其所依赖的事实与域。

若 Ω_D(K,C) 为域 D 中与当前合法知识相容的完整补全，则可靠认证要求
Ω_D 非空且对所有 W∈Ω_D 有 F_t(W,C)=u。
过近似集合为单点可证明子域唯一；过近似非单点不能证明子域歧义。
若采用空世界集处理，应返回明确矛盾/回退，禁止用空集上的全称真签发证书。

## 2. 头部权威与数值域

**α**：合法生产者保证同内容和同变换下，头部分类与后到完整分析分类一致。
**β**：不作该承诺；模型允许后到分析推翻头部。接口可构造 β，不代表正常生产者已被证明违约。
变化戳使后续缓存失效，不能反向证明此前签发可靠。

**D_ext**：冻结标量接口的扩展域；特别的 Python 精确整数比较仅在明示该域时适用。
**D_64**：有限 binary64 接口，严格比较和相邻可表示数；不含 NaN/Infinity。
**D_+**：D_64 中非负且小于给定门槛的值。
**D_src**：受限见证过程生成的量化秩子域，其定义见 `NATIVE_CONSTRAINTS.md`。
不能用独立任选侧向标签、状态和秩的扩展世界证明联合物理可实现性。
域约束不成立、没有证据或发生不支持的输入时，退回可靠的更宽域。

## 3. 三类支撑

R_selected 支撑公开选中尝试；R_policy 支撑尝试的选择结果；R_publish 支撑当前发布授权。
三者可以重叠但不相等。当前正确基线的 R_policy 为所有实际尝试读取的保守并集，
不把被拒绝尝试的需求和失败合并到公开结果。

新的更小 R_policy 需要证明未记录事实的任意允许变化不会改变公开选择；
只把失败重试的 reads 删除、只记录成功分支或只比较短 hash 不可靠。
缓存前缀/摘要必须携带构造它的支撑，跨请求诊断、需求、失败和预算必须正确隔离。

## 4. 工作、事实与授权

逻辑需要不等于物理任务。一个原始见证可服务分析与相邻若干派生；
一次物理服务按其完整身份和真实尝试计费，多个消费者只增加引用。
取消意图不等于物理退出；不可抢占工作在真正完成/消费前仍占资源。
任务完成、结果接纳、事实可见、可靠证书、当前发布、显式确认是不同事件。

同上下文的可靠单元应相同或不相交；发布目标必须属于单元。
仅检查重叠可以提供一致性防线，不能替代证书可靠性；旧版本证书即使内容值相同，
也不能自动携带新版本发布或确认权限。

## 5. 成本与目标

对外生意图轨迹 X 与策略 π，分别记录本机计算 Q、物理启动/数据量 A、派生 D、
维护 U、废弃/取消残留 Z、内存活跃/驻留 M、输出/释放 O，以及意图关键路径 T。
并发下不能把所有服务时间简单相加当 T；共享工作也不能重复扣费。

缺少服务实测时，给 T_π(θ,X) 的参数化事件模拟和适用区间；θ 的单位和来源必须标明。
原生计算测量与模拟服务不能相加后改称实测总时延。多目标目标函数应显式给优先次序或
Pareto 前沿，不能默默用总吞吐抵消当前意图延迟或资源硬上限违例。

## 6. 不变量与终止

身份、顺序、设置、location、owner 和饱和修订守卫先于快路径；
任一超预算、中断、矛盾或未完成尝试不得把其部分结果升级为确定证书。
若明确的全局预算尚允许，可以另行运行完整、独立可验证的尝试；前一尝试的成本仍须计入。
内存与任务上界计入缓存摘要、支撑、索引、历史版本、在途、完成未消费、发布和观察者。
整个研究不要求改现行划分规则；L2 必须单独定义其新函数和迁移合同。
