# 新题的前轮依据与增量

这是按族导航的source anchor；每题还需在coverage填写具体所用前轮cell、合同或反例。
不是宣称120题都从未被研究，而是要求在已有结论上补新机制、证明或采用层。
原生层锚点统一为 `COST_EVIDENCE.md`、`CASE_STUDIES.md`、`data/`；
接口为 `MODEL_API.md`、`EXECUTABLE_LIMITS.md`；候选先读 `ALGORITHM_FRONTIER.md`。

| 族 | 已有依据 | 本轮必须增加的东西 |
|---|---|---|
| A01–A06 | 驻留淘汰正例可多签，真实服务未知 | 物理边际收益、proof/service竞争、可观察采用gate |
| B01–B06 | 独立叶近似与共享DP均已有 | 精确可组合边界、序约束和增量精度/空间界 |
| C01–C06 | 完整树点查询快、全输出慢 | 按需建立、懒维护、切换/顺序变化与消费者 |
| D01–D06 | 二进制数值与源量化域不同 | 联合可满足完备性、来源约束、接口一致性 |
| E01–E06 | 有界raw、标量保留、共享见证 | 最小特征、低维可实现性、变换与渐进真实服务 |
| F01–F06 | 少事实不一定少轮次 | 考虑证明复杂度、共享和排队的联合信息价值 |
| G01–G06 | policy支撑并集正确；简单全局戳廉价 | 选择证据压缩、低分配屏障、全层回收 |

| I01–I06 | 共享/提升/逐完成接纳已具备 | 动态准入/微批、共享负外部性、完成背压 |

| N01–N06 | 有长依赖和小域反例；不是一般穷尽 | 部分摘要状态下界、协议归纳、独立反例搜索 |

| P01–P06 | 固定高级策略没有普遍赢家 | 含切换成本的在线选择、稳定安全gate与留出泛化 |

| R01–R06 | 接口违约不等于正常producer故障 | 多事实原子性、空补全集、长期饱和与异常回收 |
| S01–S06 | 规则变体会迁移单元，无质量真值 | 质量保证边界、最小裁定、迁移与是否值得L2 |
| T01–T06 | 上述负结果和采用缺口仍开放 | 新隐藏前提、成本差距模型、剩余收益界与新范式 |

历史缺陷/测量污染可以作为对照与回归，不能再计作本轮新算法。
旧负结论可以推翻，但需说明新的可检验机制、假设或负载；不能仅换参数/语言重新命名。
