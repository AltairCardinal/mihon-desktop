# 包内检查与可信边界

## 已执行的实现核验

- 61项研究包测试通过，其中35项为冻结原始测试，golden文件含7个case。
- 13个冻结规则/依赖/原测试/夹具文件与前轮输入逐字节相同，未改oracle。
- smoke默认seed905，240次owner增量差分，两个虚拟服务profile的公共目标/确认一致；
  L1额外证书是明确标注的prefix-start toy，不是已有强算法移植或原生收益证明。
- 数据包含3861行匿名投影，6组完整保留；逐行来源核对和公开重算通过。
- 独立增量差分另做3600次；同轮审查覆盖策略支撑、身份复用、物理占位、
  完成未消费隔离、陈旧发布/确认和饱和身份。发现的问题已加失败回归并修正。
- 问题编号为120主课题、30组合、18对手族；coverage初始150行均为未开始，
  不把本包准备工作写成外部研究已完成。

这些是已执行范围的证据，不是对全部调度、生成域、所有运行环境或未建模层的证明。
实际验证环境为Python3.14；API源文件以Python3.10+为目标，不宣称逐版本/跨平台均已运行。

## 自行复核

从包根目录运行：

```text
python -m unittest discover -s tests
python smoke.py --seed 905
python data/recompute.py --check
```

根MANIFEST.json列出除自身外的每个输入文件及SHA-256/字节数；
`fixtures/frozen-hashes.json`仅针对13个冻结源文件，两者范围不同。
新增研究结果放research_out/，不要更新输入manifest掩盖oracle或数据变更。

匿名检查针对公开边界的直接名称、业务标识、路径和意外私有文件；
它不是通过数学约束或公开数值无法推断系统类别的保证。
公开包不含内部来源映射、原生类/路径、Git提交或用户机器记录。
服务时间、hidden world、状态与授权限制以EXECUTABLE_LIMITS为准。
