# 已知案例与仍需突破的机制

这些案例是研究起点，不算新成果；新的 18 个对手场景见主任务文档。

| 案例 | 已知事实 | 研究必须新增的内容 |
|---|---|---|
| 完整尝试 memo | 目标不动，非 selected 尝试读取的一项新事实可令等待转为 Certified；仅记录 selected 支撑会误命中 | 在冻结语义下减少完整支撑维护的机制及真实反例，不能删依赖 |
| 精确成功戳刷新 | 戳变但支撑值相同，精确重验成功应更新存储戳 | 设施维护、碰撞、饱和与跨请求状态隔离的正确对照 |
| 有界 witness 驱逐 | 已有 analysis，邻接 rank 缺失；source-grid 四请求可多得四合法证书但计算更贵 | 合法支撑范围、命中频率及真实补取服务阈值，不能只报覆盖率 |
| α 与 β | 先验几何在 α 下权威；接口允许人工违反 α | 明确证明域，不能把违约构造当真实 producer 故障 |
| 全计划输出 | 树点查询有利，输出全计划却可更慢 | 消费协议与输出敏感下界，不能只测一个点后承诺整个输出 |
| 方向重命名 | 关闭自动 rank 决策时完整计划可换槽复用 | 不迁移旧认证/发布权；证明兼容条件或拒绝路径 |
| 共享服务 | 四组 serial/joint × 独立/共享 witness 工作量 8/7/3/3，访问 3104/2716/1164/1164；首 target 两次服务后就绪即发布 | 两种优化不可相乘；寻找互补域与首 target 关键路径证据 |
| 先分析后 rank | 不再需 rank 时特征访问 388→288；仍需时 388 不变且多一阶段 | 真实 open/transform 成本及相同输入，不能拿访问数代 IO 时间 |
| 公平与前台 | optional 最大等待降低却增加 required 总等待 | 可证明的 Pareto 或约束优化，报告饥饿、尾部及失败成本 |
| debounce | 少过时任务，也可能更晚服务最终版本、丢中间版本 | 明确可合并语义和不可合并反例，不能事后选择到达序列 |
| 局部规则变体 | 251/19200 位置单元改变，无质量真值 | 独立质量标准；不把差异当改善 |
| 物理取消 | 逻辑取消仍占 slot，直至真实退出 | 耦合发布/接纳的可执行反例，不能取消时立刻腾 slot |

证据分为 historical-source real comparison、same-code ablation、research kernel、virtual service 四层；每个新结果标明所属层，缺失的 native IO、关键路径、质量真值据实保留。不能用 Python 任意精度大整数或任意 float64 扩展域反例冒充受限宿主秩域故障；扩展域研究仍有价值，但必须单独命名并提供回退。
