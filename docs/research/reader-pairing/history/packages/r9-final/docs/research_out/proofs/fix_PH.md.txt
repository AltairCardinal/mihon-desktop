# 修复轮 PH：N01/N06 的任意规模证明与全称结论审计

代码：`candidates/fixPH_bounds.py`；原始数据：`results/raw/fix/PH/{n06,n01,s02_maximality}.json`
（`bench/run_fixPH.py n06|n01|s02`）；测试：`tests/test_fixPH.py`。冻结规则为 `reference.py`（未修改）。

## 1. 参数化族 P_n(V)

取任意三个不同的非空秩 V0 > V1 > V2 ≥ 0。P_n(V)：n 个对象，分析全部 computed、NARROW、side UNKNOWN；
settings automatic=True、direction AB、opening AUTO，无 pin/isolate；边 e（对象 e 与 e+1 之间）的秩 = V[e mod 3]。
该族在 ext、nonneg、G0（0.04/0.02/0.00）各域中合法，也可在服务适配器中实现（x_{i+1} = x_i + V[i mod 3]，
rank = |x_i − x_{i+1}|，整数 V=(3,2,1)）；四组取值都做了可执行检查。

**事实 F（直接读 `reference._Scan`）。** 在 P_n 上：
(a) 1 ≤ i ≤ n−2 时 `allowed(i)` 为真（全 NARROW、无 forced/manual、resolved=UNKNOWN 不触发 automatic 拒绝、
side 不等于 leading/trailing）；`allowed(0)` 为假（opening=AUTO 时要求 side(1)=trailing，而 side(1)=UNKNOWN）；
`allowed(n−1)` 为假。
(b) 1 ≤ i ≤ n−3 时 `strength(i)=strength(i+1)=0`，于是 `later_wins(i)` ⇔ d_{i+1} < d_i（d_e 为边 e 的秩）。
(c) `step` 在游标 (i, o, r)：若 allowed(i) 且（i = r 或非 later_wins(i)）则输出对 (i, i+1)，游标到 (i+2, False, r)；
否则输出单元 {i}，游标到 (i+1, o, i+1)（i>0 且 allowed(i) 时保留 i+1）。在 i = r 时 `later_wins` 不被求值（短路）。
单元 {i}（1 ≤ i ≤ n−3、allowed、later_wins）的 reason 为 RANK_BOUNDARY（之前的分支 WIDE/FIRST/ISOLATE/TAIL/
OPENING/BEFORE_WIDE 均不成立）。

**引理 P（相位）。** 称游标 (j, o, r) 自由，若 r ≠ j。
- 原输入 P_n：游标从 (0, True, −1) 出发，输出 {0}（FIRST），到自由游标 1。对每个自由游标 j = 3k+1 ≤ n−3：
  d_{j+1} = V2 < V1 = d_j，故 later_wins(j)，输出 {j}，保留 j+1；在 j+1 处 i = r，输出对 (j+1, j+2)，到自由游标 j+3。
  归纳得：p ≥ 1、p ≤ n−3 时，p ≡ 1 (mod 3) 为单元 {p}，p ≡ 2 为对 {p, p+1}，p ≡ 0 为对 {p−1, p}（相位 A）。
- 编辑输入 P'_n（只把 d_1 改为 V2）：自由游标 1 处 d_2 = V2 = d_1，非 later_wins，输出对 (1, 2)，到自由游标 3。
  对每个自由游标 j = 3k ≤ n−3（k ≥ 1）：d_{j+1} = V1 < V0 = d_j，输出 {j} 与对 (j+1, j+2)，到自由游标 j+3（相位 B）。
- 对每个 p ∈ [1, n−3]，相位 A 与相位 B 中 p 所在单元（作为对象集合）不同（逐个余数类比较即得）。∎

可执行：n = 6…60 及 64…300（步长 12）× 4 组取值，闭式与 `reference.complete_plan` 逐位置一致，且 [1, n−3]
全部改变（`n06.json`：all_lemma_ok = all_positions_changed = true）。

## 2. N06：影响半径不可能有常数界（对所有 R 证明）

**定理 N06-PH。** 对任意常数 R，取 n = R+6。P_n 与 P'_n 只差一个事实（rank 1:2），而对象 n−3 的单元不同；
对象 n−3 与被改事实（对象 1、2 之间）距离为 n−5 = R+1 > R。所以任何与冻结规则逐输出相等的规则，
其输出在位置 q 不可能只依赖 [q−R, q+R] 内的事实：**精确 ⇒ 无常数影响半径**。R 任意，结论对所有 R 成立。∎

**插入与顺序（三角其他两边，分别说明）。**
- *前端插入稳定性*：在 P_n 前插入一个对象（新边秩 V0），旧对象按 id 计，有 n−1 个的单元改变
  （n = 8…128 实测 n−1/n；由引理 P 同样的相位论证可证对所有 n 成立：旧对象 k 位于新位置 k+1，
  新链从自由游标 1 起处于相位 A，因而旧位置 p 的单元按 p+1 的余数类重排）。精确规则必然继承这一点。
- *追加（在线）稳定性*：**成立，延迟 3**。窗口引理（step i 只读 [i−1, i+3]）⇒ 在末尾追加对象后，
  位置 ≤ n−4 的单元不变。1 500 个随机输入（含 pin、isolate、各种开局）实测改变的位置都 ≥ n−2（`n06.json#append`）。
  R9 把"插入稳定"写成一般不可兼得，过宽：前端插入不稳定是事实，在线追加稳定是事实。
- *顺序无关（解释为镜像等变：反转对象顺序并交换 AB/BA）*：冻结规则不满足（500 个无设置混合的随机输入中 169 个
  不等变；P_10 不等变）。任何精确规则同样不满足。
- 结论（收窄后）：仅"精确"一条就已经排除常数半径和前端插入稳定性；在线追加稳定性与精确相容；
  不可能三角的正确表述是"精确 ⇒ ¬常数半径 ∧ ¬前端插入稳定"，而不是三者对称地不可兼得。

R9 的放宽数据（LMP 半径 3、6.85% 位置不同；重启式规则半径无界；强制切分 cut8/cut16 半径 ≤ L）不受影响。
R9 O02-L（差分输出每次翻转 Θ(n) 个单元，只测了 n=1024）现在由引理 P 对 P_n 族的所有 n 给出证明。

## 3. N01：证书复杂度（对所有 t 证明，族内精确值）

框架：部分证据 = 已知事实集合；证书 = 事实子集 S，使所有与 S 一致的补全中目标单元相同（Ω 语义，`omega.certify_exact`）。

**敏感性引理（标准）。** 若世界 w 与 w' 只在事实 k 上不同且目标单元不同，则 w 的每个证书都含 k
（否则 w、w' 都与证书一致，单元却不同）。故 C(f, w) ≥ |{k : k 在 w 处敏感}|。

**定理 N01-PH。** 在 P_n（n ≥ t+4）上，对象分析全部已知时，目标 t ≥ 1 的最小秩事实证书大小恰为
2⌊(t−1)/3⌋ + 2，即 Θ(t)。
*证明.* 令 j(t) = t − ((t−1) mod 3)（t 所在相位 A 块的自由游标）。
(i) 下界：对 j' ≡ 1 (mod 3)、j' ≤ j(t)，把 d_{j'} 改成 ≤ d_{j'+1}，或把 d_{j'+1} 改成 ≥ d_{j'}，都使自由游标 j' 处
非 later_wins，输出对 (j', j'+1)，此后进入相位 B（与引理 P 同一论证，起点为 j'+2 ≡ 0 mod 3 的自由游标），
从而 t 的单元改变（对 j' = j(t) 直接比较三种情况 t = j, j+1, j+2）。所以 E(t) = {e ∈ [1, j(t)+1] : e mod 3 ∈ {1,2}}
中的每个秩事实都敏感，|E(t)| = 2⌊(t−1)/3⌋ + 2。
(ii) 上界：固定 E(t) 中的秩后，在任何补全中扫描都沿相位 A 走到 t：自由游标 j' ≡ 1 只比较 d_{j'}, d_{j'+1} ∈ E(t)；
保留游标处 `later_wins` 被短路；边 0 从不被读（allowed(0) 为假，reason 先判为 FIRST）；e ≡ 0 (mod 3) 的边在相位 A
中从不被读；j(t)+1 之后的边不影响 t（窗口引理）。故 E(t)（加对象事实）是证书。∎
可执行：t = 1…60（ext）以及 G0、nonneg、适配器整数在 t = 5、13、29：敏感集合与预测逐项相同，精确 DP
（其余边全部未知）对 E(t) 认证同一单元，t ≤ 40 时去掉任一元素都不再认证（`n01.json`：all_match = true）。
若对象事实也未知，证书至少还要包含它们，上界为 support_keys 的 O(t)（R9 引理 S-1）——Θ(t) 不变。

**与自适应决策树深度的比较。** 任何自适应查询策略在世界 w 上结束时，已查询的事实就是 w 的证书，所以路径长度
≥ C(f, w)；对 P_n，自适应深度 ≥ 2⌊(t−1)/3⌋+2，**自适应不能绕开这一长依赖**——它是信息限制，不是特定算法的
重复工作。"跟着扫描读"的策略在 P_n 上恰好查询 E(t)，达到下界。小规模穷举（变量 = 边 1…t+1，取值 {V0,V1,V2}）：
t = 1…6 时最优最坏情况深度 D(f) 与最坏世界的证书大小 max_w C(f,w) **相等**（2,2,4,4,6,6），P_n 世界的证书等于公式值
（`n01.json#exhaustive_certificate_vs_depth`；t=6 用时 129 s，t ≥ 7 未穷举）。这只是 t ≤ 6 的有限观察，
不主张 D = max C 对一般 t 成立。

范围：Θ(t) 是**族内**结论（对该族所有 t 成立），不是对所有输入的结论——相位复位处的目标可以有 O(1) 证书（R9 已注明）。
