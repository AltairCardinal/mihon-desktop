# WP-C: structures, selection, output, witnesses, persistence, reduction

Evidence layers: core (work units, deterministic), coupled (virtual u via `coupled_runner.Runner`), local wall
(single trials on a shared 2-vCPU box, never formal timing). Work = scan steps + resync steps + 5*leaf evals;
node compositions are excluded (favours trees). Proofs/limits: `proofs/wpC.md`. Raw: `results/raw/wpC/`;
compact tables: `results/summary/wpC/summary.md` (generated by `candidates/wpC_summarize.py`).

## Main findings

1. **No structure dominates the r8 incumbents across regimes.** r8 resync is best on local updates (n=1024: 1007
   work), the eager r8 tree is best in work on flip and alternation (n=1024 flip 8120). The new mechanisms win only
   inside named regimes:
   - *Lazy build* (LazyTree / PrefixScan / Hybrid) wins when queries are sparse: W03 400 updates + 1 far query costs
     n-1 vs 12845 (eager tree, n=1024); with 0.02 queries/update prefix rescan is best (4427 vs 18005 eager).
   - *Hybrid* (resync with cap, promote to lazy tree, quiet-probe demotion) is a robustness mechanism: within
     1.2-1.65x of the better incumbent on local and on flip, 29x better than resync on flip (10598 vs 307200),
     but it thrashes under short alternation (28067 vs 8720).
   - *Never-demote layered index* (SkiKeep) fixes short alternation (n=512: 9542 vs hybrid 62101) and loses on
     flip-then-local (11942 vs 6485). The X06 interaction of "ski promotion + quiet demotion" is strongly negative.
2. **No competitive bound.** The ski-rental style selector is driven to 3.49-3.76x model OPT by an adaptive
   adversary; the hybrid to 4.25-4.49x. Grid-tuned parameters do not transfer to held-out workloads (P04). Advice can
   be separated from correctness exactly (P06), and its damage is bounded by a switch-rate limit.
3. **Order changes:** a rope with window recomputation is exact under ordinal-free settings (lemma C04-1) and cuts
   leaf work 25x per order change at n=1024, after an O(n) one-time parse. Three counterexamples mark the boundary
   (ordinal reuse, pinned ordinals, stale certificates after replace).
4. **Differential output** is a new consumer interface: 71 vs 76555 output entries on local updates, but on phase
   flips any per-item diff is Omega(n) per update (proved lower bound) and loses to full output by ~1.5x. One shared
   DiffPlan serving point/full/prefix views beats dedicated structures in work (C06/X09).
5. **Witness derivation:** a prefix-normalisation cache that respects the operator's early-null exit dominates both
   separate per-pair derivation and eager fusion in normalisation count (mixed 6361 vs 8736 separate vs 18000 fused),
   with exact outputs. Direction labels are mandatory in any value cache (X13: 199/200 wrong without).
6. **Coupled D4 (indexed consumer):** a complete-prefix gated index (lemma C-I1; radius evidence: r=1 is unsound,
   72/900 disagreements) is the first full-information structure that pays in the coupled path, but only on
   long-lookback chains: held-out W01 n=96 certification steps 10329 -> 744 with identical publications, latency and
   admissions (wall 995 -> 787 ms, single trial); W01 holes=4 5921 -> 1779 (572 -> 361 ms). It loses wall time on
   W05 (92 -> 265 ms despite 482 -> 143 steps) and RP sparse (no index wins, +47% wall), so the adoption boundary is
   "index wins / requests" observable at run time; fallback = L0 owner path.
7. **Persistence (hypothesis branch):** strict content keys are exact; short hashes and capability references fail;
   cross-owner proof migration is sound iff all support keys and identity re-validate; shared caches leak membership
   (advantage 1.0). None is adopted as a default.
8. **Reducer:** ddmin + structural shrink reduce a 120-event / n=128 cost reversal to 16 events / n=10 with the work
   ratio reproducible across processes (3.152 x3).

## Gaps (true remaining work)
- No formal timing campaign; all wall numbers are single local trials.
- Node-composition cost is not in the work unit; a weighted unit could change tree-vs-resync verdicts.
- C-I1 sufficiency of radius 2 is open; the selector policy's D4 result is mixed (W06 latency 37 -> 28 is inherited
  from the existing strong gate; W01 holes=4 latency 16 -> 26).
- Q02 and X12 are synthetic-u models only; Q branch has no coupled-path measurement.
- Some intents are superseded under the runner's single-active-target semantics (published < intents on W01 holes,
  W06); identical across policies, but they are not served by any candidate.
