# 未知成本的参数化研究

本包没有提供真实获取、派生、排队或端到端时长。可执行 smoke 的时间只衡量 Python 虚拟宿主。下面是研究者应实现或使用的**合成情景**，不是已采集数据，也不是默认真实分布。

## 成本变量

令 A 为一次物理见证获取成本，D 为派生成本，Q 为认证/查询成本，V 为验证维护成本，B 为批次准备成本，S 为每单位驻留空间。时间可分解为固定启动和按数据量增长部分。一个获取可能服务多个派生，一份派生也可能服务多个逻辑需要。

工作到达、服务完成、接纳与资源归还使用事件图表示；并行总时间是受资源限制的关键路径，不能直接将所有 A/D/Q 相加。首个可靠结果、完整目标可发布和全部请求完成分别计时。

## 最少情景

| 情景 | 单位化条件 | 主要比较 |
|---|---|---|
| P0 纯计算 | A/D未建模，仅实际运行Q/V | 当前三项机制、增量与证明成本；不换算实际等待 |
| P1 获取主导 | A/Q取10/100/1000，D/Q独立变化 | 多证据共用、预取、较强证明的取证节省 |
| P2 派生主导 | D/Q取10/100/1000，A可复用 | 共同中间特征、渐进派生、方向/变换共享 |
| P3 维护主导 | 变化频率逐渐超过查询频率 | 精细索引、版本戳、证明缓存是否反而昂贵 |
| P4 排队与偏斜 | 单个任务比其余慢10/100倍，C=1/2/4 | 无整批屏障、不可抢占取消、前台突发 |
| P5 驻留受限 | M/R分别很小、略小于工作集、足够大 | 缓存/重取、证明空间和物理驻留的交互 |
| P6 非平稳环境 | 顺序→反向→跳转，失败相关或突发 | 在线门控、预取、自适应策略的漂移损失 |

这些数是无量纲的敏感性网格。若用 u 为模拟时间单位，明确 u 未标定；不要把 100u 擅自写成 100ms。对参数先做小范围单因素，再扩展可能改变排序的关键交互，避免机械穷举所有组合。

## 必须报告的条件式

对候选给出类似以下的、由实际账本支持的表达式：

```text
额外构建/维护/证明成本 ΔC
省去的不同物理工作集合 W_saved
新增或重复的工作集合 W_added
资源重叠后的关键路径变化 ΔT_path
峰值空间变化 ΔS
```

简单串行情景可推导 ΔC 与各类工作节省的盈亏条件；有并行和排队时，必须用事件图或正确的调度模型，不能将该串行公式直接套用。所有前提、失败概率、命中规律和时长界均须显式。

如果能识别“Q再降到0也最多省多少”，就把它作为研究价值排序依据。若主导成本未知，交付参数区域决策表和最小补测清单，不编造真实瓶颈。
