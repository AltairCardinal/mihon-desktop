# 潜在见证：已核实子域与尚未刻画部分

本文件描述一个已核实的见证派生子过程，不是整个联合生成域的完备刻画。不能据此宣称任意标签/秩序列均可实现。

## 三种不同接口域

- **G0：见证派生子域。** 有限通道样本经下述规范化、筛选和距离产生数值秩或已知空值，数值秩具有量化来源。
- **G1：有界候选接口。** 接受有限且 `0≤r<30` 的外部候选，接口不强制量化。量化证明只能用于已保证 G0 来源的场合。
- **G2：冻结参考的通用标量扩展域。** 用于规则差分，包括有限负值、大值、空值等，不声明均由 G0 产生。Python整数与其他运行时Double也须分别对待。

## 精确数值子过程

每对象 i 有向量 L_i、R_i，各50个元素。每元素有三个整数通道及一个覆盖参数，都取值0…255。令 U=255，逐通道规范化为：

```text
N(c,a) = floor((c·a + U·(U−a) + 127) / U)
Xhat[k,j] = N(X[k,j], aX[k])
Yhat[k,j] = N(Y[k,j], aY[k])
d(X,Y) = (1/50) Σ(k=0…49) Σ(j=1…3) |Xhat[k,j]−Yhat[k,j]|
```

规范化通道仍为0…255整数，覆盖分量固定为U。理想距离属于 `{m/50:0≤m≤38250}`。只在 d<30 且过滤未触发时保留数值秩，所以 G0 的数值属于 `{m/50:0≤m≤1499}`。Double表示仍可能舍入，不能当作无限精确实数。**0是合法秩，不等于空值。**

方向 AB 使用 `d(R_i,L_(i+1))`，BA 使用 `d(L_i,R_(i+1))`。交换同一对向量的距离对称，不意味着同一对象边的AB与BA相等。

## 已知空值过滤

任一过滤触发就是已完成判定的空值，不能混作未观测：

- 两端向量都为上饱和：每端至少40/50个元素的三个规范化通道最小值>220。
- 两端都为下饱和：每端至少40/50个元素的三个规范化通道最大值<50。
- 两端加权投影的总体方差都<100；投影为 `0.299·v1+0.587·v2+0.114·v3`。
- d≥30。

完整占用状态还可能按结构规则直接给出空关系，优先级以冻结参考为准。未取得有效端点分析或必要证据仍是未知。

## 向量与空间来源

一个已核实的采样子过程使用有限二维通道张量及离散坐标变换。原尺度必须为正；定向后w>h不产生边样本。w≤h时两侧位置为 `min(2,w−1)`、`max(0,w−3)`，纵向位置为 `floor(k·h/50)`，k=0…49，再逆映射到原来源。

小尺度会使两侧重合或采样重复，任意独立L/R赋值未必可实现。采样允许条件不等于规划可成对条件；w=h的占用分类仍以冻结规则为准。

方向性标签来自共同潜在来源与变换的另一组采样/判定，不是只凭L/R即可重建的公开子程序。秩的规范化也不能未经证明套到标签过程。

**不能由共同来源推出所有相邻秩有某个固定数值关联。** 同方向相邻边使用中间对象的不同向量。只有明确共享同一规范化向量的距离组才能应用相应度量关系；过滤成空值后的秩不是完整距离度量。

## 知识与驻留

一个真实基线所有者的原始向量驻留容量在2…16。接纳时相邻向量均驻留，就能计算并缓存两方向标量，包括空值。raw驱逐只移除向量与来源标志，已确认的标量和对象分析可以继续存在。

相关身份/元数据变化撤销对应项；close清空。重绑定只复制身份精确未变的对象及双端都未变的关系。虚拟Host不完整实现这些物理生命周期，见 `MODEL_API.md`。

## 仍未刻画

全部L/R、标签、几何与变换的联合可实现集合；所有尺度/坐标重合关系；真实来源、访问、到达、失败和服务分布；以及14个导出案例之外的普遍实际可实现性。

E1/E3/E6可研究这些关系。更大保守域上的唯一性仍可能形成可靠证书；以两个世界证明实际信息下界时，必须给具体构造或充分可实现性证据。缺少它就明确条件化。
