# Ordered system: deep research package

这是匿名、自包含的一次性研究委托，包含48个主课题、12个组合挑战及可执行基线。

从 [START_HERE.md](START_HERE.md) 开始；可执行委托见 [OPUS_PROMPT.md](OPUS_PROMPT.md)。先按 [RUNNING.md](RUNNING.md) 检查环境，研究门槛见 [RESEARCH_QUESTIONS.md](RESEARCH_QUESTIONS.md) 和 [DELIVERY_TEMPLATE.md](DELIVERY_TEMPLATE.md)。

参考规则、虚拟宿主、生成域和合成协议的权限与证据不同，边界见 [MODEL_API.md](MODEL_API.md)、[GENERATIVE_DOMAIN.md](GENERATIVE_DOMAIN.md) 和 [PACKAGE_VALIDATION.md](PACKAGE_VALIDATION.md)。
