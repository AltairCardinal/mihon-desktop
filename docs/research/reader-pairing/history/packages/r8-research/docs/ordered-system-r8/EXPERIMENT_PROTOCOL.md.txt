# 实验、证明与成本协议

## 1. 冻结与范围

研究前记录包内源码内容指纹、可执行环境、命令和可用资源。新增实现放 `research_out/`，冻结 oracle、原始夹具和已有结果。原型可复用 oracle 的扫描实现来验证表示变化，但这种复用不是独立数学正确性证明；算法替代需独立完整结果或可检查推导。

每个结果必须绑定具体代码、参数、输入和证据层。匿名宿主投影只支持其列出的字段与案例；不能把它升级为全规则、完整运行环境或生成域完备证明。

## 2. 证明先说明域

分别声明：合法常规输入、为接口健壮性定义的扩展域、带原始见证的生成域。无效指定连接等扩展输入不得计入正常收益。

证明完整字段等价时包括成员、顺序、槽、原因与确定性；L0 还核对需求与失败等接口观察。证明更早认证时须检查所有允许完整补全，而不是只检查当前已观测世界。过近似唯一可以支持子域唯一；过近似歧义不能直接证明子域歧义。

有限枚举通过只能报告具体范围。正式命题须写前提、充分状态、不变量、转移、终止/预算与最坏成本；必要时提交反例而非强行证明。

## 3. 固定外生事件与公共失败身份

在策略执行之前固定请求意图、输入变更、外部约束和环境参数。所有候选使用同一外生事件序列；候选只获知已经发生的事件及当前合法知识，不能读取未来轨迹、隐藏完整事实或评价 oracle。

内生工作次序在 L1 中可以不同，因此不能强行要求所有任务事件完全相同。对共同物理任务身份及其合法 attempt，服务成本、失败和结果须一致。失败键至少区分上下文、物理内容、变换/方向、算法版本与该身份的尝试号；不能由共享随机流的第几次调用决定。

逐条比对共同外生事件和公共失败键，保存完整事件或可复算生成规则及指纹。相同 seed 不足以证明输入公平。明确重试是否改变 attempt、失效是否换身份、共享工作如何计费。

## 4. 强基线与消融

默认比较当前保留三项机制的基线。冻结参考的逐次深复制、旧分支器或默认全关只是辅助对照，不能作为唯一竞争者。

每个新构件和关键组合单独消融；显式构造配置，不让默认值变化污染 baseline。区分同代码消融与历史版本前后比较。新机制若要求两组都维护一个新索引/计数，报告此安排没有测出该维护相对历史实现的成本。

至少包含冷构造、热重复、多目标、相关/无关变化、失败恢复、驻留驱逐、重绑定/关闭及预算退化中与机制有关的阶段；不能只展示最容易受益的一段。

## 5. 完整工作与空间账本

总成本从请求意图开始，至少计入准备、结构建立、获取、派生、证明、验证、更新、取消后剩余工作、废弃完成、输出和回收。一次物理工作可以服务多个事实，不能按逻辑需要数重复收费。

分别给出：

- 真实测得的计算 wall time，必要时单列 process CPU time；不得混称。
- 配对请求与端到端意图延迟的定义；并行重叠用事件时间线/关键路径计算。
- 实际物理工作启动次数、数据量和派生次数；模型没有的项目写 missing。
- 分配、峰值活跃、稳定驻留和结构条目数；它们不是同一个指标。
- 构造与维护成本、被拒尝试、失效/取消浪费、预算触顶次数及最坏退化。

Python 的 tracemalloc 峰值不是其他实现的分配字节。计时与分配仪器互相干扰时分开运行，同一配置和输入保留关联；不要把所有平台指标合成一个没有解释的分数。

## 6. 重复、噪声与公平结论

先小试确认资源范围和语义，再对进入 D3 的候选做至少 3 个串行独立进程的正式重复。记录真实 PID、UTC 时间、代码指纹、命令、配置、原始输出、预热与重复数；缺少元数据就如实写缺少，不补造。

配置顺序轮换，按同进程、同输入、同阶段、同重复配对。先给各进程中位及范围，再给跨进程汇总；不能只挑最快一次，也不能把同进程许多重复当许多个独立机器实验。

正确性/预算失败不能从统计中删除。超时和内存触顶作为删失或失败单列，不按 0 耗时计入。不用模拟长 sleep 产生“真实等待测量”；模拟时钟结果明确标记为 synthetic。

当改动没有超过噪声，结论为未显示稳定提升。报告绝对量、变差场景及维护代价；不把算法内部加速百分比当端到端体验百分比。

## 7. 参数缺失与敏感性

尚无真实获取/派生时间、队列分布或访问频率时，不停止所有研究。给单位化成本、上下界、参数化 break-even 及几种明确合成情景；参考 `COST_PROFILES.md`。每个条件结论写出反转点，不能静默选择对候选最有利的假设。

在线预测器的训练、调参和评价分离；对非独立失败、漂移和对手轨迹作压力检查。未提供外部真值时，L2 只能比较结构性质、规则差异和成本。

## 8. 去留与停止

先过硬合同，再比较时间、空间、实际工作和维护复杂度的 Pareto 关系。被严格支配者不保留；某区域占优者标明条件，不能当默认普遍赢家。组合与构件全部负结果也可收口。

每题停止的合理理由是：已形成足够证据、具体反例、证明了限制、达到已声明的实验资源边界或确有缺失前提。只有概览、尚未编程、运行了两小时、题目很多，不是完成理由。达到预算时交付真实进度和恢复命令，禁止把未跑项目写成通过。
