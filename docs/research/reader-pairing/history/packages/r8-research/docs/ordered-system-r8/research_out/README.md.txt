# research_out — 第三轮研究成果目录

- `REPORT.md`：总报告（先读）。
- `coverage.csv`：48 主课题 + 12 组合 + 7 新假设的逐题证据索引（DELIVERY_TEMPLATE 列）。
- `sections/`：逐题正文（core = 主会话族，hosts = 宿主缓存族，protocol = 协议族，new_hypotheses）。
- `proofs/`：定义、引理、条件定理、最小反例。
- `candidates/`：候选与研究代码（标准库）；`tests/`：差分、oracle、变异与协议测试（55 项）。
- `bench/`：实验与正式计时驱动；`results/`：原始记录与汇总（`results/formal/` 为三进程正式计时）。
- `fixtures/`：冻结的外生轨迹、反例夹具。
- `REPRODUCE.md`：复现命令与继续入口；`CONVENTIONS.md`：内部工作约定。
