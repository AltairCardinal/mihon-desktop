# 交付验收范围

本文件说明研究包本身的验收边界。48主课题与12组合挑战是接收者将执行的研究，不是制作包时已经完成的优化。

## 独立证据

- 初始代码通过白名单ZIP、干净目录解压的34项标准库测试及三配置小smoke，没有注入上级模块路径。
- 整合发现自定义轨迹没有close事件时，cleanup已计时但计数快照提前取得。先以 `0 != 1` 确认红，再最小修复；事件测试5项与smoke通过。修复后的最终代码再次经独立白名单ZIP、全新解压验证：35项测试全部通过，三个显式配置的smoke结果一致，工作计数包括末尾cleanup调用。
- 14个独立真实核心合成案例共22项投影核对：状态、成员/槽、确定性及选定失败，另有8份完整计划投影。不证明reason、needs、读集、memo/stamp或更新/重绑定接线等价。
- 另有270次有限标量定向差分，经过JSON往返、两方向和三配置；仅覆盖标量扩展域，不证明物理生成域完备。
- 同target不相交替换、跨target重叠、取消未退出、完成未接纳及旧完成等协议负例有回归。可信单调epoch是环境前提，不是通用ABA防护。

## 不能外推

模型不包括完整获取/派生、外部I/O、真实调度器、原生事件、确认/持久化或整个运行环境。研究测试不是外部产品的全量验证。

smoke只检查可运行与配置一致性，不是性能结论。三解释器入口供后续研究使用，不能把一次smoke说成已完成三进程正式测量。真实成本分布仍为missing/null。

源语法目标为Python3.10+，实际本地验证使用Python3.14，未逐版本、逐系统运行。仅依赖标准库，不需要账户或联网。

## 匿名与完整性

仅导出中性文档、代码、测试、合成夹具与清单。不含私有provenance、原项目文件、名称、真实路径、提交、用户/会话信息、bytecode或缓存目录。

交付者进行人工接口检查、有界敏感词/路径扫描、白名单、相对引用与归档哈希核对。最终独立检查中，隐私/真实路径扫描与相对Markdown链接缺失均为0；48主课题及12组合挑战编号完整唯一。检查支持未直接披露具体标识的范围，不是无法从数学结构猜测应用领域的形式化保证。

`MANIFEST.json` 列出除自身外每个导出文件的SHA-256和字节数。最终ZIP哈希在包外保存，避免自引用。执行入口见 `RUNNING.md`，研究入口见 `START_HERE.md`。
