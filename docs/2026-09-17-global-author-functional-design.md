## 1. 产品规则

**相同名称文本就是同一个作者，跨所有插件自动统一。不同名字才需要合并。**

| 输入 | 默认结果 |
|---|---|
| 漫画柜和其他插件都署名“冈本伦” | 自动进入同一作者页，不弹身份选择，不要求关联来源 |
| 只有“冈本伦”文字，没有作者编号或链接 | 同样自动进入该作者页，不产生待确认事项 |
| “冈本伦”与“岡本倫”或“Okamoto Lynn” | 不同名称，初始为不同作者；可通过“添加别名”统一 |
| 不同名字已被合并 | 任意插件以后出现其中任何名字，自动复用该作者 |
| 新出现的非空名字 | 自动创建一位作者，无需首次身份确认 |
| 没有姓名/全为空白 | 显示作者未知，不建统一的“未知作者”实体 |

精确比较单个解析后的姓名文本，不自动做繁简、大小写、标点或音译转换。搜索的宽松匹配不等于自动合并。系统不提供同一文本按来源、作品或真实人物分开的选项，这是产品定义。

## 2. 入口与页面结构

Windows 保留底栏“作者”；Android 保留“浏览 → 作者”页签，不新增底栏。漫画详情的作者署名是主要入口：点击后直接进入唯一作者页。

作者列表页（Windows底栏「作者」、Android「浏览 → 作者」）右上角提供全局「作者设置」齿轮。作者详情页显示主名称、可点击别名（仅有别名时显示）、作品/版本数量、关注、「添加别名」、作品列表及来源筛选；详情不再提供检查频率设置按钮。来源仅帮助找作品，不划分作者。作者列表不显示头像。列表只显示活跃作者，各主名来自其独占名称集合，不出现三行同样的“冈本伦”。

删除原型中的“选择同名作者”“整理同名档案”“关联其他来源”“文字署名待确认”“同名不同人”“来源身份依据”等入口。新增同名作品时自动加入，无确认弹窗或逐来源开关。

## 3. 默认主流程：点击即达

用户路径：《平行天堂》→ 点击“冈本伦”→ 一个作者页 → 查看所有已收录来源中的作品与统一关注。

历史三个“冈本伦”由系统自动收敛；进入作者页不需要用户挑主档、核对 ID 或确认他们是同一个人。自动整理保留原作品、旧入口和关注；成功直接进入详情，不增加常驻说明或确认；真实存储迁移正在进行或失败时，显示准备/重试，不能退回同名选择框。

新作品加载得到已存在名称时，自动出现在作者集合。即使来源不同、站内编号不同或没有编号，行为都一样。操作不需要额外取证请求，不因来源作者网页无法打开而阻断已知作者页。

自动收敛后的关注保留已有启用状态，检查周期统一读取全局作者设置，不再保存每作者周期；作品不丢失。只保留原已有订阅设置，不为迁移启用新的通知渠道。原型不在作者页常驻显示自动归集或检查频率说明；正式实现须完成设置迁移验收。

## 4. 添加别名直接生效

入口：作者详情 →「添加别名」→ 搜索/勾选其他名字 →「添加」。不再出现合并预览、主名选择、返回预览或二次确认窗口；按钮文字为「添加」。

窗口展示其他作者名称、代表作品和关注状态，支持搜索及多选；当前作者已有名字不再列为候选。零选择时添加按钮禁用并给出原因，无其他名字时显示空状态。搜索保留已选项，选择窗口中简短说明添加后这些名字将共用作者。

点击添加即将所选作者的全部名称与作品关系归入当前作者，保留当前主显示名，关注取所选作者的启用并集；全局频率不改变。成功关闭窗口、刷新详情与作者列表并显示简短结果。其他未选作者不变。之后任何插件使用这些名字都自动复用同一作者，来源漫画保留原始署名。

取消、Escape、蒙层不写入。提交失败保留选择及原数据；选择窗口打开后资料发生变化，提交被拒并提示刷新候选，仍在同一个添加窗口更新有效选择及数据，用户再次点击添加，不增加预览步骤。新增候选不能自动勾选，重复提交不得产生重复作品或身份。

生产合并必须写入原子事务与本地恢复记录，失败无部分修改；错误关联的恢复边界见第10节。这些内部保护不增加预览或确认步骤；原型不生成真实备份。

## 5. 名字与关注的后续管理

主名是显示选择，其他名字仍属于同一作者。关注只需一次，任意来源或别名进入都显示同一状态；取消关注需要确认，并说明会停止关注该作者而保留作品和名称关系。

既有别名管理和拆分能力需要遵守新规则：新增已被其他作者占用的名字通过「添加别名」关联；拆分只能将某些不同名称整体迁到另一作者，不能把同一个名字分别留给两个人或按图源例外处理。本次原型覆盖添加已有作者为别名及主显示名称修改，不实现完整别名删除/拆分器。

### 从别名设置显示名称

移除「修改名称」按钮及自由输入/下拉选名窗口。作者详情中的每个别名独立显示为可点击项，无别名时不显示占位行。别名与漫画详情署名统一采用原版Mihon作品详情的 `titleSmall` 排版：14sp、Medium、20sp行高、0.1sp字距，16dp人物轮廓图标与4dp间距，正文色及0.78次级透明度。主显示名称去掉前置图标，使用与漫画详情作品标题一致的字号、字重及正文颜色，不降低透明度。别名在主名下方横向排列、空间不足换行，保留人物图标及点击确认交互，键盘焦点可见。漫画页仍显示来源原始署名，作者详情展示主名与别名集合。

点击任一别名XXX，弹窗正文为「要把XXX设为该作者的显示名称吗」，提供「取消」和「确定」。确定后该别名成为主显示名，旧主名转为可点击别名，其他别名保持不变；作品、关注、根身份和全局检查频率不改变。

取消、Escape或蒙层关闭不写入，焦点返回点击的别名；确认成功后该项已成为标题，焦点移到主名称标题，并显示简短结果。失败保留原主名与确认窗口。本入口只选择当前作者已有别名，不允许输入新名称或占用其他作者名称。旧作品署名始终进入同一作者。

### 全局作者设置

作者列表页右上角 → 齿轮「作者设置」→「检查频率」→ 每天/每周/每月 →「保存」。一份设置统一应用于全部现有与未来作者，不在作者详情页设置，不为每位作者保留独立频率。默认每天，每月按日历月语义；原型只保存设置，不执行真实调度。

修改频率不改变任何作者的关注状态。未关注者仍不触发检查；以后关注时使用同一全局频率。添加别名、修改主名、自动同名收敛以及新增作者都不得重置该设置。

打开窗口读取全局保存值，选项修改草稿；取消、Escape和蒙层关闭不保存。保存成功反馈并将焦点返回列表页设置按钮，再次打开可读回；保存失败保留原值并允许重试。两端原型各自独立，不演示设备间同步设置。

### 页面文案精简

作者页不再显示自动归集规则说明、检查频率/全部来源/统一关注说明、无别名占位文字。作品卡不再显示「已确认同一作品 · 来源版本」说明，图源名称本身作为进入对应版本漫画详情的按钮，取消额外「查看漫画」按钮；同一作品的图源横向排列、可换行，封面缩略图与作品名称在行内顶部对齐。技术规则保存在本文和README，不需要常驻产品页面。

名称识别与作品识别独立。相同作者的作品不一定是同一本；只有已有作品对应关系时才折叠成来源版本。标题相同不自动合并漫画，不改变章节、阅读进度或下载。

## 6. 状态与反馈

| 状态 | 用户看到什么 |
|---|---|
| 同名自动命中 | 直接进入作者页，无额外确认或常驻自动归集文案 |
| 不同名字未合并 | 各自独立作者页，可主动发起异名合并 |
| 已合并别名出现新作品 | 自动加入相同作者，名称集合与关注保持不变 |
| 没有可合并名字 | 空状态及返回按钮 |
| 异名合并失败 | 现有关联未改变，可重试或取消 |
| 候选资料变化 | 原添加窗口提示刷新，更新候选后再次点击添加 |
| 来源不可用/插件卸载 | 保留作者、作品和关注，标记该来源不可用；本地已有详情可查看 |
| 同名自动整理失败（production） | 保留原数据，重试整理；不要求人工判定同名人物 |

作者关注同步开关不改变同名规则，不再设计“开启同步就禁止同名关联”的门槛。双端 HTML 的数据彼此独立，不承诺名字合并会在线同步到另一设备；正式同步集成边界见技术方案。

## 7. 双端交互细节

- 复用 Mihon 外壳、深浅主题、图标及平台导航。Android 适配320px，长内容内部滚动、操作按钮可达，无横向溢出。
- 对话框打开时焦点进入，Tab/Shift+Tab 循环；Escape 或蒙层关闭会话，焦点回触发按钮。添加别名不增加第二层预览。
- 每端数据、导航、筛选、滚动及焦点独立；另一端操作不能抢焦点或改变状态。主题切换只改外观。
- 成功反馈说明合并的名字/结果，错误解释原状态保留。来源 ID、portable key、置信分数等不进入产品流程。
- 同名自动规则是默认，不是需要用户勾选的“自动识别模式”。不同名字仍由用户决定是否合并，不用相似度自动混入。

## 8. 固定原型样本与演示控制

初始历史样本的三个“冈本伦”档案自动统一，对应《平行天堂》《极黑的布伦希尔德》《变异体少女》，跨漫画柜及演示文字来源；另有“Okamoto Lynn”与“岡本倫”两个不同名作者。原型中的来源和作品是固定样本，不是用户手机私有数据库快照。

“Okamoto Lynn”对应的 Parallel Paradise 与《平行天堂》在样本中预设已有作品对应关系；“岡本倫”也使用已有作品的另一来源版本。具体计数以 README 为准。异名统一不会由作者相同反推未知的作品关系。

应用外工具栏提供目标设备、场景切换、重置、深浅主题与320px；增加“加入同名作品”和“加入已合并别名作品”动作，分别模拟不同来源送来新署名，执行同一名称解析流程。未合并名字的新增作品仍归其独立作者；重复加入同一个演示作品应幂等，不能重复增加计数。

这些是演示控制，不放入产品操作区。不接网络、不抓站点证据、不读写真实应用；页面内存保存状态，刷新重置。普通场景外还覆盖无可合并名字、提交失败、候选资料变化、来源不可用。

## 9. 验收路径

以下是可执行的产品/原型验收路径，不表示正式应用已完成：

- 《平行天堂》→ 作者：直接进入统一“冈本伦”，不出现三个身份或手动整理。
- 应用外加入其他来源的同名作品 → 当前作者作品增加，作者数量和关注不变；重复加入不重复。
- 作者列表 → “Okamoto Lynn”与“岡本倫”：在明确合并之前保持各自独立。
- 冈本伦 → 添加别名 → 仅选择 Okamoto Lynn → 取消：两个名字和作品均保持原样。
- 同路径点击添加 → 一个页面展示两个名字，旧署名入口进入同一页，未选“岡本倫”仍独立。
- 加入已合并别名的新作品 → 自动加入主作者，不要求按插件重新关联。
- 详情点击别名 → 指定确认提示 → 确定：主名称切换，旧主名变为可点击别名；旧入口仍进入同一作者。
- 点击别名后取消/Escape/蒙层 → 主名不变，焦点回到原别名；无修改名称按钮或自由输入框。
- 作者列表页右上角设置 → 每天/每周/每月 → 保存并重开：选值保留并对全部作者生效；详情无频率入口，取消不保存。
- 设置后添加别名、修改主名或新增作者 → 全局频率不变，不产生单独作者设置。
- 失败/候选资料变化 → 无部分写入，在原添加窗口刷新后继续，无预览步骤。
- Windows 操作 → Android 状态不变；深浅主题、键盘、320px与零远端请求通过验证。

正式验收另须覆盖数据库并发、迁移中断、角色并集、备份往返和同步接收，并使用真实 Android/Windows 发布产物。HTML 不代替上述 production 验收。


## 10. 最终范围与设计权威

本文定义产品行为；技术方案定义共享数据约束；roadmap定义实施批次和完成证据。HTML提交 `77a610534` 定义已确认的信息层级、按钮、排版与操作路径。后续实现不得借技术接线恢复身份选择、合并预览、修改名称按钮、详情频率按钮或查看漫画按钮。平台原生对话框/字体度量可有差异，但语义与入口相同。

原型应用外工具、虚构封面/作品、内存状态和解释样本文案仅用于审阅，不移入正式应用。主名在生产中复用作品标题的主题排版，而非固化HTML的24/21px；别名复用原版署名字体。主名无图标、别名横排可换行、作者列表无头像、图源按钮横排和封面顶部对齐均为正式验收项。

| 本期交付 | 本期不新增 |
|---|---|
| Android与Desktop共享名称唯一约束、历史自动收敛、未收藏作品作者直达 | 逐图源人物规则、站点作者ID识别、相似姓名自动合并 |
| 添加已有作者为别名、别名确认切换主名、统一关注与全局周期 | 自由输入别名/主名编辑器、完整可视化拆分器、新作者头像系统 |
| 本地持久化、备份往返、现有关注同步兼容、正式运行验收 | 在线传播异名合并/主名偏好/检查频率的新同步协议、同步服务部署 |

“全局”指当前用户作者库内所有插件；不指互联网统一人物编号，也不保证不同设备的本地ID相同。已有作者发现、搜索、筛选、语言/来源限制、通知及其他Desktop独有能力继续保留，不能以原型未展示为由删除。已有删除、拆分、别名入口必须通过同一名称约束校验；不得按漫画子集将相同文本分给两个人。合法的不同名整体拆分继续复用既有入口；无法安全表达的旧动作给出原因并保持数据不变，不静默制造新身份。本期不设计新的拆分管理界面。

添加别名成功不附带撤销按钮。事务失败自动回滚；成功后发现误选，优先使用已有合法拆分能力或迁移前的应用备份恢复。恢复记录用于故障诊断与受控恢复，不承诺任意时刻一键撤销；恢复后仍须满足同名唯一规则，且不能覆盖其后新增记录。若当前入口无法满足这些约束，发布前必须明确其限制并通过回归，不能交付破坏唯一性的旧入口。

## 11. 持久化、计数与并发契约

- 使用现有Creator根、作品关系和旧键重定向；主名及接受别名登记在全局精确名称索引。作者姓名来自既有分词器的原始token，去分隔符边缘空白后精确去重，不使用搜索归一化结果做身份键。两个角色的同名token属于同一人，角色分别保留；不同合作作者不被带入合并。
- 空白/缺失署名走未知展示，不建共用未知实体。非空原始文本不由本功能猜测是否占位词；不新增语言相关的名字黑名单。图源修改署名时重新解析，不因外部ID未变自动建立别名，其他作品的原关系保持不变。
- 作品数按已有规范作品关系计数，来源版本数按已收录版本去重计数；没有确认作品关系的漫画各自计数。作者页显示本地已归档集合，不宣称已经覆盖全网作品。来源筛选和搜索仅过滤展示，不改身份、关注或完整集合计数。
- 添加候选按活跃根去重并排除当前根；候选携带版本快照。确认添加必须一次校验目标与全部选中根，任一过期则整组不写。刷新保留仍有效的选择，已经归入当前作者的选项移除，不自动添加新选择。
- 名称切换确认时重新检查根、版本和名称归属；已被其他操作改动则保持原数据、提示刷新再选。重复提交幂等，提交中禁用重复保存；结果不能因界面取消就假称撤回事务，已提交结果按真实状态回显。
- 提交成功之后重启读回主名、别名、关注和全局周期；旧漫画入口、旧portable key和已打开页面都订阅到当前根。自动收敛和添加别名不改章节、阅读进度或下载文件。
- 历史迁移以组为事务边界，名称连通分量稳定收敛；全组断电/异常不留半迁移。数据层未就绪时，作者入口显示准备/重试；其他阅读能力保持可用，不用空列表假装迁移完成。不在用户库上直接做破坏性试验。

## 12. 全局检查频率的确定语义

本节为正式调度实现约束，HTML只覆盖保存交互。

| 场景 | 规则 |
|---|---|
| 新安装/首次启用全局配置 | 默认每天；已有全局选择优先且迁移幂等 |
| 旧每作者周期升级 | 不把多份周期取最小或复制成多份全局值。没有新配置时统一设为每天；旧周期仅留恢复记录，后续调度不读取它。已有关注、来源/语言范围及通知开关保留 |
| 每天 / 每周 | 从该关注最近成功检查完成时间起加1/7个本地日历日，保留本地时刻；不是精确到点的系统闹钟承诺 |
| 每月 | 从最近成功检查时间加1个日历月，目标月没有该日则取月末；例如1月31日到2月末，下一次从实际成功时间重新计算 |
| 时区与夏令时 | 用设备当前时区计算，缺失时刻向后顺延到有效时刻，重复时刻取较早偏移；时区变化重新计算未来到期时间，已有成功时间仍按Instant保存 |
| 关注/从未成功检查 | 首次关注即可排入到期任务，不等待一天；恢复运行时合并过期触发，不按错过天数补跑多次 |
| 修改周期 | 保存后重算已关注作者到期时间，不取消正在执行的一次检查；新周期适用于其后计算。若已到期只排一次，不制造并发副本 |
| 失败、离线、来源不可用 | 不记成功；复用既有来源检查点、退避、任务约束与限流，不让周期变化绕开退避。单个来源失败不删除其他来源成功结果 |
| 取消关注 | 不再创建新的定期检查；已启动请求按现有安全取消边界收尾，结果写入前复查关注，不能继续发新的关注通知 |

共享计算器接受可注入Clock/Zone与已有检查点，两平台仅负责唤醒和系统约束。Android复用后台任务，Desktop复用现有scheduler；关闭应用/系统限制可能延迟执行，重开后补一次到期工作。全局周期是设备偏好，进入现有设置备份但不新增实时同步字段；恢复旧备份没有该字段时保留已配置值，仍未配置才用每天。有效新字段随用户选择的设置恢复范围导入，未知值不覆盖有效本地值并报告兼容问题。

## 13. 备份与现有同步的边界

备份必须完整保存精确名称集合、主名、根/旧键映射及关注；旧备份导入先收敛同名，再应用关系，不复活三个同名身份。新备份恢复到空库应还原名称与关系；恢复到已有库，名称交集先统一根，现有有效主名优先，空库采用备份主名，关注按既有恢复策略且不能因根重定向丢失。损坏引用、环、占用冲突无部分写入；未知新格式不能伪装导入成功。

本期只适配现有作者关注同步：先将可信署名/已有键解析为本地根，再投影FOLLOWING。仅有未知键且无名字时等待补全，不能猜测新人物。相同文本来自不同设备必须汇到同一根；远端名字不能当作显示名更新指令，也不能仅因同一个远端ID换了名字就自动把不同名称合并。别名与主名切换保持设备本地，异名合并记录只随明确的备份导入迁移；不隐含传播到另一设备。

开启关注同步不得禁止本地同名归集或添加别名。本机合并必须保留所有旧键映射；后续旧键关注事件路由当前根，继续服从现有因果冲突/移除语义，不以“合并关注取并集”覆盖后续明确取消。名字不足或协议不兼容通过既有同步异常/待处理入口反馈，其他类别不静默丢弃。若现有协议无法安全携带本期所需描述信息，先形成最小兼容变更与fixture，再接入；新增在线别名决策协议不在本roadmap范围。
