## 目标与页面契约

用户从作者详情浏览作品时，列表可直接辨认一部作品来自哪些图源；舒适网格和紧凑网格优先呈现封面、标题、日期和新作状态。所有模式点击作品均进入同一个「选择漫画源」窗口，再点击具体版本进入漫画。作者详情作品条目不出现 `Needs review` 直接按钮。

| 模式／对象 | 卡片上展示 | 点击与反馈 |
|---|---|---|
| 列表中的聚合作品 | 封面、标题、已有收藏/新作标记、**该组全部不同图源的名称**、日期 | 整条作品打开完整来源选择窗口；图源名称是文字，不是逐来源按钮 |
| 舒适网格 | 封面、标题、已有收藏/新作标记、日期；不显示图源名、图源数量或图源按钮 | 点击卡片打开同一来源选择窗口 |
| 紧凑网格 | 封面上的标题及已有标记、日期；不显示图源名、图源数量或图源按钮 | 点击卡片打开同一来源选择窗口 |
| 来源选择窗口 | 各版本的原始标题、图源、封面、章节/收藏/日期等既有信息 | 选择准确版本进入漫画；取消/Escape/遮罩只关闭窗口并把焦点还给作品 |

顶部「作品数／来源版本数」概览、来源筛选 Chip、搜索、显示方式偏好和来源窗口的信息量保持既有语义。来源筛选只控制哪些作品卡可见；**列表卡的来源名称和来源窗口均使用未被该筛选裁剪的当前展示组成员**。被主动分开显示的版本不再属于原组，显示在自己的作品卡；未收录或不属于当前作者的版本不混入。

## 图源文字与视觉规则

列表中来源名称放在作品标题下方、日期上方，按当前展示组成员稳定顺序显示；同一图源的多个版本只显示一次名称，按 source ID 去重，不能仅按重名字符串合并不同图源。缺失插件沿用项目的 stub／缺失来源名称与状态，不因插件暂不可用而隐藏已归档版本。长名称可换行，320dp 宽度不横向溢出，读屏应能读出完整来源集合。

视觉上复用当前主题与 Material 字体层级：图源名按 `bodyMedium` 语义作为普通次级文字，采用 onSurface 的次级强调；多个名称用轻量间隔点分隔。不要使用 FilterChip、TextButton、带边框的徽标或强调色来暗示卡片上可逐来源导航。日期沿用更低层级的 `bodySmall`／现有日期样式。封面比例、收藏书签、新作标记和卡片点击区域沿用平台现有组件，不把 HTML 的 14px、颜色或封面比例当作原生固定值。

依据标签：`SOURCE` 为当前 Android/Desktop `CreatorArchiveWorkCard`、Android `CreatorVersionButton`、Desktop `CreatorCanonicalVersions`、共享 `WorkPresentationGroup` 与 Mihon `BaseSourceItem` 的实际入口；`PROJECT_POLICY` 为本节双端一致的展示/操作契约与复用规则；`HTML_ADAPTER` 为已审核原型中列表的分隔点及字号近似。Desktop 的封面比例须以当前 Desktop 组件为准，Android 以其实际消费组件为准，见[Desktop UI 规范](design/mihon-desktop-ui/README.md)及[事实表](design/mihon-desktop-ui/desktop-reference.md)。原型截图是交互参考，不是原生像素基准。

## `Needs review` 的边界

作者详情的作品条目不提供直接标为 `Needs review` 的按钮；Android 待定作品列表与网格中的同名 TextButton 是本轮移除对象。当前 Android 的审阅对话框只由这个按钮打开，所以**待定独立条目**改用条目级「更多」菜单中的「作品校正」进入既有处理流程；菜单动作是高级纠错入口，不在普通作品卡或来源文字上出现。Android 已拒绝条目的操作不新增。Desktop 已有条目级 MoreVert → `WorkCompareScreen`，沿用该高级入口；普通作品卡上的逐来源动作随模式收起，不删除其比较能力。待定／拒绝事实、语言校正和对照能力仍须可达，状态名称不得作为新按钮回流。此处不改变 `PENDING`、`REJECTED`、canonical 决策、排除展示记录或通知状态。

## 失败与边界情况

- 列表单源作品也显示该图源名，点击仍打开来源窗口；多源按当前组完整列出。来源名称为空或解析失败时用项目现有缺失来源表示，不展示空白间隔点。
- 筛选到某个来源后，列表卡仍列出该作品组的全部来源；切回全部不会改变组身份、收藏和未读状态。网格模式始终不泄漏来源数量。
- 日期缺失、来源不可用或封面失败时保留作品条目和已有占位。打开窗口失败保留可见错误及重试能力；取消不标记新作已查看。只有成功进入漫画详情后才按现有链路更新已查看状态。
- 切换显示方式、作者或主题不更改归档数据；本轮不改数据库、备份、同步、来源抓取、作品聚合算法或显示偏好存储。

## 实现前固定验收

1. Android 与 Desktop 的真实挂载页面：列表单源、多源、缺源和按来源筛选时，来源名称为去重后的完整组；不是可独立点击的版本按钮，整卡打开完整来源窗口。
2. 两种网格的真实挂载页面：卡片不含来源名称、数量及逐版本操作；整卡点击后来源窗口列出全部版本并能准确进入选定漫画。320dp、长名称和深浅主题下无横向溢出或遮挡。
3. 待定、拒绝、自动聚合及手动分开展示样本：作者详情无直接 `Needs review` 按钮；既有高级纠错路径仍可达，状态/关系不因纯 UI 改动变化。
4. 切换显示方式、筛选、取消来源窗口及导航返回后，焦点、显示偏好、收藏、新作标记、日期和作者列表计数保持原有行为。HTML 测试只证明原型，生产验收须运行 Android/Desktop 的 Compose 行为与 wiring 测试。
