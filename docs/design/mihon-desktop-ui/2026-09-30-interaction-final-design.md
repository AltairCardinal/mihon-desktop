定稿日期：2026-09-30。状态：设计基线，待按配套 roadmap 实施和实机验收。

本文件汇总本次会话最后确定的书架、作品详情、分类管理、导航、主题和外观设置。对应[实机实施 roadmap](../../roadmap/2026-09-30-desktop-interaction-iteration-roadmap.md)与[交互 DEMO](../../prototypes/library-completion/index.html)。这里的“最终”指实施应采用的版本，不表示所有 DEMO 验收框都已由用户勾选，也不表示原生产品能力已完成。

本轮迭代的主要交付平台是 Windows Desktop。共享业务必须与 Android 对齐，并保护 Android 和 macOS 既有能力；Windows 输入与系统条件只通过平台 adapter 实现。保留 Desktop 同步、作者、笔记、源登录恢复、外部章节及阅读进度能力，不因对齐原版而删除它们。

不在本次迭代扩大阅读引擎、下载引擎、同步协议、作者发现算法、扩展执行协议或迁移引擎的范围。真实交互应接入已有服务；发现已有链路无法满足本文目标时，只修正目标所需边界。HTML 演示工具、场景重置、假下载、假账号、模拟设备条件不成为产品页面。

## 3. 主导航、更多及设置目录

### 3.1 主导航与页面所有权（I06、I08）

根入口固定为书架、更新、历史、浏览、更多。宽窗口左侧 NavigationRail，窄窗口底部 NavigationBar，采用对应原版组件的尺寸、图标、文字和选中状态，不复制 CSS 断点；选中指示器使用 secondaryContainer／onSecondaryContainer，不用 primary 的任意混色替代。页面自己拥有顶栏、滚动区和反馈区；详情、阅读器、分类管理、设置子页隐藏根导航，返回恢复原根页上下文。

浏览子页签固定为图源、作者、扩展、迁移。作者页复用现有内容、model、通知跳转和详情路由；根级作者旧导航请求映射为浏览→作者，避免通知、Test Mode、快捷入口或已保存路由失效。子页签的查询、列表位置及作者详情返回上下文保留，移动入口不重建作者数据库或发现流程。

### 3.2 更多页（I07）

按原版分组排列：品牌标识；仅显示已下载、无痕模式两个开关；下载队列、分类、统计、数据与存储；设置、关于、帮助。不显示捐赠。既有 Desktop 特有设置仍在合理的现有设置分组可达，不伪装成原版功能，也不重复堆在根页。

开关即时持久化并有实际消费者：仅显示已下载约束书架和章节；无痕沿用原有历史与追踪规则。这里不另改无痕协议。下载、统计、存储、关于、帮助在实机接入既有页面或系统动作，不能把 DEMO 的提示框当成完成。

### 3.3 设置目录

复用 Voyager 设置导航。窄屏先设置目录再进入子页；宽屏左侧目录、右侧当前子页，首次进入默认外观。左栏 `min(可用宽度/2, 450dp)`，两栏无分割线、独立滚动；宽屏外观顶栏不重复显示返回，目录返回退出设置；窄屏返回先退目录。

公共分组与图标按已固定原版 SettingsMainScreen；保留现有 Desktop 独有设置和设置搜索。书架偏好只从设置→书架进入；目录布局改变不能损坏设置搜索的锚点定位、关键字索引及返回路径。其他设置页面复用当前实机内容，不要求按 DEMO 的禁用说明停用已有页面。

## 4. 书架最终契约

### 4.1 普通工具栏与统一面板（I04、I05、L05）

普通动作顺序为搜索、筛选／排序／显示、同步、更多。更多菜单依次更新全部、更新当前分类、随机打开作品；宽度按内容自适应，留足组件规定的边距、热区和屏幕边界，不采用 210px 固定最小宽。选择动作先收起菜单；Escape 只关菜单并还焦。

统一面板是本页单一模态，固定筛选、排序、显示三个页签；每次新会话默认筛选，会话内各页保留滚动。重选当前书架导航项打开或聚焦同一面板，不重建根页、不重置查询／分类／滚动、不叠弹窗。详情等子页在前台时不处理根书架重选请求。多选时普通顶栏隐藏；通过仍可用的书架重选入口打开面板，隐藏选择仍保留。

| 页签 | 必须提供并接入的选项 |
| --- | --- |
| 筛选 | 下载、未读、已开始、书签、完结、自定义更新周期、追踪；不指定→包含→排除→不指定。单服务显示“已追踪”，多服务显示服务名称；所有活动条件包括追踪均计入顶栏提示。全局仅下载强制包含下载条件并禁用局部修改，解除后恢复局部偏好。 |
| 排序 | 标题、总章节数、最近阅读、最近更新、未读数、最新章节、获取时间、加入时间、追踪评分、随机，共十项；适用项升／降序，随机重选重新打乱，不显示虚假方向。 |
| 显示 | 紧凑网格、舒适网格、仅封面、列表；横／纵列数 0–10，0 为自动；下载数、未读数、本地、语言角标，继续阅读，分类标签及分类数量。 |

筛选、排序、显示沿用已有动作和 Preference，即时保存并消费；失败恢复权威旧值且显示原因。分类独立设置只影响排序 flags，显示布局、列数及角标仍是设备全局偏好。旧外观页列数能力迁移到此处，不能删掉用户设置或维护第二套列数权威。面板没有确认按钮或独立清除筛选按钮。

### 4.3 Windows 选择与分类滚轮（I01、I03）

| 输入 | 选择与导航结果 | 锚点 |
| --- | --- | --- |
| 未选择时普通主点击 | 直接打开详情 | 清除 |
| 已选择时普通主点击 | 增减目标，其他选择保留；取消最后一项仅退出选择 | 更新为目标，清零时清除 |
| Ctrl+主点击 | 进入或增减多选，不打开详情 | 更新为目标，清零时清除 |
| Shift+主点击 | 以锚点到目标闭区间替换当前分类可见集中的选择；其他分类及过滤隐藏选择保留；连续范围可收缩 | 固定起点不移动 |
| Ctrl+Shift+主点击 | 闭区间追加，保留其他选择 | 固定起点 |
| 长按 | 复用既有范围策略追加；无有效锚点时选择目标 | 有效起点保留，无效则重建 |
| 全选／反选 | 只对当前可见集合，隐藏选择保留 | 清除 |
| Escape／选择栏关闭 | 无上层弹窗时退出选择；随后 Escape 才退出搜索 | 清除 |

范围按当前可见排序计算，正反向包含两端。无锚点、跨分类或锚点隐藏时以目标重建单项范围；Shift 仍执行可见集替换，Ctrl+Shift／长按追加。删除后的陈旧目标事件忽略。四布局走同一事件和策略；Android 默认追加范围策略不因 Windows 替换语义改变。修饰键优先级 Ctrl+Shift→Shift→Ctrl→普通；右键、Alt 输入和非主体控件不误导航或选择，长按抑制随后 click。

Ctrl+滚轮只在 Windows 根书架内容上下文切上一／下一分类；向上为上一，向下为下一，首尾不循环。保留查询、筛选和跨分类选择，恢复目标排序与滚动。相同方向连续事件间隔小于 250ms 只切一次；停顿至少 250ms、反向、释放再按 Ctrl 重开一段。正在编辑输入、IME 组合、模态、详情／阅读器、Alt／Shift 修饰、横向滚动时不接管；Android 不绑定。消费有效输入防止宿主缩放，旧 Ctrl+方向键移除，Ctrl 滚轮不触发刷新。

### 4.4 书架多选界面

顶栏按原版 action mode：关闭、纯数字数量、全选 SelectAll、反选 FlipToBack；隐藏搜索、统一面板、同步、更多等普通动作，保留分类标签。网格用 secondary 实色选择框、封面 0.76 透明度；列表用 secondary 半透明整行底色，封面不降低透明度，最终参数以相同原版组件消费为准。

底栏位于内容与主导航之间，顺序为分类、标为已读、标为未读、下载、更多。更多为迁移、删除；全部本地作品时不显示下载／更多，迁移和删除直接显示。下载子菜单为 1／5／10／25 章、未读章节、已书签章节，复用下载适用性与队列。执行成功后按原版清选；迁移离开选择；失败保留可重试对象并有结果反馈。

批量“设置分类”只列自定义分类，支持全选、空、混合三态；混合项确认时维持原成员关系。取消保留选择和归属；确认提交后清选。“编辑”丢弃草稿、清选，进入更多使用的分类页。删除对话框原版两项“书架中的作品”“已下载的章节”，无勾选时确认禁用；本地作品不显示删除下载项。取消无副作用，只删下载不移出书架，移出书架不隐式多删未选择的文件。确认对象为打开时固定的稳定 ID 快照。

### 4.5 顶部两段刷新（I02，共用于详情 A6）

只处理漫画内容容器内无修饰的原生向列表起点滚动；滚到顶本身不刷新。根书架更新完整当前分类，不按查询／筛选裁剪；详情只更新当前作品，宽屏仅右侧章节滚动可触发，左侧信息区不触发。选择模式、模态、空库、加载／加载错误不武装；非空但不足一屏仍可用。

| 状态 | 固定转移及反馈 |
| --- | --- |
| Idle→Hinting | 顶部收到向上未消费量，显示“继续向上滚动，准备刷新当前分类／作品”，不请求。 |

### 6.3 章节选择 UI 的进一步固定

选择顶栏仅关闭、纯数字数量、全选、反选；常规标题／下载／筛选／更多隐藏。行主体仅选中背景，不加复选框；继续阅读 FAB 隐藏、章节头设置入口不可用、滚动刷新暂停。宽屏底部原版圆角动作容器占页面右半宽，窄屏占全部可用宽；这一宽度与右侧章节栏剩余宽度是不同公式，不能混用。

按已选状态显示书签增减、已读、未读、之前已读、下载、删除图标；无重复数量、常驻横排文字或退出按钮。长按短暂显示操作名，悬浮提示和可访问名称仍可用；原生沿组件 tooltip，DEMO 的 500ms／约 1 秒不成为平台常量。排队／下载中仍可显示批量下载图标，执行不重复入队。成功按原版清选，失败保留重试信息；反选至零、关闭或执行完毕回可见控制点焦点。

章节范围在 Windows Ctrl／Shift入口复用共享算法但保留原版章节追加范围语义，不把书架 Shift 替换范围未经决定强加给章节。普通点／Ctrl 更新锚点，连续 Shift／长按追加闭区间并保留有效起点；锚点失效只选目标重建。跨作品清选，列表变化裁掉不可见章。章节隐藏选择不保留，书架跨分类隐藏选择保留，须有两套明确调用策略而非复制范围算法。

## 7. 全部主题与外观页面

### 7.1 主题来源与共享消费（T01–T08）

主题目录固定为：DEFAULT 默认、MONET 动态、CATPPUCCIN、GREEN_APPLE 青苹果、LAVENDER 薰衣草、MIDNIGHT_DUSK 午夜幽暗、NORD、STRAWBERRY_DAIQUIRI 草莓黛绮莉、TAKO、TEALTURQUOISE 青绿、TIDAL_WAVE 浪潮、YINYANG 阴阳、YOTSUBA 四叶草、TOKYONIGHT 东京夜色、MONOCHROME 单色，共 15 个身份，顺序与上游一致。复用共享 AppTheme／AppThemeColorScheme／BaseColorScheme；不把 HTML colors JSON／CSS另建成生产权威。

各固定主题的浅／深方案及纯黑覆盖按上游完整 ColorScheme 角色消费，包含所有背景、文字、容器、选择、弹窗、角标及错误态；不能仅替换六种近似颜色。切换保留当前页、选择、输入、焦点和列表位置，不重新压栈或重置 model。已有 appTheme／themeMode／themeDarkAmoled 偏好继续有效，重启仍保留。

MONET 以平台动态色能力为条件。Android 具备能力时接真实系统配色。当前 Windows 不具备 Android 壁纸色源，不新增未授权取色服务：目录保留 MONET 身份用于兼容，但无能力时不作为可用主题卡出现；旧 MONET 值安全回退 DEFAULT，并在外观页明确说明平台不可用，不清除原存储值。这与上游 `selectableAppThemes(dynamicColorAvailable=false)`的条件筛选一致。HTML 展示 15 卡及默认回退是审阅映射，不意味着原生已实现动态色；若未来新增真实 Windows provider，另行实施其平台能力。

### 7.2 外观结构与尺寸

外观按原版两组：主题、显示。主题内三段跟随系统／浅色／深色，横向主题卡，纯黑开关；不增加“应用主题”可见标题或组间分割线。主题卡宽 114dp、预览 9:16、边框 4dp、圆角 17dp，内部顶栏／封面／双色角标／底栏按 AppThemePreferenceWidget；选中为 RoundedFilled.CheckCircle。使用匹配 Material3 token和源码控件，不通过字符勾号模拟图标。实际 hit target 与最终字体走原生组件，不以 CSS 硬编码代替。

手动 LIGHT 时纯黑整行隐藏，原值保留；SYSTEM即使当前系统浅色也显示，实际覆盖仅在深色生效。系统模式接实际系统深浅信号，不读浏览器 media query。默认值沿 UiPreferences：SYSTEM、纯黑 false、平板 AUTOMATIC、日期默认空值、相对时间 true、简介图片 true；升级保留用户显式值，不能用新默认覆盖。

显示组依次应用语言、平板界面、日期格式、相对时间戳、在漫画注释中显示图片；以下 AP01–AP15全部在原生验收，不只是静态页面还原。

## 8. 共同状态、确认和平台边界

所有实体、作用域和动作快照使用稳定 ID；书架／章节／作者／任务状态不能随主题重绘重置。普通搜索 null 与空查询有区别。子页返回恢复位置与可用焦点，弹层入焦、Tab／Shift+Tab圈定、背景不可交互，关闭回触发器；触发器消失时回到语义相同的可见控制点。一次 Escape 只消费一层，不能同时关模态和退出页面。临时反馈只在所属页面／会话显示，不在重开时回放。

危险操作确认固定对象集合、适用数量及实际影响（收藏关系、本机下载、类别、远端追踪），确认一次只处理仍有效对象；取消、遮罩、Escape无业务副作用。即时偏好沿真实存储，草稿只确认提交；失败保留权威旧值或用户草稿并提供重试。HTTP／权限／磁盘／未知系统条件错误分别反馈，不用一条成功 Toast 掩盖部分失败。

| HTML 参考内容 | 原生交付要求 |
| --- | --- |
| 详情450dp×0.8→360px，外观1dp→1px、根导航720px断点 | 消费原版 dp／组件公式及统一平台窗口配置；不能照搬 CSS 或两套断点。 |
| DOM 焦点、wheel、鼠标右键、500ms提示 | Compose实际事件／focus／tooltip adapter；Windows 真鼠标／触控板／DPI验收。 |
| 正常网页刷新清空、模拟重启保留内存 | 实机 Preference、SQLDelight、任务 store、已有文件系统持久化；真实重启与升级验证。 |
| 内存章节、假队列、假文件、假账号、源样本 | 真实 use case／repository／HTTP parser／下载 manager／授权及系统能力；不复制模拟模型为业务代码。 |
| 并列端状态隔离、外层统一配色 | 产品设备局部 UI 与偏好保持隔离，既有同步域沿原协议；不因 DEMO 外层工具自动同步主题。 |
| 动态主题回退、模拟供电／Wi-Fi、模拟语言列表 | 实际平台能力／打包资源及可解释失败；native adapter测试和真实发布runtime证据。 |

实机完成证据必须覆盖真实 UI 事件→导航／DI→共享业务→存储或系统 adapter→用户反馈。只扫描源码字符串、检查 DOM 或复制算法不能验收生产完成。本次文档不改变 parity manifest状态，不勾选产品 roadmap，不生成 EXE或 APK。
