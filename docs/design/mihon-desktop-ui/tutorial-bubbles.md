# Desktop 教程气泡

## 目的与边界

`PROJECT_POLICY`：教程用于在用户首次遇到功能时解释操作；它是非模态、可确认的上下文提示，不是 Toast、设置页或强制向导。稳定教程 ID、已确认状态及外观共用一个实现。当前仅注册阅读器手动调整匹配，不预建教程队列、远端配置或状态服务。

`SOURCE`：手动匹配继续调用 `ReaderScreenModel.adjustSpread()`，由既有共享双页会话决定配对、保存与失败反馈。快捷键和气泡中的尝试动作不实现第二份配对逻辑。

## 注册与持久化

- 教程定义集中在 `DesktopTutorial`：稳定 `id`、本地化标题和正文。ID 不随文案、语言或版本变化；若未来确实需要用户重新学习，新增语义明确的 ID，不清空所有教程状态。
- `DesktopTutorialState` 消费 `DesktopAppPreferences` 中的教程确认集合，使用 `Preference.appStateKey` 标记为本机运行状态，排除普通备份和跨设备偏好同步。通过当前依赖图提供的 `appPreferences` 获取，不新建独立配置目录。
- 挂载、重绘或临时隐藏不写入确认。只有用户点击“知道了”或实际触发对应教学动作，才记住该教程；读者关闭窗口但尚未确认，下次符合条件仍可看到。
- 写入失败只影响教程记忆：当前会话收起，下一次进入可再次提示，不能中断已经请求的阅读动作。写入时合并既有集合，保留其他及未来未知教程 ID。

## 阅读器契约

| 项目 | 固定行为 |
|---|---|
| 入口 | 首次进入可用双页内容时显示；自动布局切入双页也适用；工具栏隐藏时仍可看见 |
| 可用条件 | 双页且非条漫、正文可读、配对恢复完成、无保存进行中、无设置或恢复确认遮挡 |
| 内容 | 解释 C 键可以手动调整当前匹配，提供同一动作按钮与“知道了” |
| 快捷键 | 阅读器拥有焦点时，未按 Ctrl/Alt/Shift/Meta 的 C KeyDown 调用现有动作；KeyUp 不重复触发 |
| 不可用时 | 单页、条漫、加载、配对错误、保存、设置及恢复确认期间不触发、不消费教程 |
| 临时切换 | 离开双页或打开设置只隐藏；回来后仍提示未确认教程 |
| 焦点 | 自动出现不抢焦点；确认或点击尝试后恢复阅读器焦点；非模态不阻塞其余阅读操作 |
| 危险确认 | 调整沿既有可恢复配对行为，不增加危险操作确认 |

## 组件与验证

`PROJECT_POLICY`：`DesktopTutorialBubble` 统一使用 MaterialTheme 语义颜色、圆角 Surface、气泡尾部、正文、确认按钮及关联动作入口；宿主选择位置并提供可用条件和动作。阅读器放在底部右侧，工具栏显示时避开底栏；窄窗限制最大宽度并允许正文换行，不以绝对屏幕像素定位。

新增教程须增加真实挂载、确认、重建与临时隐藏测试。动作教程必须验证真实操作入口及其 production wiring，不能仅检查定义字符串存在。`ReaderPairingTutorialIntegrationTest` 通过 Compose 场景真实按键/点击、共享双页 owner 和隔离偏好存储覆盖当前入口，并生成浅色/深色、360/900 宽度的渲染图。离屏图像不代表 Windows 实体键盘、显示缩放或正式发布运行验收；发布门槛仍遵循仓库规则。
