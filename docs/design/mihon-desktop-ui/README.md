# Mihon Desktop UI 实施规范

版本：2026-09-25。适用：新增或修改 Desktop 用户界面，以及用于审阅这些界面的 HTML 原型。此入口补充现有仓库架构、TDD、复用和原生验证要求，不替代它们。原始 Android 规范仍作为[参考输入](../mihon-ui-kit-evaluation/input/mihon-ui-kit/docs/ui/README.md)，不直接安装其中 AGENTS 或 overlay。

2026-09-30 本次交互迭代的业务定稿见[最终设计](2026-09-30-interaction-final-design.md)与[实机 roadmap](../../roadmap/2026-09-30-desktop-interaction-iteration-roadmap.md)。两者承接书架、详情、分类、导航、主题和外观的最终要求；本文的复用、焦点、测试和原生验证约束继续适用。

## 先读哪些内容

1. 读取本页和[Desktop 事实与组件表](desktop-reference.md)。按页面任务读取原规范适用章节，不必每次阅读全部128条。
2. 读取[三个页面契约与固定验收](page-contracts.md)。涉及其他页面时，用相同字段定义本页的状态、入口、返回、焦点和副作用，不机械套用样本业务。
3. 读取当前分支组件实现及调用方，记录当前commit和有关未提交改动。引用基线过期时只重核受影响项。
4. 实现前固定必做验收；先写真实行为红测。实现后逐项绑定测试与证据，缺项仍算未完成，不能事后改为“不适用”以通过验收。

验证和发布退出规则以仓库 [AGENTS.md](../../../AGENTS.md) 为准：默认按本次变更完成 focused 行为、集成和受影响平台体验；只有具体未覆盖风险证明 focused 不足时，才可申请经用户批准的最小模块级扩验。完整发布矩阵仅在用户明确指定的里程碑执行。checkbox 表示本批约定已完成，不代表 roadmap 已发布就绪。

## 必须落实的共享约束

- **容器和入口**：顶栏、底栏、滚动区、反馈区各有唯一所有者。子页有标题和有效返回；根标签不强加返回。未实现的演示入口禁用并解释，不留空回调。
- **局部状态**：选择使用实体稳定ID；阅读、下载等状态至少以作品+章节标识隔离。改变排序、主题或尺寸不得改变动作对象。搜索未打开用独立状态表示，不能与空查询混淆。
- **选择**：零选择退出；全选/反选作用于当前可见有序集合；范围选择明确锚点及端点，不能以DOM位置充当实体身份。批量只执行适用子集，反馈实际处理和跳过数量。
- **确认**：打开时固定本次对象集合。取消/遮罩/Escape不执行删除或启动任务；确认一次只处理快照内仍有效对象。可恢复性、影响本机/远端、删除文件/关系要写清。
- **返回与焦点**：每页声明Escape、顶栏返回、遮罩和关闭按钮的区别；一次事件只消费一层。弹层入焦、Tab/Shift+Tab圈定、背景不可交互、关闭返回触发器。主题/尺寸变化不重新导航，不清除选择或输入，不抢另一个设备焦点。
- **即时偏好与草稿**：即时开关关闭面板后保留已提交状态；草稿只有确认才提交。演示刷新重置可以是边界，必须写明；生产必须使用现有Preference链路。
- **视觉复用**：颜色按语义token，图标保留原fill/stroke约束；封面、控件尺寸依据同类组件。无法从源码确定的参数标为adapter决定，不伪装成原版常量。不得为像素近似复制第二套生产组件。
- **反馈**：临时消息有明确生命周期，不因重绘重复播报；消息不遮挡关键操作。加载/空/错保留页面容器；真实异步页面必须覆盖重试和旧结果处理，不用本地同步假数据冒充验证。

## 验收与失败处理

每项记录：规则/契约ID → 真实操作 → 断言 → 测试文件与名称 → 结果/环境。测试需在点击事件、导航或绑定损坏后失败；只检查源码字符串、截图存在或模型复制不算行为证据。

先运行当项 focused 红绿测试，并验证真实导航、DI 和 production wiring。按风险决定是否需要未实施者独立审查：低风险可自查；迁移、安全、发布身份、共享协议或公共运行机制等实质高风险须独立审查，独立 capability 本身不触发。批次按受影响范围验证即可；若有具体证据表明 focused 不足，可按 AGENTS 申请经用户批准的最小模块级扩验。完整发布矩阵仅在用户明确指定里程碑时执行。独立发现缺陷时，保留失败事实，修复后复验相关路径；有效完整基线可与针对后续局部差异的补验证据合并说明，无具体未覆盖风险不得重复申请全量。

视觉证据分三类：源码 token/尺寸事实、现有 HTML 参照、候选窗口视觉。Test Mode 自身不提供桌面截图 API；外部工具的授权、能力判断和观察边界遵循 [AGENTS.md](../../../AGENTS.md)。当前尚无经过审核的原生截图集，不能声称像素级原版一致。新增原生页面仍须遵守仓库的导航、DI、HTTP 集成测试及实际发布里程碑要求。

本次固定范围是三个页面样本，不涵盖全应用导航、真实阅读引擎、下载器或同步服务。范围外项目在实现前声明；范围内项目未通过则本轮不完整。环境不可用时写真实阻塞和影响，不以跳过当通过。
