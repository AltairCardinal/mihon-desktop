# 05-visual-accessibility — Mihon fork UI 规范 v1.0

本文件中的“必须/禁止”是本次制定的 fork 规范。来源标记对应 `source-outline.md` 的固定提交索引；规则中增加的健壮性要求不表示上游所有代码已经符合。

## UI-22 视觉基础与复用

适用范围：所有新增UI。

例外与边界：测试探针可显示边框/标签但默认可隐藏，禁止进入业务。

参考实现：S02、S05、S07；读取当前工作分支对应文件后实现。

### 强制条款

- **UI-22.01** 主题颜色、字体层级、形状和间距优先来自当前分支现有主题/组件；禁止擅自引入另一套视觉语言。
- **UI-22.02** 当前分支的图标体系与上游版本分别记录；不能在旧分支引用不存在的新图标包。
- **UI-22.03** 组件能满足需求时不得另造同功能控件；必须定制时记录差异和为何需要。
- **UI-22.04** 明暗、动态主题、禁用和错误状态均需可辨；截图必须注明主题、字体、尺寸、locale和commit。

### 验收场景

| ID | 场景/前置 | 操作 | 预期 |
|---|---|---|---|
| UI-22-C01 | 亮色：亮色系统 | 查看控件组 | 使用项目主题。 |
| UI-22-C02 | 暗色：暗色系统 | 查看相同控件 | 文字和状态可读。 |
| UI-22-C03 | 禁用：禁用状态 | 尝试点击 | 无动作且外观可辨。 |
| UI-22-C04 | 错误：错误状态 | 检查文字与控件 | 符合主题error语义。 |

验证层级：本地模型断言只证明状态转换；Android 组件行为、视觉、设备环境和生产业务必须各自记录证据。

## UI-23 封面文本角标日期

适用范围：实体卡片与元数据。

例外与边界：样例封面为本地测试图形；不构成真实图片加载验证。

参考实现：S02、S21、S11、S04；读取当前工作分支对应文件后实现。

### 强制条款

- **UI-23.01** 封面比例、裁切、圆角和占位沿用现有组件；加载失败与无封面分别处理。
- **UI-23.02** 标题省略、简介展开和标签动作保持同类页面一致；长文本不能侵占独立操作区。
- **UI-23.03** 计数、日期与未知值使用现有格式化逻辑；零、未知、无值的语义分别定义。
- **UI-23.04** 角标有明确含义并服从用户显示偏好；同一数字不得在不同页面表示不同对象而不说明。

### 验收场景

| ID | 场景/前置 | 操作 | 预期 |
|---|---|---|---|
| UI-23-C01 | 常规内容：短标题 | 查看条目 | 信息层级一致。 |
| UI-23-C02 | 长文本：超长标题简介 | 展开/收起 | 完整内容可访问。 |
| UI-23-C03 | 缺失封面：空封面 | 查看占位 | 布局不塌陷。 |
| UI-23-C04 | 边界元数据：零计数和未知日期 | 查看角标 | 不把未知当成零或今天。 |

验证层级：本地模型断言只证明状态转换；Android 组件行为、视觉、设备环境和生产业务必须各自记录证据。

## UI-24 动效与滚动联动

适用范围：列表、详情、弹层和工具栏。

例外与边界：动效观感须实机检查；模型测试不能判定观感。

参考实现：S01、S04、S05、S18；读取当前工作分支对应文件后实现。

### 强制条款

- **UI-24.01** 复用当前分支的过渡与动画；新增时长/缓动需要具体用途和参考依据。
- **UI-24.02** 列表重排、模式切换和工具栏显隐不得在动画中暂时改变动作目标或重复提交。
- **UI-24.03** 滚动标题与FAB形态和真实滚动位置联动，不能用无关布尔值替代生产行为。
- **UI-24.04** 关闭系统动画、大列表和快速反向操作需验证；动画结束不能代表后台任务结束。

### 验收场景

| ID | 场景/前置 | 操作 | 预期 |
|---|---|---|---|
| UI-24-C01 | 列表变动：默认条目 | 增加删除假条目 | 动画不改变ID语义。 |
| UI-24-C02 | 快速切换：模式开关 | 快速切换多次 | 最终状态正确。 |
| UI-24-C03 | 滚动联动：长列表 | 上下滚动 | 示例浮动操作随真实滚动调整。 |
| UI-24-C04 | 关闭动画：系统动画关闭 | 执行相同行为 | 状态和交互仍完整。 |

验证层级：本地模型断言只证明状态转换；Android 组件行为、视觉、设备环境和生产业务必须各自记录证据。

## UI-25 屏幕与系统适配

适用范围：手机、平板、多窗口。

例外与边界：开发面板的尺寸开关仅为局部预览，不替代真实设备配置。

参考实现：S01、S04、S12、S08；读取当前工作分支对应文件后实现。

### 强制条款

- **UI-25.01** 采用当前项目的平板判定和双栏策略；禁止每页随意设断点。
- **UI-25.02** 尺寸、方向或窗口变化时保留声明状态，切换侧栏/底栏时不重新导航到默认页面。
- **UI-25.03** IME、状态栏、手势导航、三键导航、刘海和大字体分别验证；不能只检查默认截图。
- **UI-25.04** 英文、中文、长伪语言和RTL作为环境样本；方向动作遵循逻辑方向，阅读方向按阅读器规则独立处理。

### 验收场景

| ID | 场景/前置 | 操作 | 预期 |
|---|---|---|---|
| UI-25-C01 | 手机：窄窗口 | 检查全页 | 控件可点击。 |
| UI-25-C02 | 平板：宽窗口 | 切换布局 | 沿用项目平板判断。 |
| UI-25-C03 | 大字体：字体200% | 滚动全页 | 无关键操作裁切。 |
| UI-25-C04 | RTL与键盘：RTL并打开IME | 输入和返回 | 安全区和导航方向正确。 |

验证层级：本地模型断言只证明状态转换；Android 组件行为、视觉、设备环境和生产业务必须各自记录证据。

## UI-26 无障碍与本地化

适用范围：全部可交互控件。

例外与边界：装饰图标可无描述；存在旁边合并文本时避免重复读屏。

参考实现：S02、S01；读取当前工作分支对应文件后实现。

### 强制条款

- **UI-26.01** 图标操作提供资源化的可访问名称；可选择控件暴露checked/selected/disabled语义。
- **UI-26.02** 标签与开关/复选框形成一个可访问操作目标；禁止双重读屏节点或双触发。
- **UI-26.03** 可见文案、复数和状态说明通过资源获取；测试用稳定testTag，禁止依赖翻译文本做唯一定位。
- **UI-26.04** 触控目标沿用组件最小交互尺寸，读屏、键盘导航和大字体必须有独立证据；截图不证明无障碍合规。

### 验收场景

| ID | 场景/前置 | 操作 | 预期 |
|---|---|---|---|
| UI-26-C01 | 语义标签：默认 | 使用TalkBack遍历 | 动作名称正确。 |
| UI-26-C02 | 复选状态：未选择 | 通过读屏切换 | 状态变更被正确表达。 |
| UI-26-C03 | 禁用：禁用控件 | 尝试读屏激活 | 不可执行。 |
| UI-26-C04 | 语言切换：中英文环境 | 重复核心流程 | 资源完整，testTag稳定。 |

验证层级：本地模型断言只证明状态转换；Android 组件行为、视觉、设备环境和生产业务必须各自记录证据。
