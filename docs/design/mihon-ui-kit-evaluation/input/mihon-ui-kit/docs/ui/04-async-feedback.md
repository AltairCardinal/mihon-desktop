# 04-async-feedback — Mihon fork UI 规范 v1.0

本文件中的“必须/禁止”是本次制定的 fork 规范。来源标记对应 `source-outline.md` 的固定提交索引；规则中增加的健壮性要求不表示上游所有代码已经符合。

## UI-18 加载空态与错误

适用范围：异步内容界面。

例外与边界：局部加载不能遮蔽无关已加载内容。

参考实现：S09、S11；读取当前工作分支对应文件后实现。

### 强制条款

- **UI-18.01** 至少区分初次加载、正常、空数据、查询无结果、筛选无结果、依赖缺失和错误的适用状态。
- **UI-18.02** 内容状态不得导致页面标题或有效返回入口意外消失；重试不能重新压入相同页面。
- **UI-18.03** 无数据提示使用原因对应文案并给出适用动作；禁止所有异常统一展示“暂无数据”。
- **UI-18.04** 已有内容失败保留内容，附局部反馈；首次失败用整页恢复；不得把失败转换为空结果隐藏。

### 验收场景

| ID | 场景/前置 | 操作 | 预期 |
|---|---|---|---|
| UI-18-C01 | 加载：首次加载 | 检查并返回 | 有加载反馈和导航。 |
| UI-18-C02 | 空数据：无实体 | 查看提示 | 说明如何添加数据。 |
| UI-18-C03 | 无结果：有筛选/查询 | 清除限制 | 与空数据库文案不同。 |
| UI-18-C04 | 错误：失败状态 | 点击重试 | 恢复正常且栈不增加。 |

验证层级：本地模型断言只证明状态转换；Android 组件行为、视觉、设备环境和生产业务必须各自记录证据。

## UI-19 刷新分页与长任务

适用范围：分页、刷新和长任务。

例外与边界：下拉动画可仅表示任务启动，但必须另有任务真实状态。

参考实现：S10、S09；读取当前工作分支对应文件后实现。

### 强制条款

- **UI-19.01** 启动、运行、成功、失败、取消是不同任务状态；禁止用按钮点击或动画结束代表完成。
- **UI-19.02** 已有内容刷新保持可用数据；分页错误不清空列表，重试只重做对应阶段。
- **UI-19.03** 进行中禁止重复启动或采用既有去重；选择模式下的刷新手势遵循参考行为。
- **UI-19.04** 任务可以离开页面继续时须说明进度入口；可取消边界和迟到结果策略必须明确。

### 验收场景

| ID | 场景/前置 | 操作 | 预期 |
|---|---|---|---|
| UI-19-C01 | 首次任务：空内容 | 启动 | 状态变运行，尚未报告成功。 |
| UI-19-C02 | 刷新：已有结果 | 开始刷新再模拟失败 | 结果保留。 |
| UI-19-C03 | 分页失败：已有第一页 | 追加失败后重试 | 不丢失第一页且不重复。 |
| UI-19-C04 | 重复启动：任务运行 | 连续启动 | 有效启动次数不增加。 |

验证层级：本地模型断言只证明状态转换；Android 组件行为、视觉、设备环境和生产业务必须各自记录证据。

## UI-20 反馈重试与恢复

适用范围：所有可失败交互。

例外与边界：保留原版局部Toast的场景；新策略需显式记录。

参考实现：S09、S22；读取当前工作分支对应文件后实现。

### 强制条款

- **UI-20.01** 短结果使用既有 Snackbar/Toast；持续全局状态使用横幅；必须决策的事项使用对话框。
- **UI-20.02** 失败文案说明发生了什么和可执行下一步；重试入口必须实际重试相同操作。
- **UI-20.03** 暂时错误保留输入和已有结果；禁止错误后自动清空草稿；错误日志不得泄露令牌或个人数据。
- **UI-20.04** 消息不重复弹出；一次性事件不随重组重复发送；只有成功回执后显示成功。

### 验收场景

| ID | 场景/前置 | 操作 | 预期 |
|---|---|---|---|
| UI-20-C01 | 成功：默认 | 触发假成功 | 只显示一次结果。 |
| UI-20-C02 | 可重试：失败操作 | 点击消息里的重试 | 重新执行并更新状态。 |
| UI-20-C03 | 草稿保留：有文本 | 模拟失败 | 文本保留。 |
| UI-20-C04 | 取消消息：消息显示 | 关闭提示 | 不改变业务状态。 |

验证层级：本地模型断言只证明状态转换；Android 组件行为、视觉、设备环境和生产业务必须各自记录证据。

## UI-21 全局模式与横幅

适用范围：隐私、仅下载、索引状态。

例外与边界：读取真实行为需要集成用例，横幅本身不能证明约束生效。

参考实现：S17、S08；读取当前工作分支对应文件后实现。

### 强制条款

- **UI-21.01** 横幅复用既有组件和次序；系统栏边距由统一容器处理。
- **UI-21.02** 全局模式改变数据和操作能力时，所有受影响页面必须遵循同一状态源。
- **UI-21.03** 仅下载模式禁止展示与该模式冲突的可执行入口；受强制的筛选需禁用并注明。
- **UI-21.04** 隐私模式的数据记录与外发策略必须单独测试；样例只演示状态，不宣称证明生产隐私实现。

### 验收场景

| ID | 场景/前置 | 操作 | 预期 |
|---|---|---|---|
| UI-21-C01 | 正常：全部模式关闭 | 观察 | 没有无意义横幅。 |
| UI-21-C02 | 仅下载：开启模式 | 尝试改下载条件 | 强制条件生效。 |
| UI-21-C03 | 隐私：开启隐私 | 执行假阅读 | 假历史计数不增加。 |
| UI-21-C04 | 组合：多个模式开启 | 切换索引状态 | 横幅排序和布局稳定。 |

验证层级：本地模型断言只证明状态转换；Android 组件行为、视觉、设备环境和生产业务必须各自记录证据。
