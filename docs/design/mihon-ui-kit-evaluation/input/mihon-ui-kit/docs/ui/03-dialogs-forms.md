## UI-13 菜单与溢出操作

适用范围：顶栏菜单、条目菜单。

例外与边界：菜单项的排序以对应参考页面为准。

参考实现：S02、S13；读取当前工作分支对应文件后实现。

### 强制条款

- **UI-13.01** 主操作和次要操作按页面设计放置；使用 AppBarActions 或现有 DropdownMenu 封装。
- **UI-13.02** 菜单选择后按原版关闭；嵌套菜单关闭应退出对应层级，不重复执行父项。
- **UI-13.03** 操作名称准确描述影响对象；隐藏和禁用需保持能力判断一致，禁止表面可点但无行为。
- **UI-13.04** 点击外部和系统返回关闭菜单而不离开页面；键盘焦点和锚点在设备上验证。

### 验收场景

| ID | 场景/前置 | 操作 | 预期 |
|---|---|---|---|
| UI-13-C01 | 普通菜单：默认 | 打开更多并选动作 | 动作执行一次并关闭。 |
| UI-13-C02 | 嵌套菜单：排序子菜单 | 选择子项 | 提交子项并关闭菜单链。 |
| UI-13-C03 | 取消：菜单打开 | 点击外部或返回 | 不执行业务动作。 |
| UI-13-C04 | 受限能力：不可用动作 | 查看菜单 | 无虚假的可用入口。 |

验证层级：本地模型断言只证明状态转换；Android 组件行为、视觉、设备环境和生产业务必须各自记录证据。

## UI-14 弹层与内部导航

适用范围：确认框、自适应Sheet。

例外与边界：不可取消过程只能在真实必要且有说明时锁定关闭。

参考实现：S12、S08；读取当前工作分支对应文件后实现。

### 强制条款

- **UI-14.01** 短确认使用既有 AlertDialog；多选项和较复杂局部流程使用 AdaptiveSheet/TabbedDialog；复杂步骤使用内部导航。
- **UI-14.02** 弹层标题、主动作、取消结果和退出条件必须声明；取消时不提交未确认值。
- **UI-14.03** 关闭顺序由内部导航和未保存状态决定；遮罩、滑动、系统返回不得绕过需要保护的草稿。
- **UI-14.04** 小屏靠底、大屏居中遵循原版自适应实现；不得靠固定屏幕像素模拟弹层位置。

### 验收场景

| ID | 场景/前置 | 操作 | 预期 |
|---|---|---|---|
| UI-14-C01 | 确认框：默认 | 打开并取消 | 无副作用。 |
| UI-14-C02 | 自适应弹层：Sheet场景 | 在手机和平板打开 | 采用现有AdaptiveSheet布局。 |
| UI-14-C03 | 嵌套层：进入第二步 | 返回 | 回到弹层第一步。 |
| UI-14-C04 | 草稿保护：已编辑文本 | 尝试关闭 | 按声明提示放弃或保留。 |

验证层级：本地模型断言只证明状态转换；Android 组件行为、视觉、设备环境和生产业务必须各自记录证据。

## UI-15 设置项与生效时机

适用范围：设置页面和局部设置。

例外与边界：样例使用本地假值；禁止接入真实Preference存储。

参考实现：S06、S07；读取当前工作分支对应文件后实现。

### 强制条款

- **UI-15.01** 设置页优先使用 PreferenceScaffold/PreferenceScreen 和既有Preference类型；保持分组与摘要风格。
- **UI-15.02** 开关、单选、多选、滑块、文本使用适配语义的控件；不要把二态设置改成不明操作按钮。
- **UI-15.03** 当前值摘要与已提交值一致；依赖设置关闭时子项禁用并说明原因。
- **UI-15.04** 明确即时保存、确认保存和退出丢弃；输入取消不得变更已提交偏好；样例偏好必须使用内存实现。

### 验收场景

| ID | 场景/前置 | 操作 | 预期 |
|---|---|---|---|
| UI-15-C01 | 即时设置：默认值 | 切换开关 | 已提交摘要立即改变。 |
| UI-15-C02 | 单选：打开列表选择 | 选择选项 | 复用现有Preference控件并更新假值。 |
| UI-15-C03 | 依赖禁用：主开关关闭 | 尝试子项 | 子项禁用。 |
| UI-15-C04 | 取消编辑：已保存旧值 | 改值后取消 | 旧值保留。 |

验证层级：本地模型断言只证明状态转换；Android 组件行为、视觉、设备环境和生产业务必须各自记录证据。

## UI-16 输入校验与焦点

适用范围：创建、重命名及文本输入。

例外与边界：trim、大小写和重复定义由实体规则明确，不照抄历史缺陷。

参考实现：S19；读取当前工作分支对应文件后实现。

### 强制条款

- **UI-16.01** 提交统一经过规范化和业务校验；可见确认按钮与IME动作调用同一函数。
- **UI-16.02** 必填、重复、范围和无变化分别处理；行内错误可读；无效值不能提交。
- **UI-16.03** 初始值、光标、焦点和键盘类型根据任务设定；输入框不被IME遮挡。
- **UI-16.04** 编辑时只修改草稿；确认后提交一次；取消恢复原值；重命名比较初始值，不能只比较上一次输入。

### 验收场景

| ID | 场景/前置 | 操作 | 预期 |
|---|---|---|---|
| UI-16-C01 | 必填：空文本 | 点击确认或键盘提交 | 不可提交，有必填说明。 |
| UI-16-C02 | 重复：输入已有名称 | 尝试提交 | 不提交，显示重复错误。 |
| UI-16-C03 | 有效：输入新名称 | 提交 | 提交一次并更新已保存值。 |
| UI-16-C04 | 撤销编辑：已有保存值 | 编辑后取消 | 已保存值不变化。 |

验证层级：本地模型断言只证明状态转换；Android 组件行为、视觉、设备环境和生产业务必须各自记录证据。

## UI-17 破坏性操作

适用范围：移除、删除、清空、解绑。

例外与边界：取消可重建队列是否确认按任务风险记录；不套用统一确认。

参考实现：S14、S13；读取当前工作分支对应文件后实现。

### 强制条款

- **UI-17.01** 操作前明确对象及影响：书库关系、下载文件、历史、远端绑定不能使用含糊的删除描述。
- **UI-17.02** 不可恢复或跨设备影响默认需要确认，列出影响范围；同类原版不同处理需写例外记录。
- **UI-17.03** 没有选择影响范围时确认禁用；取消和遮罩关闭无副作用；失败不宣称成功。
- **UI-17.04** 确认防重复；撤销仅在真正可逆时提供；绝不让样例删除真实文件或记录。

### 验收场景

| ID | 场景/前置 | 操作 | 预期 |
|---|---|---|---|
| UI-17-C01 | 确认范围：无勾选范围 | 打开移除 | 确认禁用。 |
| UI-17-C02 | 选择范围：选择假数据删除范围 | 确认 | 只删除所选范围。 |
| UI-17-C03 | 取消：已选择范围 | 取消 | 假数据不变。 |
| UI-17-C04 | 重复确认：成功提交一次 | 快速重复触发 | 只记录一次有效提交。 |

验证层级：本地模型断言只证明状态转换；Android 组件行为、视觉、设备环境和生产业务必须各自记录证据。
