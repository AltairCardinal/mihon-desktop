# 01-navigation — Mihon fork UI 规范 v1.0

本文件中的“必须/禁止”是本次制定的 fork 规范。来源标记对应 `source-outline.md` 的固定提交索引；规则中增加的健壮性要求不表示上游所有代码已经符合。

## UI-01 页面类型与容器职责

适用范围：所有页面与可复用内容。

例外与边界：阅读器允许工具栏隐藏；嵌入内容复用父级容器。

参考实现：S05、S20；读取当前工作分支对应文件后实现。

### 强制条款

- **UI-01.01** 每次新增界面必须声明 root、subpage、tab-content、settings、detail、modal 或 reader 类型，以及顶栏、底栏、消息和安全区的唯一提供方。
- **UI-01.02** 普通子页面必须提供非空标题和有效返回回调；内容组件禁止自行添加第二套页面导航；开发验证控件不能进入业务页面。
- **UI-01.03** 不得因加载、空数据、错误分支提前返回而绕过已规定的页面容器。
- **UI-01.04** 复用容器必须连同导航、滚动、间距和状态参数一并接入；不得仅复制视觉样式。

### 验收场景

| ID | 场景/前置 | 操作 | 预期 |
|---|---|---|---|
| UI-01-C01 | 普通子页：默认数据 | 打开子页并返回 | 只有一处页面顶栏；回到目录。 |
| UI-01-C02 | 标签内容：切换标签场景 | 切换子标签 | 父级顶栏保留；内容没有重复顶栏。 |
| UI-01-C03 | 加载：切换加载场景 | 检查标题和返回 | 内容加载不影响返回。 |
| UI-01-C04 | 失败：切换错误场景 | 重试后返回 | 错误有恢复动作；页面容器不变。 |

验证层级：本地模型断言只证明状态转换；Android 组件行为、视觉、设备环境和生产业务必须各自记录证据。

## UI-02 顶层导航与标签切换

适用范围：根导航及其子标签。

例外与边界：开发目录的退出动作属于工具入口；不复制进首页导航。

参考实现：S01、S03、S20；读取当前工作分支对应文件后实现。

### 强制条款

- **UI-02.01** 根标签使用项目既有导航容器与平板判断；禁止每个标签独立定义屏幕断点。
- **UI-02.02** 标签切换必须同步选中状态、标题、搜索能力及操作区；角标只表达对应计数，零值默认不展示。
- **UI-02.03** 重复选择当前标签必须调用该标签既有重选行为；新增标签在设计记录中声明无操作或具体动作。
- **UI-02.04** 根导航系统返回遵循宿主规则：先处理局部模式，再从非书库根标签回书库；不得创建重复目的地。

### 验收场景

| ID | 场景/前置 | 操作 | 预期 |
|---|---|---|---|
| UI-02-C01 | 普通标签：默认根标签 | 依次切换标签 | 选中项和内容一致。 |
| UI-02-C02 | 重复选择：当前标签已选中 | 再次点击当前项 | 记录重选事件；不压入重复页面。 |
| UI-02-C03 | 计数：启用样例计数 | 查看零值与非零值 | 只有非零计数显示。 |
| UI-02-C04 | 宽屏：切换设备到平板或宽窗口 | 切换根标签 | 使用侧栏；状态不随尺寸丢失。 |

验证层级：本地模型断言只证明状态转换；Android 组件行为、视觉、设备环境和生产业务必须各自记录证据。

## UI-03 顶栏标题与操作区

适用范围：包含顶栏的页面。

例外与边界：详情标题可以随滚动显现；需保留返回入口。

参考实现：S02、S04；读取当前工作分支对应文件后实现。

### 强制条款

- **UI-03.01** 子页顶栏复用 AppBar；title、navigateUp、scrollBehavior 的传递必须在审查中逐项确认。
- **UI-03.02** 标题来自资源或明确的实体名称；长标题按原版单行省略，副标题使用现有组件；禁止依赖截断后的标题识别实体。
- **UI-03.03** 选择模式显示数量与取消动作，搜索模式使用 SearchToolbar；退出模式恢复原标题和操作。
- **UI-03.04** 直接操作具有可访问名称与工具提示；次要操作放入既有更多菜单，能力不支持时不得保留无效回调。

### 验收场景

| ID | 场景/前置 | 操作 | 预期 |
|---|---|---|---|
| UI-03-C01 | 普通顶栏：默认场景 | 点击返回和右侧动作 | 两种动作各自有效。 |
| UI-03-C02 | 长标题：长标题场景 | 查看窄屏顶栏 | 标题省略；操作可见。 |
| UI-03-C03 | 选择顶栏：预选两项 | 取消选择 | 计数为2；取消后恢复标题。 |
| UI-03-C04 | 搜索顶栏：搜索已打开 | 输入后清空并关闭 | 清空保留搜索；关闭恢复普通顶栏。 |

验证层级：本地模型断言只证明状态转换；Android 组件行为、视觉、设备环境和生产业务必须各自记录证据。

## UI-04 返回关闭与取消

适用范围：页面、模式、弹层、键盘。

例外与边界：系统 IME 会自行消费返回；不得把业务优先级误当系统全局顺序。

参考实现：S01、S02、S03、S12；读取当前工作分支对应文件后实现。

### 强制条款

- **UI-04.01** 必须分别声明系统返回、顶栏返回、选择取消、遮罩和滑动关闭的结果。
- **UI-04.02** 有局部模式时先按当前参考实现退出模式；选择与搜索共存时遵循书库的先取消选择再退出搜索。
- **UI-04.03** 嵌套弹层先返回内部上一级；关闭弹层不应同时弹出底下的业务页面；弹层关闭的一个动作只执行一次。
- **UI-04.04** 未提交编辑默认取消无副作用；高成本草稿退出需确认或明确保存方案，禁止静默丢弃。

### 验收场景

| ID | 场景/前置 | 操作 | 预期 |
|---|---|---|---|
| UI-04-C01 | 子级返回：子级深度为1 | 触发返回两次 | 先回父内容，再退出示例。 |
| UI-04-C02 | 选择优先：选择与查询共存 | 连续返回 | 先清空选择，再关闭查询。 |
| UI-04-C03 | 搜索关闭：查询已打开 | 系统返回 | 关闭查询并保留本页。 |
| UI-04-C04 | 嵌套弹层：弹层打开后进入第二层 | 返回、再返回 | 先回弹层首页，再关闭弹层。 |

验证层级：本地模型断言只证明状态转换；Android 组件行为、视觉、设备环境和生产业务必须各自记录证据。

## UI-05 安全区与滚动容器

适用范围：可滚动页面、键盘、浮动操作。

例外与边界：嵌套内容的已消费边距不重复添加。

参考实现：S15、S04、S20；读取当前工作分支对应文件后实现。

### 强制条款

- **UI-05.01** 内容必须使用宿主传入的 PaddingValues；同一边缘由一个层级消费，禁止再叠加猜测的状态栏高度。
- **UI-05.02** 有 FAB 时保留项目 Scaffold 的底部避让；最后一项及底部按钮必须可完全滚入并点击。
- **UI-05.03** 顶栏滚动行为连接到实际滚动容器；不得嵌套两个无约束的同向滚动容器。
- **UI-05.04** 输入页面处理 IME，使用 start/end 方向边距；真实键盘、手势导航和三键导航需要设备验证。

### 验收场景

| ID | 场景/前置 | 操作 | 预期 |
|---|---|---|---|
| UI-05-C01 | 长列表：多项数据 | 滚到最后一项 | 末项可点击且无顶栏遮挡。 |
| UI-05-C02 | 浮动按钮：开启FAB | 滚至底部 | 末项不被FAB覆盖。 |
| UI-05-C03 | 键盘：输入场景 | 聚焦最后的输入框 | 输入和提交入口可见。 |
| UI-05-C04 | 方向布局：RTL设备设置 | 横向观察与点击 | 方向性边距正确，导航图标按项目镜像。 |

验证层级：本地模型断言只证明状态转换；Android 组件行为、视觉、设备环境和生产业务必须各自记录证据。

## UI-06 状态保留与回跳

适用范围：有用户输入或滚动状态的页面。

例外与边界：敏感字段、短暂提示、一次性事件不自动持久化。

参考实现：S01、S03；读取当前工作分支对应文件后实现。

### 强制条款

- **UI-06.01** 为查询、选中项、分类、滚动、草稿分别定义保存范围：重组、回栈、配置重建、进程重建或持久偏好。
- **UI-06.02** 短暂UI状态用 saveable 或持有状态的现有机制；业务状态归 ViewModel/仓库；禁止将 remember 当成进程恢复保障。
- **UI-06.03** 恢复以稳定实体ID重建状态；数据变化后清理失效选择并限制页码，不能用列表位置当长期标识。
- **UI-06.04** 回跳与外部入口分别测试；事件不得因恢复重复提交；执行过配置重建不能宣称执行过进程终止测试。

### 验收场景

| ID | 场景/前置 | 操作 | 预期 |
|---|---|---|---|
| UI-06-C01 | 输入保留：输入草稿 | 触发无关重组 | 输入和选择不丢。 |
| UI-06-C02 | 回栈保留：修改标签和计数 | 回目录再进入同类别 | 本轮会话状态恢复。 |
| UI-06-C03 | 配置重建：草稿非空 | 旋转设备或重建Activity | 声明为saveable的状态恢复。 |
| UI-06-C04 | 进程恢复：保存测试草稿 | 按文档执行进程终止并回任务 | 仅已声明可恢复字段恢复，无重复动作。 |

验证层级：本地模型断言只证明状态转换；Android 组件行为、视觉、设备环境和生产业务必须各自记录证据。
