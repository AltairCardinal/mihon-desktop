# 02-content-actions — Mihon fork UI 规范 v1.0

本文件中的“必须/禁止”是本次制定的 fork 规范。来源标记对应 `source-outline.md` 的固定提交索引；规则中增加的健壮性要求不表示上游所有代码已经符合。

## UI-07 主要操作与可用性

适用范围：主操作、FAB与上下文动作。

例外与边界：没有有效操作的页面可以不展示FAB。

参考实现：S04、S10；读取当前工作分支对应文件后实现。

### 强制条款

- **UI-07.01** 页面必须指定主操作及可用条件；主操作位置沿用同类页面，禁止无依据地增加另一套大按钮。
- **UI-07.02** 是否显示、禁用或替换必须依据真实状态；不可用动作不能靠空回调实现。
- **UI-07.03** 选择模式与正常模式操作相互协调；例如章节选择时停止显示继续阅读FAB。
- **UI-07.04** 主操作必须防止重复提交；隐藏后的页面布局仍应正确收回占用空间。

### 验收场景

| ID | 场景/前置 | 操作 | 预期 |
|---|---|---|---|
| UI-07-C01 | 可执行：存在未读项 | 点击主操作 | 进入对应假数据结果。 |
| UI-07-C02 | 无候选：没有未读项 | 检查FAB | 无无效继续入口。 |
| UI-07-C03 | 多选：预选项目 | 检查主操作与批量操作 | 继续入口隐藏，批量入口可用。 |
| UI-07-C04 | 执行中：任务运行 | 重复点击启动 | 只启动一次。 |

验证层级：本地模型断言只证明状态转换；Android 组件行为、视觉、设备环境和生产业务必须各自记录证据。

## UI-08 条目和点击区域

适用范围：列表、网格、嵌套按钮。

例外与边界：各业务的封面/整行动作可不同，需在映射表中声明。

参考实现：S21、S11；读取当前工作分支对应文件后实现。

### 强制条款

- **UI-08.01** 相同实体的不同展示模式应保持动作语义；优先复用既有列表和封面组件。
- **UI-08.02** 必须声明整行、封面、尾部、长按的独立事件；子按钮动作不得冒泡触发整行动作。
- **UI-08.03** 选择模式点击切换选择，普通模式点击打开内容；长按有明确用途并具备替代入口。
- **UI-08.04** 列表使用稳定键；处理长标题、缺封面、大列表和字体放大；纯装饰图片不重复读屏。

### 验收场景

| ID | 场景/前置 | 操作 | 预期 |
|---|---|---|---|
| UI-08-C01 | 普通列表：默认列表 | 点击整行和尾部动作 | 输出不同事件，每次只执行一个。 |
| UI-08-C02 | 网格：网格模式 | 点击同一实体 | 与列表打开相同实体。 |
| UI-08-C03 | 长标题：长文本假数据 | 放大字体并点击 | 文本不覆盖尾部动作。 |
| UI-08-C04 | 选择模式：预选一项 | 点击另一项 | 只切换选择，不进入详情。 |

验证层级：本地模型断言只证明状态转换；Android 组件行为、视觉、设备环境和生产业务必须各自记录证据。

## UI-09 选择与批量操作

适用范围：支持选择的集合。

例外与边界：未提供批量业务的页面不强制加入选择模式。

参考实现：S03、S10、S02；读取当前工作分支对应文件后实现。

### 强制条款

- **UI-09.01** 进入、退出、全选、反选和范围选择必须定义作用集合；全选不得默默包含当前筛选之外的不可见实体。
- **UI-09.02** 选中计数与稳定ID集合一致；零选中退出动作模式；返回优先取消选择。
- **UI-09.03** 批量操作按选中项目能力和状态计算适用子集，并说明部分成功或跳过；禁止只依据首项状态。
- **UI-09.04** 确认、失败和取消后是否清空选择分别声明；不得因列表排序使选中实体变化。

### 验收场景

| ID | 场景/前置 | 操作 | 预期 |
|---|---|---|---|
| UI-09-C01 | 单选进入：无选中项 | 长按一项 | 进入选择模式，计数为1。 |
| UI-09-C02 | 多项选择：已有选中项 | 点击另一项再取消 | 计数和选中外观同步。 |
| UI-09-C03 | 全选反选：六项数据 | 全选后反选 | 计数归零，恢复普通模式。 |
| UI-09-C04 | 范围与混合：项目状态混合 | 范围选择并执行可用批量动作 | 只作用于适用实体并反馈。 |

验证层级：本地模型断言只证明状态转换；Android 组件行为、视觉、设备环境和生产业务必须各自记录证据。

## UI-10 滑动拖拽与触觉

适用范围：有滑动或排序的条目。

例外与边界：无触觉硬件或系统关闭触觉时允许没有震动。

参考实现：S05、S04、S03；读取当前工作分支对应文件后实现。

### 强制条款

- **UI-10.01** 章节滑动读取原版用户配置，明确 start/end 动作和禁用条件；选择模式不得意外执行横滑业务。
- **UI-10.02** 拖拽从明确手柄或既有长按机制发起；与滚动、点击、范围选择避免竞争。
- **UI-10.03** 排序提交遵循稳定ID与持久化规则；失败恢复原序列或提示未保存；拖拽取消不得误提交业务删除。
- **UI-10.04** 触觉沿用同类行为且每次有效操作只触发一次；重要操作必须具备非手势入口。

### 验收场景

| ID | 场景/前置 | 操作 | 预期 |
|---|---|---|---|
| UI-10-C01 | 横滑：正常条目 | 按提示横滑条目 | 只有配置动作触发。 |
| UI-10-C02 | 禁用横滑：选择模式 | 尝试横滑 | 不触发滑动动作。 |
| UI-10-C03 | 重排序：默认顺序 | 长按手柄拖到新位置 | 顺序变化且返回后保留本轮状态。 |
| UI-10-C04 | 替代入口：不使用手势 | 使用上移下移动作 | 可以完成相同排序。 |

验证层级：本地模型断言只证明状态转换；Android 组件行为、视觉、设备环境和生产业务必须各自记录证据。

## UI-11 搜索与键盘

适用范围：可搜索界面。

例外与边界：自动过滤与提交搜索是不同策略，页面必须选定一种。

参考实现：S02、S03、S11；读取当前工作分支对应文件后实现。

### 强制条款

- **UI-11.01** 查询用null表示未打开搜索，空字符串表示打开但未输入；不得将两者合并。
- **UI-11.02** 进入搜索按现有焦点策略请求键盘；清空查询保持模式和焦点；退出搜索恢复顶栏并释放焦点。
- **UI-11.03** 键盘搜索与可见提交入口共用校验；空白查询按页面策略处理，异步旧结果不得覆盖新查询。
- **UI-11.04** 明示搜索范围；查询和筛选共存时空结果提示应能帮助解除限制。

### 验收场景

| ID | 场景/前置 | 操作 | 预期 |
|---|---|---|---|
| UI-11-C01 | 未搜索：query=null | 点击搜索 | query变为空字符串。 |
| UI-11-C02 | 空查询：搜索已打开 | 清空再返回 | 清空保持模式；返回退出。 |
| UI-11-C03 | 有效查询：输入关键词 | 键盘提交 | 只提交一次且关闭键盘。 |
| UI-11-C04 | 无结果：特殊查询 | 清空搜索 | 出现无结果提示，清空后恢复数据。 |

验证层级：本地模型断言只证明状态转换；Android 组件行为、视觉、设备环境和生产业务必须各自记录证据。

## UI-12 筛选排序显示偏好

适用范围：集合筛选和显示选项。

例外与边界：随机排序沿用独立语义；不假设每项都能切升降序。

参考实现：S08；读取当前工作分支对应文件后实现。

### 强制条款

- **UI-12.01** 三态筛选使用项目枚举和循环顺序；不得把包含、排除、无约束压成普通开关。
- **UI-12.02** 活动筛选有可见提示，并提供可理解的复位；全局模式强制的选项需展示原因及禁用状态。
- **UI-12.03** 排序字段和方向分开保存；当前字段重复点击按原版翻转方向；随机排序不显示虚假的升降序。
- **UI-12.04** 注明选项作用于全局、分类或单作品，以及即时生效/确认生效；横竖屏列数沿用原偏好。

### 验收场景

| ID | 场景/前置 | 操作 | 预期 |
|---|---|---|---|
| UI-12-C01 | 三态：默认无约束 | 连续切换三次 | 无约束、包含、排除可辨别。 |
| UI-12-C02 | 活动筛选：包含筛选 | 复位 | 过滤提示消失。 |
| UI-12-C03 | 排序：默认升序 | 重复选择同字段 | 切换方向，显示顺序改变。 |
| UI-12-C04 | 强制条件：仅下载模式 | 尝试修改下载筛选 | 禁用且说明原因。 |

验证层级：本地模型断言只证明状态转换；Android 组件行为、视觉、设备环境和生产业务必须各自记录证据。
