# 06-business-flows — Mihon fork UI 规范 v1.0

本文件中的“必须/禁止”是本次制定的 fork 规范。来源标记对应 `source-outline.md` 的固定提交索引；规则中增加的健壮性要求不表示上游所有代码已经符合。

## UI-27 作品与章节

适用范围：作品详情、章节列表与快捷入口。

例外与边界：样例使用虚构实体；真实阅读/下载/来源需另跑集成。

参考实现：S04、S10、S11；读取当前工作分支对应文件后实现。

### 强制条款

- **UI-27.01** 封面、标题、章节行、来源、继续阅读和追踪各自有明确动作映射；跨历史与更新页保持语义一致。
- **UI-27.02** 继续阅读根据未读章节与进度决定目标；全读、空章节、缺源和离线各自有可理解结果。
- **UI-27.03** 选择状态、滑动、书签、下载和阅读状态联动使用同一实体状态；批量状态遵循UI-09。
- **UI-27.04** 详情大小屏布局复用原实现；测试需要普通、全读、筛选空和来源缺失数据。

### 验收场景

| ID | 场景/前置 | 操作 | 预期 |
|---|---|---|---|
| UI-27-C01 | 可继续：存在未读章节 | 继续阅读 | 定位下一未读假章节。 |
| UI-27-C02 | 全已读：所有章节已读 | 检查继续入口 | 不出现无目标动作。 |
| UI-27-C03 | 多选章节：选择两章 | 批量标记 | 只修改所选假章节。 |
| UI-27-C04 | 缺源：来源缺失 | 检查返回与恢复 | 信息保留，有缺失说明。 |

验证层级：本地模型断言只证明状态转换；Android 组件行为、视觉、设备环境和生产业务必须各自记录证据。

## UI-28 阅读器

适用范围：阅读器、页码和阅读设置。

例外与边界：手势、音量键、真实图像解码与翻页性能需原阅读器集成测试。

参考实现：S18；读取当前工作分支对应文件后实现。

### 强制条款

- **UI-28.01** 阅读器为独立页面类型，工具栏可以隐藏；隐藏时必须保留可发现的恢复手势与系统退出路径。
- **UI-28.02** 翻页、章节跳转和页码必须限制边界；阅读方向、界面RTL和滑块方向分别定义。
- **UI-28.03** 点击区域、缩放、长按、音量键使用当前阅读器配置；新增动作不能拦截已有手势。
- **UI-28.04** 单作品覆盖与全局默认分离；设置关闭后保持阅读位置；加载失败和末章结果明确。

### 验收场景

| ID | 场景/前置 | 操作 | 预期 |
|---|---|---|---|
| UI-28-C01 | 工具栏：第一页 | 点内容显示/隐藏 | 控制层可恢复。 |
| UI-28-C02 | 边界：首末页 | 尝试越界 | 页码始终在有效范围。 |
| UI-28-C03 | 方向：反向阅读 | 前后翻页 | 语义前后与阅读方向一致。 |
| UI-28-C04 | 设置返回：中间页 | 打开设置再关闭 | 页码不丢失。 |

验证层级：本地模型断言只证明状态转换；Android 组件行为、视觉、设备环境和生产业务必须各自记录证据。

## UI-29 下载与后台控制

适用范围：队列和后台任务页面。

例外与边界：取消队列不自动删除已下载文件；策略变更需记录。

参考实现：S13；读取当前工作分支对应文件后实现。

### 强制条款

- **UI-29.01** 等待、运行、暂停、失败、完成区分显示；暂停/恢复入口与真实任务状态一致。
- **UI-29.02** 单项取消、全部取消、清空完成、删除文件有不同作用域；文案不可混用。
- **UI-29.03** 任务去重、进度边界、排序持久化和失败重试明确；不得启动后立即显示完成。
- **UI-29.04** 离开页面后任务若继续，需可恢复进度与控制；样例仅驱动内存任务，禁止启动真实下载。

### 验收场景

| ID | 场景/前置 | 操作 | 预期 |
|---|---|---|---|
| UI-29-C01 | 待运行：默认队列 | 启动 | 进入运行且进度未满。 |
| UI-29-C02 | 暂停恢复：正在运行 | 暂停再恢复 | 进度不回零。 |
| UI-29-C03 | 失败重试：失败项 | 重试 | 进入等待或运行，已有完成项保留。 |
| UI-29-C04 | 空队列：全部取消 | 查看动作 | 没有无效运行FAB。 |

验证层级：本地模型断言只证明状态转换；Android 组件行为、视觉、设备环境和生产业务必须各自记录证据。

## UI-30 源扩展与外部入口

适用范围：源、扩展和跳转。

例外与边界：权限、签名信任、系统安装器必须在隔离测试环境集成验证。

参考实现：S16、S09、S04；读取当前工作分支对应文件后实现。

### 强制条款

- **UI-30.01** 源缺失、扩展可安装、已加载、可更新、不受信任和加载失败必须区分动作与提示。
- **UI-30.02** 缺权限提供解释和系统入口；拒绝/取消返回后可恢复，禁止自动反复弹权限。
- **UI-30.03** 信任决定必须由用户明确操作，展示原版风险与标识；不能为便利自动信任签名。
- **UI-30.04** 应用内网页、外部浏览器、复制、分享分开命名；恶意/无效链接不得直接作为内部导航指令；样例不发起外部安装。

### 验收场景

| ID | 场景/前置 | 操作 | 预期 |
|---|---|---|---|
| UI-30-C01 | 可安装：可用扩展 | 假安装 | 显示运行状态。 |
| UI-30-C02 | 已加载：已有扩展 | 打开设置 | 进入假配置。 |
| UI-30-C03 | 未信任：未信任标记 | 取消或确认信任 | 取消不改变信任，确认才改变。 |
| UI-30-C04 | 缺权限：无安装权限 | 重试入口 | 只记录请求，未获得权限前不安装。 |

验证层级：本地模型断言只证明状态转换；Android 组件行为、视觉、设备环境和生产业务必须各自记录证据。

## UI-31 追踪与外部绑定

适用范围：追踪服务面板。

例外与边界：不同服务能力不统一；真实OAuth和远端同步不在假数据页验证。

参考实现：S23；读取当前工作分支对应文件后实现。

### 强制条款

- **UI-31.01** 未登录、未绑定、已绑定、搜索中、失败和已解绑分别定义；禁止把UI勾选视为服务端成功。
- **UI-31.02** 评分、日期、私密状态按服务能力显示；未支持字段无可编辑入口。
- **UI-31.03** 修改状态/进度/评分验证范围，异步失败保留上下文；远端结果与本地显示的一致性有集成测试。
- **UI-31.04** 解绑需说明本地关联与远端记录的影响；不记录或展示令牌；样例使用虚构服务。

### 验收场景

| ID | 场景/前置 | 操作 | 预期 |
|---|---|---|---|
| UI-31-C01 | 未绑定：假服务 | 搜索后绑定 | 进入已绑定假状态。 |
| UI-31-C02 | 完整能力：支持评分日期 | 编辑字段 | 字段按范围更新。 |
| UI-31-C03 | 能力有限：服务不支持评分 | 查看面板 | 评分入口不存在。 |
| UI-31-C04 | 失败解绑：保存失败 | 重试或取消解绑 | 错误明确，取消保留关联。 |

验证层级：本地模型断言只证明状态转换；Android 组件行为、视觉、设备环境和生产业务必须各自记录证据。

## UI-32 存储备份与导入导出

适用范围：文件选择、导入、恢复与导出。

例外与边界：样例不读写真实URI；完整备份恢复需使用可丢弃测试数据库。

参考实现：S22；读取当前工作分支对应文件后实现。

### 强制条款

- **UI-32.01** 未选择目录、有效目录、权限失效、文件不兼容和处理中有明确文案与恢复入口。
- **UI-32.02** 选择器取消无副作用；结果有效后才记录目录；持久授权失败不能假定长期可访问。
- **UI-32.03** 恢复/导入前展示范围和冲突策略，过程互斥；不可取消阶段说明边界；失败不能显示完成。
- **UI-32.04** 恢复后的数量/关系/文件需要验证，不仅检查任务结束；样例只驱动内存状态，不恢复用户书库。

### 验收场景

| ID | 场景/前置 | 操作 | 预期 |
|---|---|---|---|
| UI-32-C01 | 未配置：未选目录 | 假选择和取消 | 取消不改变配置。 |
| UI-32-C02 | 有效：假目录有效 | 开始假备份 | 运行中禁止重复任务。 |
| UI-32-C03 | 权限失效：失效状态 | 重新授权 | 显式操作才变为有效。 |
| UI-32-C04 | 不兼容：无效文件 | 尝试恢复 | 拒绝执行并保留原数据。 |

验证层级：本地模型断言只证明状态转换；Android 组件行为、视觉、设备环境和生产业务必须各自记录证据。
