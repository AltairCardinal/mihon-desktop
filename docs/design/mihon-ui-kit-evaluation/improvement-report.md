## 源码纠正

初版V1统一要求2:3，Luna读取当前Desktop书架/详情的显式0.7f后，主代理独立确认并修订为Windows7:10、Android2:3。修改理由是原规范引用平台与实际消费组件不同，不是为已有结果放宽断言。此前3:4在两端均不匹配；独立几何断言已改为分别检验平台实际值。

## 对比原则

旧版也经过修复并有6项测试通过，但保留二态筛选、无反选/范围、无继续阅读入口、3:4封面等不足。新版以冻结契约验证这些具体差异；测试数量增加不直接等于质量提高。

`contract-oracle.test.cjs`由主代理独立编写，读取真实DOM几何、计算颜色、跨iframe焦点/状态，并用捕获阶段阻断开关事件作为负对照：相同偏好持久到面板重开的断言必须失败，解除阻断后必须通过。该检验没有改生产实现，不复制应用算法，也不以符号扫描代替行为测试。

此轮实现者拥有上轮上下文并收到更具体要求，因此能证明“文档+固定验收+修复流程交付更完整样本”，不能单独分离文档、额外投入和代理学习各自的因果贡献。不宣称未经协助的首次生成已完全合规。
