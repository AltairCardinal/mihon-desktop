- 交互基线：[双端DEMO](prototypes/author-identity/index.html)，冻结提交 `7773095f5e`。
- 配套计划：[开发Roadmap](roadmap/2026-09-18-author-experience-iteration-roadmap.md)。
- 本文整合本轮所有验收反馈。与此前[验收调研](2026-09-18-author-ui-acceptance-design.md)、[作品与日期补充](2026-09-18-author-work-presentation-and-dates.md)冲突时，以本文为准；原调研保留为决策依据。

## 1. 目标、范围与不变量

用户能在关注列表辨认作者、发现未看过的作品，在作者详情按书架习惯浏览作品，再选择具体图源版本。日期不能因为重新抓取而冒充今天上架。

本轮包含：作者列表关注/全部子页及B布局、详情标准顶部栏和横向来源筛选、三种作品视图、收藏图标、多图源选择、新作反馈闭环、代表作选择、日期可信度和稳定保存，以及所需双端接线、迁移和验证。

继承以下规则，任何新实现都不得改变：

1. 相同非空作者名称文本跨插件无条件作为同一个人；来源ID、远端作者ID不决定人物身份。不自动繁简、音译、大小写转换。不同名字通过添加别名关联。
2. 作者同一与作品同一是两种关系：canonical 作品身份只来自已有确认事实，不因作者或标题相同而自动写入；作者页展示层可以按[简繁同名自动聚合设计](2026-09-19-author-work-script-equivalence-presentation-design.md)合并严格等价的来源版本，原始来源身份保持独立。
3. 主名、别名、关注、既有高级作品校正和语言证据保留。普通详情去掉内部语言枚举，不删除其数据或原有能力；已有高级操作复用既有更多菜单/页面，不新增管理系统。
4. 全局检查频率只有每天、每周、每月，入口在作者列表右上角设置，适用于当前及未来关注作者。保留现有调度、约束、退避、来源/语言策略。
5. 取消关注不删除作品，修改主名不改变作品、阅读状态或日期；别名合并保留关注并集和旧入口重定向。

不包含：新身份算法、自动模糊同作匹配、全网爬取或人气排名、手工代表作编辑器、自动跨源收藏/下载、新的同步协议、全新系统通知中心。已有系统通知和手动检查能力须保留，但应用外DEMO按钮不进入正式产品。

**2026-09-19 需求迭代**：简繁同名不再要求用户进入审阅并手动确认。作者页按[专门设计](2026-09-19-author-work-script-equivalence-presentation-design.md)自动把简繁及排版符号等价的来源版本显示为一个作品，来源窗口沿用原有图源名称并保留各自原题和准确导航。自动聚合是展示投影，不创建 canonical、不改写来源事实；已有 canonical 优先，歧义保持分开，并提供“分开显示/撤销”纠错。该需求由路线图 AX-08 承接，替代 AX-07 的手动交互。

## 3. 作者列表

### 3.1 关注与全部

默认只显示已关注活跃根作者；全部是本地已收录活跃根作者，不是全网作者目录。取消最后一位关注时显示精确文案「关注作者以获取他们的新作提示」及「查看全部作者」。关注/全部各自保存本次导航会话的滚动位置。详情返回恢复进入时子页；从主导航重新进入切回关注。

关注变化和作者合并通过现有订阅即时更新。加载显示进度，读取失败提供重试并保留可用旧数据；空结果与读取失败不能混用。

### 3.2 B布局与代表作

无头像。作者主名、作品数/关注状态、新作数量在卡片头部；下方最多3张竖封面和作品名。整张卡片（包括封面）进入作者详情，不在代表作封面上另设漫画入口。只有一部就显示一部，无作品显示「暂无作品」。

生产代表作选择是帮助用户辨认的本地展示规则，不宣称官方代表作：

1. 从有效已验证作者关系及可见作品中选择；排除拒绝及仅搜索猜测关系。语言UNKNOWN不等于作者关系不可信。
2. 以canonical work去重，未确认关系按source natural key独立。收藏且读过 > 收藏 > 读过 > 其余已归档；同档首次选择优先有封面引用、最近阅读时间、稳定键。
3. 保留仍合格的旧选择，同档新作品只补空位；收藏/阅读档位晋级可替换较低档。改名、普通刷新、一次封面失败不换位。
4. 同作品封面版本优先保留已有选择，其次自定义/收藏封面、现有语言偏好、可用来源，稳定键裁决。缺图使用书名占位；离线优先缓存。
5. 保存可重建的本设备展示缓存和策略版本，不作为身份事实，不进入本轮备份/同步事实。合并保留目标作者仍合格作品并补位，失去资格才移除。
6. 批量读取当前页作品/收藏/阅读信号，懒加载封面；不得逐作者全量查询或为排名联网抓详情。复用Coil及平台封面adapter、请求头、自定义封面和缓存失效逻辑。

## 4. 作者详情与名称操作

主名采用漫画详情作品标题字号/字重/正文色，无前置人物图标。别名横向排列，空间不足换行；采用原版漫画署名14sp/500/20sp行高的文字链接和16dp人物图标。没有别名整行隐藏，不显示「尚无其他名字」。平台字体缩放使用原生单位，不把HTML像素当绝对尺寸。

「添加别名」打开其他已收录名字候选，可搜索、多选，按钮为「添加」。不增加合并预览、关注勾选、频率设置。零选择不能提交；失败保留选择；数据过期在当前窗口刷新候选；取消不写入。

点击别名提示「要把XXX设为该作者的显示名称吗」；确定后旧主名成为别名，取消无变化。无独立「修改名称」按钮，无自由输入改名。取消关注须确认。

作品标题后紧跟当前筛选作品数，次级12sp/500等宽数字，不远置到右侧。顶部作品总数/来源版本数表达完整作者归档，分区数字表达筛选后的去重作品数，二者不能互相替换。

## 5. 作品列表、偏好与收藏

### 5.1 显示方式

复用书架列表、舒适网格（标题在封面下）、紧凑网格（标题渐变覆盖）的渲染能力，保留作者页日期、新作和来源数量。列表封面与标题顶部对齐。抽取最小可复用视觉组件，不能把书架下载/选择/全局筛选状态搬入作者页。

有效显示方式 = 作者作品覆盖值（存在且有效时），否则为书架当前显示方式。

| 事件 | 覆盖值 | 结果 |
|---|---|---|
| 首次打开或旧用户升级 | 未设置 | 动态跟随书架，不在读取时写入默认值 |
| 未选择时书架变化 | 未设置 | 作者详情跟随变化 |
| 用户选一个方式，包括与当前相同的值 | 保存所选值 | 立即应用，今后不再跟随书架 |
| 切换作者/来源/修改名字 | 保留 | 所有作者共用一个覆盖值 |
| 重启 | 从偏好存储恢复 | 保持用户选择 |
| 无效或无法识别值 | 视作未设置 | 安全回退到书架，不能崩溃 |
| 保存失败 | 保留原值 | 显示失败，可重试，不能假报已保存 |

覆盖值按设备保存，不按作者建键，不回写书架；本轮不增加恢复跟随按钮。只继承书架的显示方式，不继承分类过滤。若平台有分类专用视图，用其现有全局书架显示偏好解析器，不能由最后浏览分类偶然决定作者页。

### 5.2 收藏

任一已确认版本收藏，则聚合作品为已收藏，来源过滤不能改变这个事实。图源窗口各版本独立反映favorite。书架收藏变化应即时传播，远程元数据不得覆盖本地favorite。

收藏沿用原版CollectionsBookmark轮廓图标、secondary/onSecondary配色、12sp图标、水平3dp/垂直1dp内边距、4dp圆角；封面透明度0.34，图标/独立标题不一起淡化。**包括列表在内，所有作者作品封面的图标均在左上角，距边4dp**，这是用户确认的原版列表位置例外。提供「已收藏」无障碍名称与桌面悬停提示。

## 6. 来源过滤与版本选择

全部来源和每个来源用Material FilterChip横向完整列出并横向滚动，选中填色与勾号，未选边框；参照GlobalSearchToolbar「已置顶/有结果」样式。单选并与作品搜索取交集，默认全部。来源缺失仍保留可筛选名称与本地作品。无结果提示可清空搜索/切换来源，不删除数据。

点击作品先打开「选择漫画源」。窗口取当前作者该作品的全部已收录版本，不能沿用过滤后的版本子集；说明「此作品的全部来源版本」。每项包括该版本封面、图源名、作品标题、总章节数、收藏状态、最新章节日期。

- 完整目录才能显示N章；未抓取显示「章节数未知」，仅分页子集显示「已获取N章」。不能把未知当0，或把跨源章数相加。
- 日期字段缺少显示「日期未提供」，有但不可信显示「日期待核实」；有效日期显示「最新章节 YYYY-MM-DD」。
- 复用OpenCreatorWorkVersion及既有导航，有本地mangaId直接进入，无mangaId沿用现有保存/打开流程，不重复创建漫画。失败保留窗口并反馈；缺源仍可查看本地详情，不能虚构在线成功。
- 打开窗口不触发多个图源并发抓取；信息来自归档/已有目录缓存，缺失数据可由既有更新链路后续补齐。
- 缺封面占位、长标题换行、320dp内部滚动、键盘焦点限制在窗口内。取消不算查看新作。
- 同一作者归档内简繁及排版符号等价的来源版本自动显示为一个作品，不显示检测提示或合并按钮。归一化忽略空白、书名号、引号、冒号等排版标点，保留大小写、数字、卷次和副标题正文边界；来源窗口沿用作品列表已有图源名称并显示完整成员及各自原题，误判可“分开显示”并撤销。

## 7. 新作发现与查看闭环

### 7.1 范围与去重

复用既有发现服务、来源检查点、baseline、discoveries及通知outbox。只有关注期间、基线完成后发现的有效新作品计入提醒。首次建基线、导入旧书架、恢复备份、合并作者产生的历史关系不生成新作；未关注期间的发现不在关注时补发。

按canonical work聚合；作者页简繁/排版符号等价展示组也只显示一次新作状态，但不写入 canonical 身份。其他未确认同作关系仍按来源自然键独立，不能用模糊标题强并。已有作品新增来源/章节不再计新作。新作实际含义是「本地新发现」，可能是旧作品，不等于今天出版。

既有来源级发现记录继续保存，新增共享作品级投影/必要索引用于统一计数，不另建一套消息中心。相同作品关联多个关注作者时，各作者可显示所属计数，总提醒按作品去重。

### 7.2 可见反馈

| 状态/动作 | 反馈及写入 |
|---|---|
| 后台发现未查看新作品 | 应用内「发现 N 部新作」＋作者名＋「查看新作」；作者卡片显示N部新作 |
| 用户查看提醒 | 进入仍有未查看作品的作者详情，清空作品搜索/来源过滤，新作排前并聚焦；不清除未查看 |
| 作者详情 | 三种视图均显示「新作 · 未查看」，日期单独显示 |
| 打开/取消来源窗口 | 未查看不变 |
| 任一版本漫画详情成功进入 | 按作品标为已查看，关联来源发现一起更新，计数/标记同步消除 |
| 导航或标记保存失败 | 导航失败不清除；标记保存失败保留未查看并提示，不因乐观更新丢提醒 |
| 重复检查或另一来源到达 | 不重复提醒已查看作品 |
| 弹窗期间发现 | 不跳页、不抢焦点；关闭弹窗后刷新提示 |
| 取消关注 | 隐藏该作者提示、停止后续发现通知；历史已查看事实保留，再关注不补发取消期间事件 |

多作者提醒以最早未查看发现时间、稳定作者键决定下一目标；查看一个作者不会清除其他作品。普通列表沿用稳定顺序，未查看新作品排前，再按首次发现时间倒序及稳定键排序，不能用可变上架日期驱动新作排序。

已发送系统通知沿用现有平台adapter和权限行为，本轮不重新设计通知中心或要求HTML申请通知权限。通知发送成功不等于用户已查看；进入详情后的确认才更新查看状态。取消关注和重试沿用已有outbox幂等约束。

### 7.3 持久化与关系变化

作品级已查看事实在版本更新、重启后保留。标记已查看必须与所有当前成员的发现更新在同一事务处理；并发到达的新来源通过作品已查看事实抑制重复提醒。别名合并不重新生成事件；同作合并以已查看优先避免重复，保留原始发现记录；拆分继承成员原始查看证据，不能复制无关作品状态。历史迁移以既有read状态为准，不能把全部旧作品默认标新。

## 8. 日期语义与本地来源可信记录

### 8.1 三种时间

| 字段 | 来源与用途 | UI |
|---|---|---|
| 来源作品上架日期 | 明确语义且可信的作品日期字段；取已知版本最早可信值 | 上架 YYYY-MM-DD，可查来源依据；不宣称全网首发 |
| 最新章节日期 | 该版本目录的有效章节更新时间，独立判断字段可信度 | 图源窗口最新章节日期 |
| 本地首次发现 | 首次记录来源作品的本地事件时间；作品取有效成员最早值 | 缺可信上架时显示首次发现 YYYY-MM-DD |

章节最早日期不能冒充作品上架日期。只有年份/月时保存精度和原文，不补造1月1日，主日期退回完整首次发现日。非法日、未来日、未知语义或默认当前时间不得当可靠日期。

首次发现与最后抓取分别保存，网络响应不得覆盖首次发现。普通刷新只允许更早可信证据修正，或相同日从首次发现升级为上架；不得推迟。原始首次发现始终保留。可信度降级后保存原展示日期和失效依据，并标注「日期依据待核实」，不改成今日。显式纠错/作品拆分按实际成员证据重算并保留审计，不属于普通刷新。

本地保存UTC时刻及首次展示的日期/时区，冻结日精度标签，重启和时区变化不能让日期后移。来源只给日期时保留来源日期语义，无可靠时区不能猜测转换成用户时区。

### 8.2 可信来源注册表

本地以扩展包、扩展版本、sourceId、字段种类（作品上架/章节更新）索引；状态unknown/trusted/suspect是内部质量状态，不在普通页面显示英文枚举。保存策略版本、采样时间、作品/章节自然键、原值、日期精度、判定理由。此处来源ID用于日期质量，不参与作者身份判定。

默认未知，不预置未经回放验证的漫画柜等真实图源白名单。从既有更新过程积累有界样本，不为判断质量爬全站；每个字段最多保留最近20部样本、每部20个稳定章节、最近两次观察和异常摘要，原始诊断数据30日滚动清理，展示快照与首次日期不随之删除。

章节字段初始门槛：至少3部作品、每部至少3个稳定章节ID及3个不同历史日期，两次观察间隔至少24小时；按章节自然键比对旧记录不变，允许新章追加及目录重排。符合则登记“样本支持可信”，不是绝对真实证明。旧章节整体从历史日期漂移到抓取当日则降级；单次全部同日仅证据不足，不能排除合法集中补档。

作品上架字段独立取证：adapter确认字段标签语义，至少3部作品有不同历史值且跨日稳定、通过日期合法性校验才可登记。章节可信不能自动授予上架字段资格。SManga没有统一可靠上架字段时，使用firstSeen回退；只在已有adapter明确支持时补充字段，不逐图源硬解析页面。

插件版本/格式改变后新观测重新验证；旧快照保存历史证据。网络失败不自动降级，更不能伪造今天日期；无证据就回退。质量策略在共享domain层，平台只提供已有解析结果与来源描述。

共享层管理去重、代表作资格/排序、偏好解析、日期选择/质量、查看事务。两端差异仅限导航、渲染、平台图片与通知adapter；新DI必须注册并测试，不在Composable里执行SQL。

### 数据变更原则

优先扩展现有归档投影和发现表；最少新增：作者显示方式覆盖偏好、日期质量样本/状态、作品展示日期快照、必要的作品级查看事实。只有现有来源级发现无法表达“新来源到达仍已查看”时才增加作品级持久记录，不能仅用内存缓存解决。

日期事实和查看事实属于用户可恢复数据，随已有作者备份schema向后兼容扩展；首次日期取最早、已查看事实单调合并，恢复不创建新事件。日期质量采样和代表作缓存为设备本地可重建数据，不做跨设备可信传播。覆盖偏好为设备本地设置；本轮不扩大同步协议。已有同步触及作者表时补回归，不能由导入/回放生成新作通知。

迁移以事务完成、可重复运行，失败保持旧事实并反馈，不清库。UI遇到缺新元数据使用未知/首次发现回退，不伪造数值。新增表/字段的精确schema及索引随对应批次提交和审查，不在文档中预占迁移号。

## 10. 失败、无障碍及性能

- 网络/缺源/封面失败不阻塞作者列表；保留旧数据、占位和本地详情。章节未加载与0章区别展示。
- 模态对话框取消、关闭、Escape都不提交，焦点回入口；保存成功回目标名称/设置按钮，过期响应不能覆盖另一窗口会话。
- 320dp、深浅主题、系统字号放大、长主名/别名/来源名均可操作；横向溢出仅允许来源chip容器，整页不横滚。图标不可只靠颜色表达。
- 初次作者列表每页最多50位，投影批量读取；代表作只装载最多3项，封面可见区域懒加载。查询次数随页数而非作者数增长，不使用发现服务做列表加载器。
- 来源窗口使用单作品全量已知版本，很多来源时内部滚动。观察采样有界，取消页面不取消已提交后台事务。
