## 2. 本包新增功能与修复

| 用户可见变化 | 操作和边界 |
|---|---|
| 章节开篇选择 | Android 双页阅读器显示工具栏后，底栏“章节开篇”可选“自动”“首页独立”“首两页并排”，当前项有勾选；选择会定位到本章开头 |
| 首两页并排 | RTL 下第1张在右、第2张在左，适用于额外封面/广告后接正文首页；只指定相邻页关系，不识别封面语义、不重新编号源页 |
| 章节级保存 | 开篇选择及手动配对在本机按章保存，重开恢复；其他章不继承。不是跨设备同步或备份能力；“自动”只恢复开篇的自动决策，不是清空整章全部手调 |
| 手动调整稳定性 | 2–3先翻到4–5再返回后，调整能明确组成3–4，不受刚才回翻方向或旧4–5占用影响；间接形成的单页不再陷入永久无操作 |
| 恢复重试 | 使用默认布局后明确重试，可以恢复已保存关系；恢复期间若已翻到其他位置，迟到结果保护新画面，不把用户拉回旧位置 |
| 诊断日志 | 新增 `DualPageManual` 操作/保存/拒绝事件，结合已有 `DualPagePresentation` 与 `DualPageNavigation` 定位问题 |

手动关系优先于自动页侧/匹配评分，但真实宽图继续完整独占，不能强制裁半或保证任意两张都可并排。只有一页的章节无可配对对象。保存未就绪或进行中时入口会禁用；不能把按钮禁用直接当成配对算法无操作，需同时记录保存状态。

接收会话原有“按组翻页、不因加载拆组、未绘制不伪记已读”约束继续有效。本轮没有新增 Desktop 开篇菜单；Desktop 仅适配共享语义、存储及保存接线。

### A. 漫画柜《不死之身的斯黛菈公主》第14话

- [ ] 覆盖安装上面的 code63，打开该话，使用 RTL 双页；记录自动跨页匹配当前开关状态。
- [ ] 显示阅读器工具栏 → 底栏“章节开篇” → “首两页并排” → 第1张单行本封面在右，第2张正文第一页在左，组成一组。
- [ ] 翻到后续页再返回 → 首两页关系保持，不因加载先后重新拆分或交换物理侧。
- [ ] 退出阅读器再打开同章 → 开篇选项与并排关系恢复。
- [ ] 切到另一章 → 没有继承本章的开篇覆盖；返回原章仍保留选择。
- [ ] 选择“首页独立” → 第1张单独一屏；再切回“首两页并排”恢复预期。选择“自动”时由实际自动规则决定，不能预设它一定并排或一定独立。

图像内容和装订方向来自用户描述，本轮没有识别该话原图；上述视觉结果必须由用户判断，不凭页码日志代签。

### B. 漫画柜《平行天堂》“番外篇 修车解咒”

- [ ] 保持自动跨页匹配开启，记录进入时的页组、已有手动选择与页码；原复现状态为 `1 / 2–3 / 4–5`。
- [ ] 在2–3时先翻到4–5，再返回2–3，点击原“调整页面配对” → 3–4组成一组，不只剩第3页独占。
- [ ] 向后翻再返回 → 3–4保持，旧4–5不能重新占走第4页；页标跟随真实位置，不回跳。
- [ ] 如果进入时已是旧问题遗留的第3页独占 → 点击调整，记录实际结果，应存在合法重新配对路径，不再反复点击无变化。不要盲点多次；每次等待保存反馈并记录结果。
- [ ] 退出重开同章 → 手动配对恢复；自动匹配不能悄悄覆盖显式选择。

若已保存为3–4而无法自然重现旧的初始布局，先保留当前状态和日志并说明，不清数据，也不编造“已重新验证2–3→3–4”。

    Select-String 'DualPageManual|DualPagePresentation|DualPageNavigation' |
    Out-File -LiteralPath '<本次忽略目录中的日志绝对路径>' -Encoding utf8
