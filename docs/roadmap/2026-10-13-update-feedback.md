## 范围与预算

复用既有 ReleaseService、GetApplicationRelease、Android 下载/安装、Desktop About 与本地日志入口。
共享层负责更新协议、平台版本比较、渠道与节流；平台层负责通知、系统安装和反馈操作。
发布文件使用本项目 Releases，静态索引使用既有 Pages，人工问题使用本项目 Issues。
不增加服务器、自动遥测、匿名反馈、后台即时推送或 Desktop 自动覆盖安装。

最多两个实施子代理；主代理负责协议冻结、Desktop 接线、发布工具、整合及独立验收。
共享更新与反馈可并行写不同文件；Gradle 由主代理串行协调，资源不足时不追加构建。
高风险协议、APK 校验和发布输入由未实施相应部分的人独立审查一轮，必要修复复审一轮。
逐行为红绿重构、相关集成与格式检查；本轮不执行完整模块/全量矩阵，不分配正式版本。
预计 2–4 小时；构建资源或必要设备受阻时保留事实，继续独立工作，不以跳过代替通过。
过程只维护本计划和一份最终 evidence；协议维护文档属于交付物。

## 固定协议与产品边界

- 唯一默认索引：`https://altaircardinal.github.io/mihon-desktop/updates/v1.json`。
- schema v1 顶层为 `schemaVersion: 1` 与 `releases` 数组；空数组合法，不能虚构发布。
- 每项包含 channel、platform、arch、packageType、version、releaseUrl、downloadUrl、sha256、sizeBytes、notes。
- Android 另含 versionCode、applicationId、certificateSha256；身份以现有正式构建配置为准。
- testing 接受 testing 与 stable，选择本平台最高兼容版本；stable 只接受 stable。切换渠道不降级。
- Android 比较 versionCode；Desktop 比较完整四段数字，提交 hash 不参与顺序。
- 自动检查默认启用；小范围传播默认 testing。成功检查间隔 12 小时，手动检查可强制；失败不写成功时间。
- 网络错误、未知 schema、非法身份、错误校验或歧义条目不得退回上游或执行安装。
- 链接限本项目 HTTPS GitHub Releases，发布页与下载项 tag 一致，不接受凭据、查询、fragment 或路径穿越。
- APK 下载核对长度、SHA-256、包名、版本和签名后才提供系统安装；Debug 不冒充正式覆盖升级。
- Desktop 保留已有安装能力代码，但本项目本轮发布提示只引导显式打开下载页，手动替换。
- 用户反馈不自动提交、不上传、不读取书库或凭据。只生成白名单环境摘要，用户预览、复制并打开公开 Issue 表单。
- 旧包首次需手动安装带新机制的版本；空索引不表示已有可发布候选。

| ID | 操作与预期 |

| F1 | 关于 → 报告问题：显示可滚动安全摘要、GitHub 登录/公开说明及日志未自动附加说明 |
| F2 | 复制摘要：内容等于预览，无安装 ID、用户名目录、书库、历史或 token；成功/拒绝有反馈 |
| F3 | 打开 GitHub：只在显式操作后打开本项目模板，不自动创建 Issue；失败可恢复 |
| F4 | 关闭/Escape/遮罩：不复制、不打开外部网址；返回原 About，保留焦点和背景状态 |
| F5 | 浅深主题、窄尺寸和大字号：使用现有语义 token，摘要可滚动，确认/关闭可达，键盘焦点不穿透 |
