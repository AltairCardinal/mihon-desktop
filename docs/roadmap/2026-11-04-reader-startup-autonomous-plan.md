## 目标与计量

每轮在候选前固定主指标和对照：本轮主收益为同条件新进程首次近黑**上界均值的减少量（ms）**，内部首绘为旁证；逐样本、区间和暖态同时公开，不用均值掩盖失败。若上下界变化不能分辨收益，标记未证实，先检查既有连续帧与同次内部指标，不无限补样本。没有确定收益时不把源码少做工作换算为假定毫秒。

成本按各模型每次响应的 uncached input、cached input 和 output 计算；cached 已包含在 input、reasoning 已包含在 output，均只计一次。包括主代理、子代理、调查、失败、审查、构建等待中的模型调用、分析和收尾。墙钟构建时间不冒充 token 成本。按官方当日 API 价格处理长上下文，不使用订阅额度价格。服务档位、缓存写入字段或历史归属缺失时报告标准化估算及边界，不能称真实账单。

定义 `ROI = 实测主收益 / 本轮 API 等价成本`，首轮以前一完整P4批次作基线，此后按预先固定的研究批次比较，不把同一候选拆成有利的微轮次。收益未证实不等于真实收益0，单个候选失败不证明剩余候选收益单调递减。R2执行用户明确授权的有限研究批次；没有得到可比、可分辨的收益时报告不确定性，不用0制造整体停止证明，也不把单/双页不同场景混算一个ROI。达到完整性能目标后不继续扩大优化。
