# Mihon Desktop 下载目录使用与迁移

## 默认目录与设置入口

进入 `设置 → 下载 → 下载目录` 可以查看：

- **当前目录**：本次启动实际用于下载、查找已下载章节和删除下载的目录；
- **默认目录**：当前平台的默认位置；
- **下次启动目录**：保存了新选择且尚未重启时显示，重启后才会成为当前目录。

平台默认位置为：

- Windows：`%LOCALAPPDATA%\Mihon\downloads`
- macOS / Linux：`~/.mihon/downloads`

“打开目录”始终打开当前目录。“恢复默认”只清除自定义设置，默认目录同样在下次启动后生效。

## 更改目录何时生效

选择目录时，Mihon Desktop 会在后台检查路径是否为可读写目录。选择成功后只保存设置：

- 当前进程、正在下载的任务和已打开的 Reader 继续使用当前目录；
- 应用不会移动、合并、扫描或删除旧目录；
- 完全退出并重新启动 Mihon Desktop 后，新目录才生效；
- 下载目录设置是本机状态，不包含在 Mihon 备份中。

如果队列中还有任务，必须先等待任务完成，再完全退出应用并迁移文件。暂停按钮不保证已经启动的下载 worker 立即停止，因此不能把“已暂停”视为目录树已经静止。应用运行时复制 `_tmp` 或正在写入的页面，可能得到不完整的目录树。

## 手动迁移已有下载

建议采用“先复制、确认后再自行清理旧目录”的方式：

1. 在 `设置 → 下载` 记下当前目录，选择目标目录，并确认页面显示“重启后生效”。
2. 等待下载队列完成，然后完全退出 Mihon Desktop；不要仅凭“已暂停”就开始移动文件。
3. 用文件管理器把**当前下载目录中的全部内容**复制到目标目录，保留原有层级、文件名、CBZ 和 `_tmp` 目录。不要只复制图片文件，也不要自行改名或把不同章节目录合并。
4. 启动 Mihon Desktop。设置页中的当前目录应变为目标目录；抽查普通目录章节、CBZ 和包含非 ASCII 标题或汉化组名称的章节。
5. 确认阅读、删除和后续下载正常后，再按需自行删除旧目录。Mihon Desktop 不会替你删除旧目录。

如果没有复制旧 `_tmp`，它不会被新目录读取，也不会被误判为完整下载；仍在队列中的章节会在新目录中重新下载可用页面。

## 失败与恢复

- **目录不可写、不是目录或路径无效**：选择不会保存；根据页面错误修正权限或重新选择。
- **移动硬盘或网络盘断开**：下载显示存储错误，不会静默写回默认目录。重新连接到同一路径后，在下载队列中重试即可继续使用该目录。
- **原位置无法恢复**：选择另一个可写目录，退出应用，按上面的步骤复制仍可访问的完整目录树，再重启。
- **恢复默认**：保存后退出并重启；旧自定义目录不会被移动或删除，需要时可手动复制到默认目录。
- **只看到旧目录中的章节**：确认应用已经完全重启，并确认复制的是旧根目录的全部内容，而不是多套了一层同名文件夹。

当前边界是“单一启动期目录”：不支持运行中热切换、不自动迁移，也不会长期同时搜索多个历史根目录。
