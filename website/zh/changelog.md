# 变更历史

了解项目当前公开说明的能力，请阅读[当前功能](./features.md)。本页记录这份基线如何变化，不堆叠整份功能说明的副本。

产品公开发行和文档更新是不同事件，这里的日期不等于发行版本。实施中的变化只有在项目所有者明确验收通过后，才会进入公开功能说明。

## 2026 年 10 月 13 日 — 建立文档基线

**文档更新 · 不是产品发行**

- 建立英文默认、简体中文可选的文档网站。
- 汇集五个项目方向与已公开范围：桌面阅读、双页配对、多端同步、作者发现与语言信息。
- 链接已有的桌面下载目录、网络路由、浏览器辅助来源验证与缺失扩展建议指南。
- 将唯一的当前功能说明、按时间记录的变更摘要与每页 Git 历史分开维护。
- 说明贡献者和 Agent 如何在所有者验收通过后更新公开功能声明。

本条目迁移的是既有公开描述，不认证新构建、不宣告产品发行，也不表示其他开发中工作已获验收。

基线来源：[提交 87f8f89 的公开 README](https://github.com/AltairCardinal/mihon-desktop/blob/87f8f895dbb6fc4055c86e3a69043cc4dd30841d/README.md)，以及[其他适配与新增能力](./features.md#other-additions)中链接的已有指南。

## 如何追踪历史

每页的 **查看本页历史** 链接打开对应 Git 提交记录，可查看某次修订的原文和差异。[功能页历史](https://github.com/AltairCardinal/mihon-desktop/commits/main/website/zh/features.md)同时记录替换与新增。

后续验收后的变化以简洁的日期条目记录，附上实现版本与验收引用；有真实公开发行时，再链接对应发行页面。不另建版本状态目录，也不复制多份当前说明。
