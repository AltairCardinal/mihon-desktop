# 规划新增功能投票

这里介绍尚未实现、正在收集需求的功能。你可以分别支持每一项，帮助决定后续开发优先级。投票不代表功能已经提供，也不承诺完成时间。

**每个公网 IP 对每项功能限投一票，中英文页面共用票数。** 同一家庭、公司或校园共享公网 IP 时，会共用该项投票机会。

## 已读删除：增加延迟到下次启动再删除 {#deferred-read-deletion}

**适用平台：Android、Windows、macOS。状态：设计已封存，暂未实现。**

读完后先保留下载，给本次使用留出修改阅读状态的机会。计划在“读完自动删除”下方增加默认关闭的“延迟删除”开关，说明为：

> 下次启动时再删除，如果退出前将状态改回未读的话则不会删除

开启后的使用方式：

1. 读完章节后，退出阅读器仍保留下载。
2. 如果改回未读，就立即取消该章的待删除任务。
3. 下次启动时，处理仍在待删除队列中的下载。

Android 进程可能长期驻留：本次逻辑启动满 **24 小时** 后，退回桌面再点应用图标，也会触发一次清理；普通前后台切换、通知或深链打开不触发这一额外清理。桌面端在完全退出后重新打开时触发。

这项开关仅调整“读完自动删除”的时机。“手动标记为已读后”继续由其独立设置控制；主动删除下载仍按原操作执行。

**边界说明：** 手动删除下载会同时移除待删除任务；每个任务只尝试删除一次，失败后不自动重试。关闭延迟或自动删除、改变保留章节规则会取消未执行的旧任务，不会立即补删历史已读下载。

## 投票与建议 {#voting-and-feedback}

投票提交到服务端后才会计票，刷新页面、清理浏览器数据或更换浏览器不会解除同一公网 IP 的限制。IP 改变后无法识别为同一参与者，因此票数仅作为需求参考。

服务未开放或临时不可用时会明确显示状态，不会生成本地票数。投票服务仅保存按功能隔离的 IP 校验摘要，不公开原始 IP。

对功能有具体建议，可以到[项目 Issues](https://github.com/AltairCardinal/mihon-desktop/issues)说明使用场景。当前已公开能力见[功能说明](./features.md)。
