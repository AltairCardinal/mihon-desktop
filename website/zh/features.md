# 当前功能

这里是本分支唯一的当前功能说明，集中介绍相对于上游 Mihon 新增的体验，不重复完整介绍继承而来的所有功能。

::: info 公开文档基线 · 2026 年 10 月 13 日
首版说明承接仓库中已经公开的 README 与指南，描述早期开发源码基线，**不代表公开发行或新增验收结论**。后续功能变化只有在项目所有者明确验收通过后，才会进入本页。[查看文档变更历史](./changelog.md)。
:::

**Android 已下载章节打开：** 已验收 Android 候选 `0.19.4-aex.118` 采用 B9 阅读器优化。发布章节页表前无需等待全章图片头读取，并复用未变化的页面事实和章节查询结果。平板正式签名候选移除了阅读器计时记录器。本次验收覆盖实测 Android 平板的打开延迟，实际耗时随设备与内容变化。

## 桌面阅读 {#desktop-reading}

**Windows 全局搜索：** 进入全局搜索后自动聚焦输入框。带作品名称或其他关键词进入时，光标位于末尾且不展开搜索历史，直接输入即可追加文字；主动点击输入框可以展开历史，空关键词进入时显示已有历史。手动移动的光标和选区在重新聚焦、从作品详情返回后保留，搜索结果更新不会抢回焦点。选择历史记录填入关键词时，光标定位到新文本末尾。本次验收仅覆盖 Windows。

**Windows 书架下载反馈：** 在作品上右键，可下载下一未读章节或全部未读章节；菜单跟随点击位置并避让窗口边缘。下载结果改用短暂气泡，不再常驻书架占行；数量只计算实际新增入队的章节。没有未读时提示“已添加0个章节到下载队列：没有未读章节”；已有未读但均已下载或排队时，提示没有可添加的未读章节。“更新结果”紧接更新摘要、同排显示，点击打开现有结果弹窗。本次验收仅覆盖 Windows。

**Windows 书架分类：** 系统默认分类在简体中文下显示“默认”，英文下显示“default”。鼠标移到分类栏后，滚轮可左右滚动分类栏，不改变当前选中的分类；滚动到两端时停止，鼠标移出分类栏后沿用其他内容的滚动行为。

**Windows 启动提示：** 运行打包后的 EXE，应用初始化期间会显示深色 Mihon 卡片、启动文案和底部强调色条。卡片在首次显示前就定位到鼠标所在显示器的工作区中央，从副屏启动不会再先在主屏闪现，并在第一个应用窗口打开时自动关闭。提示需等待 JVM/AWT 初始化后出现，是静态等待提示，不表示实际进度百分比。出现速度取决于机器；恢复最大化窗口时，完整内容呈现前仍可能有短暂间隔。本功能仅验收了 Windows 打包程序，主窗口仍沿用既有的位置恢复行为。

Mihon 的书库与阅读体验有了桌面入口。可以在桌面界面管理书库和下载、打开章节，并选择阅读模式与阅读方向。

**体验路径：**[构建桌面体验版](./getting-started.md) → 从已配置来源或本地书库添加作品 → 打开章节。

**Windows 翻页设置：** 阅读器设置 → 阅读模式 → 选择 **翻页式**，在下方 **翻页** 中选择 **从左到右** 或 **从右到左**，两项互斥。单页与双页布局沿用所选方向。自动模式保持自适应从右到左行为，禁用手动方向选择；条漫模式不显示翻页方向选项。

**Windows 阅读器准备：** 已验收的 Windows 阅读器候选减少了打开章节时的重复准备，同时保留图像画质、页面顺序和正常翻页。实际速度受设备与内容影响；本次变化不代表已证实稳定的首开提速。

**作品详情与章节列表：** 作品详情页章节列表在双栏与单栏布局下均提供原生动态滚动条，滚动与悬停时高亮显示；当右下角【继续】浮动按钮显示时，章节列表底部自动增加 88dp 避让边距，滚到底部时最后一话完整可见且不被按钮遮挡。

**章节操作反馈：** Windows 作品详情页的章节操作成功或跳过后，不再弹出成功／跳过／失败计数提示；失败反馈和可选的加入书库入口继续保留。

**Windows 批量已读与未读：** 在作品详情页选择章节后批量标为已读或未读，也可使用“将下方章节全部标为已读”。正常路径只批写一次；即使本地状态已相同，也保留显式操作的同步意图。整批失败后逐章重试，准确返回成功与失败章节；标为未读时重置阅读进度。不承诺所有设备上的固定完成时间。

**Windows 阅读器设置：** 阅读器设置 → 常规中的缩放选项，简体中文显示“缩放模式”，繁体中文显示“縮放模式”。阅读模式页不再显示放大、缩小、重置及倍率快捷栏；阅读区域原有的手势与快捷键缩放继续可用。

**Windows 批量书签：** 在作品详情页选择章节后，使用添加或取消书签操作批量更新。混合选择时只为尚未加书签的章节补加；全部已加书签时则批量取消。正常添加与取消均只批写一次；整批失败后逐章重试，失败项保留选择以便重试。成功操作保持现有静默反馈。本次验收覆盖 Windows，不代表 Android 或 macOS 已验收，也不承诺所有设备上的固定完成时间。

**阅读器工具栏快捷键：** 阅读区域获得键盘焦点时，按 **空格键** 可同时显示或隐藏顶部和底部工具栏，页码与章节保持不变。此行为适用于桌面版所有阅读模式，包括从左到右、从右到左、自动和条漫，以及单页／双页布局。本次验收覆盖 Windows，不据此声明其他平台的原生操作已通过验收。

**桌面端全屏阅读模式：** 按 **F11** 键或点击阅读器顶部栏设置按钮左侧的全屏按钮可进入或退出全屏模式。首次进入全屏时，屏幕右上角会弹出提示气泡引导使用 F11 快捷键，提示将在 3 秒后自动淡出消失，并通过教程系统持久化记录（确认后不再重复提示）。全屏状态下默认隐藏顶部菜单与底部控制栏，当鼠标悬停至屏幕最上方（顶部 48dp 区域内）时自动显现顶部菜单，下移离开后自动隐藏；悬停至屏幕最下方（底部 80dp 区域内）时显现底部控制栏，移开后隐藏。在全屏状态下按 **Esc** 键亦可直接退出全屏。

**Windows 漫画画面连续性：** 切换全屏时，已显示的漫画持续可见，包括自动单页／双页布局交接。本次已验收的 Windows 阅读路径进入、退出全屏时，不再出现此前的上下跳动、黑白闪烁和左上角白块；其他平台及无法保留过渡帧的回退路径未据此验收。

**图源图片下载与访问错误：** Windows 后台章节下载保留图源自己的图片请求，包括标头、客户端以及自定义请求方法和请求体。切换到更新后的构建后，可在下载队列中重试失败章节。HTTP 403 表示访问被拒绝，不再直接提示需要登录；HTTP 401 保留登录提示。图源网络配置读取失败时保留错误，不静默发送降级请求。Android 共用的错误映射也区分这两个状态。已验收的 Windows 候选，以及 Android 和浏览器检查的边界，见[变更历史](./changelog.md)。

**平台边界：** Windows 是主要桌面开发与验证平台。仓库同时维护 macOS 构建入口，其体验版要求源码和产物目录位于 APFS 卷。当前未配置 Linux 桌面打包与验收流程。体验包构建成功不表示已经具备正式发布条件。

## 双页阅读与跨页匹配 {#two-page-reading}

将相邻两页并排阅读，展示横版页面；封面或页面顺序让配对偏移时，可以手动调整。

**体验路径：** 打开章节 → 选择双页阅读 → 检查页面顺序 → 配对不合适时，在阅读器中手动调整。建议使用熟悉的章节，对照原本应当连在一起的跨页。

**Android 阅读方向：** 阅读器设置 → 阅读模式提供 **双页式（从右到左）** 和 **双页式（从左到右）**，页面排列与翻页行为遵循所选方向。旧客户端读取不认识的左到右双页作品设置时，会降级为从左到右单页。

**Android 阅读设置：** 默认模式说明，包括全局默认为“自动”时的说明，采用标准水平留白和主题辅助文字颜色。两种双页方向下，“自动跨页匹配”紧接阅读模式选项、位于屏幕方向之前，不再附带多余的“单页式”标题；重新打开阅读器后保留开关状态。单页和条漫模式不显示这一双页专用选项。本次验收覆盖菜单和偏好行为，不扩展为自动匹配算法或所有 Android 阅读场景的验收。

**Desktop 辅助匹配：** 根据相邻页面的图像边缘信息辅助识别跨页。这是配对辅助能力，不保证能正确识别每种扫描图或排版；手动校正仍是阅读流程的一部分。

**Windows 配对连续性：** 在已验收的 Windows 阅读路径中，通过顺读、倒读、跳页或重开到达同一章节位置时，页面配对保持一致。已知配对用于安排页面布局，后台匹配保留当前显示页及其伴页。双页阅读、宽图、手动调整、缩放和阅读进度继续可用。本次 Windows 验收不代表 Android 或 macOS 已完成运行验收。

**Windows 图片重试：** 使用失败页面自身的“重试”按钮。在已验收的在线双页场景中，成功重试恢复该页图片并清除错误，正常伙伴和当前阅读位置保持不动。此操作与重新读取已保存的双页调整相互独立，不保证不可用图源一定能恢复。本次验收仅覆盖 Windows。

**Windows 放大拖动：** 放大后拖动漫画查看边缘，单页和双页阅读中，拖动产生的单侧空白最多为阅读区对应宽度或高度的三分之一；双页按整组漫画的外框计算。到边界立即停止，反向拖动立即响应，改变倍率或窗口尺寸后重新限位。小图原本不可避免的留白保留，不允许继续向外扩大。本次验收仅覆盖 Windows 桌面阅读。

**Android 边界：** 本分支 Android 阅读器已支持双页阅读和手动配对；Android 自动匹配已在本次设置和阅读连续性范围内验收，不保证完整识别所有排版。


**已验收的 Android 阅读改进：** 设置 → 阅读器 → **翻页时用水波纹**，提供 **经典（分步）**、**方案 A（平滑）** 和保留的 **简洁（无阴影）**，适用于单页和双页阅读，已有明确偏好继续保留。原图瓦片双页在已测试的奇数阅读区尺寸及恢复尺寸时保持贴合；交付候选通过模拟器像素检查。实体墨水屏刷新表现受设备影响。

**Windows 即时翻页：** 已准备的新页进入可视区时重新绘制，修复已确认的单页/双页即时翻页空帧；切换自动匹配保持阅读连续性，合法重配本身不是错误。本次验收不扩展到 macOS，也不保证识别所有扫描图。

## 多端收藏与阅读进度同步 {#multi-device-sync}

使用专用的 **GitHub 私有仓库**保存同步空间，在本分支兼容的桌面和 Android 构建之间共享状态。

当前公开说明中的同步范围包括：

- 漫画收藏。
- 作者关注。
- 章节已读状态。
- 阅读位置。

**体验路径：** 在一台设备的同步面板中连接 GitHub → 创建或加入同步空间 → 在另一台设备的兼容构建中加入同一空间。通过面板的状态和反馈了解同步进展。

**已验收的 Windows 行为：** 面板立即打开，连接检查在后台继续。本地已保存的取消冲突在检查期间和初次同步结果中均可查看；单条“保留在此设备／在此设备取消”点击后直接生效，无需确认弹窗或等待 GitHub。批量决定仍需确认。“下载批次待系统确认”与这些手动决定分开显示。正在进行的同步会自动续期可续期的 GitHub 凭据；授权被撤销时仍需重新连接。

**兼容边界：** 上游 Mihon Android 应用没有实现本分支的同步协议。两端需要使用本仓库的兼容构建。

**内容边界：** 不同步已下载的章节图片。每台设备仍需能够获取对应阅读内容；同步范围是上述书库与阅读状态，并非搬运应用的全部文件。

## 作者关注与新作品发现 {#authors-and-discovery}

关注作者，浏览其作品以及不同来源中的版本。发现流程会定期检查已配置来源，查找与关注作者相关的新发现作品。

**体验路径：** 打开作者归档 → 关注一位作者 → 浏览找到的作品和来源版本。保留相关来源配置，让发现流程能够执行搜索。

**发现边界：** 结果依赖来源的搜索能力和作者信息，不是全网作品目录，也不保证找到作者的全部作品。别名、缺失署名和不一致的来源数据都可能影响匹配。

## 作品语言信息 {#work-language}

根据来源元数据、标签，以及标题或简介中的文本识别语言信息。桌面作者归档也支持手动校正。

**体验路径：** 在桌面作者归档中查看作品语言信息 → 元数据导致结果不准确时，手动校正。

**识别边界：** 这是基于元数据的识别，**不使用 OCR 读取漫画页面图片中的文字**；来源语言也不一定等于某个作品版本的实际语言。

**筛选边界：** 更完整的语言筛选属于开发方向。这份基线不宣称书库、搜索、作者和各平台上的筛选范围已经全部完成或统一。

### 应用内反馈、私密截图与临时诊断 {#feedback}

在已验收的 Android 和 Windows 候选中，打开设置／关于 → 报告问题，选择类别后获得可编辑模板；只有阅读器类别追加漫画源、作品、章节和页码定位段。切换类别前确认是否替换已编辑草稿。设备信息默认勾选且可取消；类别、描述和选中的设备摘要会公开，附加日志和截图仅维护者可见。

可选择最多两张本地 PNG/JPEG，查看处理进度、最终 JPEG 预览并移除；编码后长边不超过1920像素、每张不超过512 KiB。图片在本地准备，只在最终提交时发送。本期没有内置涂抹编辑器，请提交前检查私人信息。

临时诊断由用户明确开启，一次记录一个选定类别；可离开表单复现后返回当前进程草稿，确认切换类别，或立即停止。取消和提交失败继续保留记录状态，下一份报告成功接收后停止；存储故障明确提示，不冒充已经捕获问题。本说明覆盖 Android 和 Windows，不扩展到 macOS。
